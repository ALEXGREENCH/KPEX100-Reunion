Chase for NES by Alexander “Shiru” Semenov (2012).

The author’s original release includes the cartridge and the corresponding
source. Its src/game.c header says “Feel free to do anything you want with
this code, consider it Public Domain”. The same notice appears in src/neslib.s,
which credits Shiru with improvements by VEG. The title screen reads
“PD2012 SHIRU”. The FamiTone2 v1.11 readme also declares that library public
domain.

Original release archive, Internet Archive capture dated 27 March 2016:
https://web.archive.org/web/20160327132502id_/http://shiru.untergrund.net/files/nes/chase.zip

FamiTone2 v1.11 readme mirrored with HonkeyPong:
https://github.com/HonkeyKong/HonkeyPong/blob/master/famitone-readme.txt

This copy of CHASE.NES is the unmodified Chase.nes from the author’s archive.
