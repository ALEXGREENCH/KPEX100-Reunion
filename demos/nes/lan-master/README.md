# Lan Master

Головоломка Shiru для NES и Famicom, выпущенная в 2011 году. Соедините все компьютеры на плате. Релиз содержит 50 уровней и пароли для продолжения игры. [Руководство автора на русском и английском](manual.pdf)

[LAN.NES](LAN.NES) — неизменённый `Lan_Master.nes` из ZIP автора, снимок 27 марта 2016 года. Размер 40 976 байт. SHA‑256 `becfeafb80479c330333c9e9385417f68f3c88e85443dfb37b05ae9283f3ea45`. NROM-256, 32 КиБ PRG-ROM, 8 КиБ CHR-ROM, вертикальное зеркалирование. [Оригинальный архив](https://web.archive.org/web/20160327132502id_/http://shiru.untergrund.net/files/nes/lan_master.zip)

Автор передал игру в общественное достояние. Условие приведено во введении оригинального руководства, SHA‑256 PDF `5d47e2e28e768de7d11ab50abb5bdbf909449032f74e994c90a67361d0c53a42`. [Сведения о лицензии](LICENSE.txt)

Первый уровень пройден в Reunion и JSNES 2.1.0. Проверены перемещение курсора, три вида поворота, пауза и экран `ALL CONNECTED!` с кодом следующего уровня. Прямой запуск SGS выводит один импульсный голос из оригинальных регистров NES, включая музыку на титульном экране.
