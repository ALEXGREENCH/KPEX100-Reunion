# NES на GNEX

В разделе «Примеры» доступны четыре NROM-картриджа.

- **Orbital Courier**. Стрелками проведите корабль через два пояса обломков и свяжите три маяка слева направо. Кнопка A или Select начинает новую попытку. Видна центральная область NES 208 × 160 без масштабирования.
- **Neon Ranger**. В независимом демоуровне Greg M. Krsak влево и вправо двигают героя, A или Select прыгает. Отпустите кнопку раньше для короткого прыжка. Видна вся ширина NES, сверху убраны 16 исходных строк, а оставшаяся область уменьшена до 192 × 168. [Происхождение и сборка картриджа](neon-ranger/README.md)
- **Lan Master**. Соедините компьютеры, поворачивая участки кабеля. Play открывает игру и паузу, стрелки двигают курсор, Select и Esc поворачивают в разные стороны, Mode делает пол-оборота. В браузере это Enter, стрелки, Z, X и C. Используется та же область 192 × 168, что и в Neon Ranger. [Картридж и руководство Shiru](lan-master/README.md)
- **Chase**. Стрелками собирайте кристаллы и уходите от преследователей. Play начинает игру и переключает паузу. Вывод занимает 192 × 168 пикселей. [Картридж и статья Shiru](chase/README.md)

[Интерпретатор Mobile C](nrom.mc.in) читает картридж через GNEX VFS, запускает RP2A03 с вектора сброса и подаёт ввод через строб и сдвиговый регистр `$4016`. PPU выводит неподвижный фон, палитры и видимые спрайты OAM. Прерывание NMI от VBlank работает с возвратом через RTI. Если обработчик занимает несколько порций Mobile C, следующий VBlank ждёт его завершения. При DMA из внутренней памяти читается непосредственно зеркалируемая страница RAM. Изменённые ячейки фона рисуются первыми, смена палитры или таблицы помечает всю видимую область.

Заголовок поддерживает iNES mapper 0 с одним или двумя банками PRG-ROM, одним банком CHR-ROM, горизонтальным или вертикальным зеркалированием. Реализована часть инструкций RP2A03. VBlank подаётся раз в 20 мс. Расширение на произвольные игры требует полного набора инструкций, APU, прокрутки, точной модели приоритета спрайтов и потактовой синхронизации. [Схема NROM](https://www.nesdev.org/wiki/NROM) · [PPU](https://www.nesdev.org/wiki/PPU_programmer_reference) · [Контроллер NES](https://www.nesdev.org/wiki/NES_controller)

## Звук Chase и Lan Master

Прямой запуск воспроизводит импульсный голос из записей оригинальной игры в `$4000–$4007` и `$4015`. Mobile C собирает 16-битный моно WAV на 16 кГц и передаёт его штатному `PlaySound`. Период и форма берутся из регистров NES, амплитуда следует программной громкости FamiTone. Одновременно звучит один голос, второй используется, когда первый молчит. Изменения группируются по таймеру GNEX. Огибающая и sweep APU, треугольник, шум и DPCM пока отсутствуют. [Исходник](pulse-audio.mc) · [Регистры импульсных каналов NES](https://www.nesdev.org/wiki/APU_Pulse)

В полной эмуляции Kingston 2.12 родной `PlaySound` принимает ресурс типа WAV, однако WAV-декодер прочитал ноль байтов из своего файлового объекта в контрольных прогонах с 8- и 16-битным PCM. Прогон на физическом устройстве ещё не проводился.

## Сборка

Для сборки SGS под Windows положите оригинальные `mcc_GNEX.exe` и `MASM_GNEX.exe` из SDK 2.12 в одну папку. Общий [сборщик](../sgs_build.py) проверяет SHA‑256 и меняет дату окончания работы компилятора во временной копии. Исходник картриджа находится в [build.py](build.py). [Архив GNEX SDK 2.12](https://archive.org/details/gnex_sdk_v2.12)

```powershell
python demos/nes/build.py --sdk C:/path/to/sdk --output ORBITAL.SGS
python demos/nes/build.py --rom-only --output ORBITAL.NES
python demos/nes/build.py --sdk C:/path/to/sdk --neon-ranger --output NEON.SGS
python demos/nes/build.py --sdk C:/path/to/sdk --lan-master --output LAN.SGS
python demos/nes/build.py --sdk C:/path/to/sdk --chase --output CHASE.SGS
```

Параметр `--cart test.nes` заменяет вложенный картридж для экспериментов с поддерживаемыми инструкциями и регистрами. `--plain` отключает кодирование XOR для другого загрузчика. [Интеграционные тесты](../../tests/nes-demo.test.mjs) проверяют три маяка и перезапуск [Orbital Courier](../../web/data/games/demo-orbital-courier.sgs), ходьбу, прыжок и приземление [Neon Ranger](../../web/data/games/demo-neon-ranger.sgs), запуск уровня, перемещение курсора и поворот кабеля [Lan Master](../../web/data/games/demo-lan-master.sgs). Самостоятельный `.nes` Orbital Courier отдельно прошёл тот же маршрут в [JSNES 2.1.0](https://github.com/bfirsh/jsnes/tree/v2.1.0).

Для запуска из меню `GAME` Kingston 2.12 положите рядом одну из пар `ORBITAL.SGS` и `ORBITAL.NES`, `NEON.SGS` и `NEON.NES`, `LAN.SGS` и `LAN.NES`, `CHASE.SGS` и `CHASE.NES`. В полной эмуляции прошивки используется внешний картридж через оригинальные вызовы GNEX.
