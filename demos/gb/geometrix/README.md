# Geometrix для Game Boy Color

В Geometrix нужно собирать линии из трёх и более одинаковых фигур. В игре Антонио Ниньо Диаса можно очищать поле, играть на время или уложиться в ограниченное число обменов. Стрелки двигают курсор, Select меняет выбранные фигуры местами, Esc поворачивает курсор, Play начинает игру или ставит её на паузу. [Оригинальные исходники и описание игры](https://github.com/AntonioND/geometrix)

В `GEOM.GBC` лежит неизменённый ROM на 32 КиБ из ревизии `8f5467ec225e21d67b2e6621eabede70dc6cc8fa`. SHA-256 — `56efdf82118e5faf22511c18dd1fc2ab8bc0c5e44cd634b8e06050ff08124586`. [Картридж](GEOM.GBC) · [Исходный архив](geometrix-8f5467e-source.zip) · [GPL v3](LICENSE)

Для запуска через Kingston 2.12 положите `GEOM.SGS` и `GEOM.GBC` рядом в папку `GAME`. Игра использует 8 КиБ SRAM. Лаунчер сохраняет их в `GEOM.SAV` при закрытии доступа к SRAM. В прямом режиме браузер хранит файл в сохранениях игры. На плеере это файл на накопителе.

Профиль реализует двухстраничный MBC5, обычный GDMA, две карты VRAM, вертикальное смещение и прерывание LY/LYC для меню паузы. Отрисовка обновляет затронутые полосы в буфере. Kingston получает целый кадр. Звук Game Boy в этой сборке отсутствует. [Регистры Game Boy Color](https://github.com/gbdev/pandocs/blob/master/src/CGB_Registers.md)
