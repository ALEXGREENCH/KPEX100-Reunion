# Flooder

Головоломка Обальфура для Game Boy Color. Перекрашивайте область, связанную с верхней левой клеткой, пока вся доска не станет одного цвета. На партию даётся 25 ходов. Play запускает игру, стрелки вверх и вниз выбирают цвет, Select применяет его.

`FLOODER.GBC` — файл `rom/flooder.gb` из авторского коммита `2e62e69ed44a0ef21840df52451d883dbe8e6375`, без изменений. Размер 32 768 байт, SHA‑256 `2b93dd9e623678e1c5c33b942a9a5621529d9073be854b32c9f59af8b70b5292`. [Авторский ROM и исходники](https://github.com/Obalfour/Flooder/tree/2e62e69ed44a0ef21840df52451d883dbe8e6375) · [Лицензия MIT](LICENSE)

В комплекте Kingston лаунчер `GAME/FLOODER.SGS` читает `GAME/FLOODER.GBC`. Такая же копия лежит в `GAME/GBC/FLOODER.GBC`. В SGS реализованы цветные спрайты 8 × 8, перенос OAM, полноэкранное окно и приближённые фазы LCD. Короткое нажатие сохраняется до окончания чтения выбранной группы JOYP. Звуковые команды исходного картриджа требуют эмуляции APU. [Сборка и остальные картриджи](../README.md)

При генерации поля SGS объединяет полные итерации распознанного цикла деления SDCC. Перед этим проверяются все 36 байтов цикла, адрес стека и диапазон операндов. Сохраняются регистры, записи в стек и число циклов SM83. На границе VBlank интерпретатор возвращается к обычным инструкциям. [Исходник Mobile C](../gb-reunion.mc)
