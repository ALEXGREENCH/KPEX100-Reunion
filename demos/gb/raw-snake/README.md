# Raw Snake

Альберт Гонсалес выпустил Raw Snake для Game Boy в 2021 году. `SNAKE.GB` совпадает с файлом `snake.gb` из авторского репозитория на коммите `1be317f457620db0752d8ca81a6afe09495c4687`. Размер 32 768 байт. SHA-256 `0fdae5875ada46cff93b8f3cfbe93f814bd77febf3d2cff162707a81d1f35fac`. [Исходный репозиторий и ROM](https://github.com/theisolinearchip/gb_raw_snake/tree/1be317f457620db0752d8ca81a6afe09495c4687) · [Unlicense](LICENSE)

В комплекте Kingston файл лежит в `GAME/GB/SNAKE.GB` и в `GAME/SNAKE.GBR`. Лаунчер `GAME/SNAKE.SGS` использует плоское имя с трёхбуквенным расширением. Play запускает игру, стрелки поворачивают змейку.

Внутри SGS циклы ожидания VBlank, очистки WRAM и копирования ROM в VRAM объединяются после проверки всех байтов исполняемой ветки. Объединение сохраняет регистры, флаги и расчётную стоимость завершённых итераций. Спрайты рисуются горизонтальными участками одного цвета, чтобы снизить число вызовов графики GNEX. [Mobile C и сборка](../README.md)

В полной эмуляции Kingston 2.12 проверены чтение всего картриджа с FAT, Play на заставке и поворот вверх. Кадр заставки совпал с прямым режимом с учётом округления RGB565. [Тест прямого запуска](../../../tests/raw-snake.test.mjs)
