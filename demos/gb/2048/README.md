# 2048 для Game Boy

[Картридж Уайатта Фергюсона](2048.GB) взят из [репозитория автора, ревизия 1677881](https://github.com/wyattferguson/2048-gb/tree/167788105db659f2049dd2d537ee12f63d87b1e7). Это оригинальный ROM на 32 КиБ без контроллера банков, лицензия [MIT](LICENSE).

SHA-256 исходного ROM — `46f9ab6a5e9acb81c76e9c2c6526db1ed4e03b4fb6f36c23fb786e31f9659fc5`.

Play открывает поле 5 × 5. Стрелки сдвигают плитки, Select начинает новую партию. SGS читает ROM с именем `2048.GBR` и выводит нижнюю строку счёта через оконный слой Game Boy. В комплекте для K-PEX положите `2048.SGS` и `2048.GBR` рядом в `GAME`.

На оригинальной прошивке Kingston 2.12 с виртуальным диском проверены загрузка ROM, старт, сдвиг плиток, появление новой плитки и сброс. Для измерений на железе нужен подключённый плеер.
