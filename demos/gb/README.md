# Pocket Lab

Оригинальная демка Reunion. В библиотеке откройте «Примеры», затем **Pocket Lab · Game Boy на GNEX**. Стрелки двигают робота по комнате.

SGS читает `cart.gb` вызовами `FileOpen`, `FileReadInt` и `FileClose`. Сам картридж заполняет VRAM, опрашивает регистр `$FF00` и перемещает тайл робота. Обработчик SGS только подаёт ввод, исполняет инструкции и выводит видимую область из тайлов. Эмуляция DMG находится в [Mobile C](gb-reunion.mc). Генератор [build.py](build.py) содержит исходник тестового картриджа и упаковывает его в хвост SGS как файл VFS.

Это прототип под тестовый 32-КиБ ROM-only картридж. Реализованы необходимые ему команды SM83, регистр направлений, 2-битные фоновые тайлы и палитра DMG. Произвольные игры, прерывания, звук, банкование, CGB и NES требуют дальнейшего портирования. Экран выводится целиком при размере не менее 160 × 144. В комплекте только наш картридж без загрузочного ROM и логотипа Nintendo.

## Сборка на Windows

Распакуйте оригинальные `mcc_GNEX.exe` и `MASM_GNEX.exe` из SDK 2.12 в одну папку и передайте её путь. Сборка сверяет оба SHA‑256. Старый компилятор заканчивает работу после 31 января 2010 года. Генератор меняет год на 2099 только во временной копии компилятора. [Архив GNEX SDK 2.12](https://archive.org/details/gnex_sdk_v2.12)

```powershell
python demos/gb/build.py --sdk C:/path/to/sdk --output pocket-lab.sgs
```

Готовый [SGS](../../web/data/games/demo-pocket-lab.sgs) можно импортировать как обычный файл. Для исполнения в Reunion нужен Kingston 2.12. `--cart` заменяет тестовый картридж на свой совместимый ROM-only файл. [Интеграционная проверка](../../tests/pocket-lab.test.mjs)
