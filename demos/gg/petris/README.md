# Petris 1.1 beta

На титульном экране нажмите Play. В настройках стрелки выбирают пункт, Select подтверждает. На поле влево и вправо двигают фигуру, вниз ускоряет падение, Select поворачивает вправо, Esc — влево. Play ставит игру на паузу.

Для запуска через меню Kingston 2.12 положите `PETRIS.SGS` и копию `PETRIS.GG` под именем `PETRIS.GGR` рядом в папку `GAME`. В комплекте для K-PEX оригинальное имя сохранено в `GAME/GG/PETRIS.GG`. В прямом режиме Reunion лаунчер читает те же 32 КиБ из VFS. [Лаунчер SGS](../../../web/data/games/demo-petris.sgs)

Это неизменённый картридж bbbbbr с SHA-256 `2de507b5708cc66020a700e3f4674216cb3374fc5d39369da86221bb34a07ba9`. ROM из релизного ZIP совпадает с `rom/Petris-beta-2021-10-10.gg` в архиве исходников. Архив содержит исходники, лицензию CC BY-NC-SA 4.0 для ветки Game Gear и отдельные уведомления о стороннем коде. Лаунчер сохраняет циклы Z80, флаги и регистр обновления памяти при свёртке проверенных циклов ROM. Переходы через строки VDP обрабатываются с учётом IRQ и снимка в VBlank. При отсутствии прокрутки кэш декодирует одинаковые строки тайлов один раз. GNEX получает индексированный кадр 160 × 144 без растягивания. В сравнении по четырём снимкам кадры совпали побайтно, объём работы GNEX при отрисовке снизился на 37–53%. Этот замер относится к отрисовке кадра. Звук PSG отсутствует, синхронизация VDP приближённая.

Прямой запуск проверен от заставки до первого управляемого падения. На поле проверены движение вправо, поворот и падение до дна. Темп на физическом плеере ещё не измерен.

```powershell
python demos/gg/build.py --petris --rom-only --output PETRIS.GG
python demos/gg/build.py --petris --sdk C:/path/to/sdk --output PETRIS.SGS
```
