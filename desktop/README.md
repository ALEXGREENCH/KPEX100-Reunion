# Reunion Desktop

Нативное ядро на Python и настольное приложение Tk для Kingston K-PEX 100 / Cenix
GMP-M6. Оно исполняет ARM-код оригинальной прошивки через Unicorn.

Проверены четыре игры K-PEX: Hell Fire, KPetris Beta, Ikaria ep2 и Godori.
Kingston 2.12 загружается до меню, файлового менеджера и Hell Fire в полном режиме.
Остальные прошивки экспериментальны. Для телефонных SGS и Swerve 3D используйте
[веб-версию](../README.md): телефонные расширения в это ядро ещё не перенесены.

## Запуск из исходников

Python 3.11 или новее, с Tk. В Windows установщик Python обычно включает Tk.
Команды выполняются в `desktop/`:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe launch.py
```

В Linux/macOS активируйте `.venv/bin/activate`, затем используйте `python`.
Для Linux может понадобиться системный пакет `python3-tk`.
Интерфейс и ядро используют переносимые библиотеки; готовый EXE и вывод MP3-звука
проверяются в Windows. Другие настольные платформы не имеют такого же уровня QA.

Общая коллекция оригиналов включена в `web/`. При первом запуске настольная версия
автоматически подготавливает `desktop/data/`: девять ROM, четыре K-PEX SGS и три
быстрых состояния. Файлы распознаются по SHA-256; повторный запуск использует уже
подготовленные копии. `desktop/data/` генерируется локально и не дублируется в Git.

В интерфейсе можно также открыть собственные ROM/SGS. Прямой запуск SGS требует
неизменённую Kingston 2.12. Для импорта дополнительной внешней подборки:

```powershell
.venv\Scripts\python.exe tools/assets.py import C:\path\to\originals
.venv\Scripts\python.exe tools/assets.py verify
```

Подходит и каталог прежней полной сборки Reunion. Импорт не скачивает файлы и не
исполняет установщики. Неизвестные файлы пропускаются, изменённые существующие
файлы не перезаписываются. `--require-all` делает отсутствие любого файла из
манифеста ошибкой; без него разрешена неполная коллекция.

## Сборка Windows EXE

Нужны 64-битный Python и MSVC Build Tools с C++ либо LLVM-MinGW в `PATH`:

```powershell
./build.ps1
```

Результат: `build/package/Reunion.exe` с коллекцией в соседней папке `data`.
Скрипт создаёт `.venv`, подготавливает оригиналы из `web/`, устанавливает
фиксированные зависимости, собирает совместимый загрузчик PyInstaller и запускает
тесты. Готовый EXE проверяется выполнением ARM, четырёх игр и двух контрольных
состояний прошивки. Для переноса программы скопируйте всю папку `build/package`.

Дополнительные параметры:

```powershell
# Добавить необязательный SMAF-декодер; требуется LLVM-MinGW clang++.
./build.ps1 -WithSmaf

# Дополнительный вариант только с исполняемым файлом, без коллекции.
./build.ps1 -WithoutOriginals
```

Подробности загрузчика, звука, CLI и управления: [doc/desktop.md](../doc/desktop.md).

## Проверки

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
python -m pytest tests -q --with-originals
```

Первый запуск выполняет тесты на синтетических данных. Второй автоматически
подготавливает коллекцию, проверяет хеши 13 ROM/SGS и включает интеграционные сценарии. Быстрые состояния
не обязательны; тест SMAF требует собранного декодера. Реальное воспроизведение
через аудиоустройство по умолчанию отключено и требует `REUNION_AUDIO_TESTS=1`.
