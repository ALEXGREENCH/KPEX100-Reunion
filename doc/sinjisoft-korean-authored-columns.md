текст — производный файл. В квитанциях указаны запрошенный и итоговый URL,
заголовки HTTP, UTC получения, размер и SHA-256. Время получения относится
к текущему ответу сайта, не к его исторической версии.

## Повтор и поиск по-корейски

После распаковки подборки доступны инструменты, входной список URL и
манифест. Нужен Python 3.11+, дополнительных библиотек нет:

```sh
python tools/preserve-platform-pages.py provenance/article-seeds.json ./new-fetch
python tools/wayback-text-index.py search derived/wayback-pass6-text-index.json "보도자료"
python tools/wayback-text-index.py search derived/wayback-pass6-text-index.json "기술세미나"
python tools/wayback-text-index.py search derived/wayback-pass6-text-index.json "개발"
python tools/wayback-text-index.py search derived/wayback-pass6-text-index.json "매뉴얼"
python tools/wayback-text-index.py search derived/wayback-pass6-text-index.json "자료실"
```

`preserve-platform-pages.py` запрашивает только явный список URL, сохраняет
также HTTP-ошибки и повторно использует оригиналы после проверки SHA-256.
`--refresh` делает новый запрос с отдельной квитанцией; старые объекты
сохраняются. Флаг `verified` означает HTTP 200, декодирование без потерь и
наличие заданных видимых строк. Проверка автора, типа и смысла публикации
выполняется отдельно; автоматическая проверка слов её не заменяет.
Код страниц и исторические программы не исполняются.

В сетевом поиске использованы `신지소프트 보도자료 GVM GNEX`,
`신지소프트 지넥스 자료실 개발 매뉴얼`, `신지소프트 기술자료`,
`신지소프트 회사소개서` и точные корейские заголовки серии.
GNEX SDK 1.20/1.40 и самостоятельный телефонный проигрыватель в этом проходе
не получены; [конкретные оставшиеся зацепки](gnex-early-sdk-player-followup.md)
сохраняются отдельно.
