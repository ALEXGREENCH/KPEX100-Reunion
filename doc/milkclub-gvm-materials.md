## Запуск Hello GVM

Исходный 718-байтный `Hello.sgs` доступен во вкладке «Примеры». Это GVM1X
с тремя ресурсами. В проверенном профиле 96 × 64 стартовый кадр содержит
картинку, а клавиша OK добавляет строку Hello GVM и меняет 118 пикселей.
Звук на старте содержит восемь событий GVM buzzer общей длительностью 1 008 мс.
Рендерер получил ненулевой PCM из оригинальных байтов. Модель телефона
для профиля 96 × 64 не установлена.

```sh
node tools/replay-sgs.mjs sample-gvm-hello validation/replay-milkclub-hello.json hello-frames
```

[Оригинальный SGS](../web/data/games/sample-gvm-hello.sgs),
[сценарий ввода](../validation/replay-milkclub-hello.json).
