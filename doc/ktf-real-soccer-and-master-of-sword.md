# Real Soccer и Master of Sword 3 для KTF

Из вложений Dubigame сохранены три сборки KTF WIPI. У исходных ZIP и вложенных JAR проверены CRC. В архиве сохранены файлы как их выдал источник, манифесты и записи запусков. [Архив игр](../research/archives/Dubigame-Real-Soccer-and-Master-of-Sword.zip) · [Хеши и результаты](../validation/ktf-real-soccer-and-master-of-sword.json)

| Игра              | Идентификатор и версия | Проверенная сцена                                                                                                                                                                                                          |
| ----------------- | ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Real Soccer 2007  | `PD005307`, `02.00.00` | В ARAM правая софт-клавиша подтверждает состав и открывает загрузку матча Германия — Англия. Кадр без ввода остаётся в меню состава. [Вложение](https://dubigame.tistory.com/46)                                           |
| Real Soccer 2009  | `PD007392`, `01.00.02` | WIE завершает установку из того же ZIP, проходит выбор команд и показывает поле с предложением начать тренировку перед матчем. В ARAM приложение останавливается на установке. [Вложение](https://dubigame.tistory.com/47) |
| Master of Sword 3 | `PD005033`, `01.00.01` | OK продвигает диалог пролога в ARAM. Прогон без ввода на том же кадре остаётся на предыдущей реплике. [Вложение](https://dubigame.tistory.com/51)                                                                          |

WIE запущен в Chrome с локальными копиями JS, WASM и игры. Внешние запросы запрещены в сценарии, за прогон их не было. У ARAM экран установки оставался виден на кадре 237, когда состояние уже стало `stopped`. В отчёте разработчика WIE для двух вариантов Real Soccer 2009 описаны исправления операций с базой данных, включая переименование, поиск имён с начальным `/`, позиционирование и создание каталога. Этот отчёт объясняет, где искать различие реализаций. Отдельная причина остановки в ARAM пока не локализована. [Ревизия ARAM](https://github.com/mirusu400/aram-core/tree/fea299cba15696ed1460f965b76626d6edab5e03) · [Отчёт WIE](https://github.com/Jun025/wie/blob/1ca15ebf5a3ebc691a680a7854e99a32e75d46f4/docs/report/0401--2026-10-01--wie-ktf-data-install-fail-db-list-records-adopt-p0.md)

## Установочные данные Real Soccer 2009

Файл `lo.zinfo` внутри JAR задаёт блок в 102 400 байт, 18 частей и общий размер 1 758 425 байт. Последовательное соединение `lo.z00`–`lo.z17` даёт ZIP. Проверены CRC всех 94 файлов и ссылки на ресурсы из `resource.xml`. Внутри есть `RS09.dll` с заголовком PE32 Thumb и 90 потоков LZMA, распаковывающихся в 1 055 139 байт. Самостоятельный запуск DLL не проверялся.

```sh
python tools/extract-ktf-real-soccer-2009.py "리얼싸커2009.zip" rs09-install.zip
```

Сценарий WIE в архиве ожидает `wie_web.js`, `wie_web_bg.wasm` и копию исходной игры под именем `real-soccer-2009-ktf.zip` рядом с собой. [Архив проверенной версии WIE](../research/archives/Otterpebble-WIE-Web-and-Dongmul-Demo.zip)
