# LG SD1020 и SD1250. Сжатый GVM и Ladder

**Ladder** (`사다리 게임`) из LG SD1250 доступен в библиотеке Reunion.
Оригинальные 110 686 байт SGS v1 извлечены из образа SD250I11 со смещения
`0x4aa8a0`. В проверенном сценарии на три участника удалось выбрать
вариант без SMS, назначить призы и открыть результат ветки. После выбора
другой ветки кадр изменился. Использован профиль 120×160.
[Исходная прошивка](https://archive.sunderland93.ru/Firmwares/LG/SD1250/SD250I11.7z) ·
[SGS](../web/data/games/ladder-lg-sd1250.sgs) ·
[Сценарий](../validation/lg-ladder-replay.json).

В дампе LG SD1020 запись `gvm2x/gvm2x_000` с заголовком **힙합정신**
тоже оказалась целой. Это раннее приложение для рингтонов. После заставки
оно показывает список мелодий и меню регистрации звонка. Экраны проверены
с профилем 120×144.
[Исходный дамп](https://archive.sunderland93.ru/Firmwares/LG/SD1020/SD43CI23_memory.7z) ·
[Оригинальная запись, распакованный SGS и кадры](../research/archives/LG-SD1020-Compressed-GVM.zip).

В записи 36 423 байта, включая 176 байт операторской обёртки. SGS начинается
с версии 1 и `IMAGETYPE 4`. Первые 100 байт SGS открыты, далее идёт поток
MSB-first. Нулевой бит вводит 8-битный литерал. Единица вводит 6-битный
индекс в последних 64 байтах и длину в коде Элиаса. В Kingston 2.12 окно
изначально заполнено байтом `0x6d`. В ассемблере Sinjisoft MASM из SDK 2.12
запись потока находится в `0x409650` и выбирается для IMAGETYPE 4 или 8.

Нативный декодер Kingston со смещения ROM `0x414e8` и реализация на Python
дали одни и те же 61 159 байт. На вход нативной функции подавался файл
через ограниченную заглушку чтения. Последние три распакованных нуля лежат
за объявленным концом ресурсов. Строгий SGS в архиве содержит 61 156 байт,
85 переменных и 54 ресурса. Операторская копия сохранена целиком.
[Смещения, хеши и проверка](../validation/lg-compressed-gvm-evidence.json).

Команда для исходной записи из архива:

```sh
python tools/decode-gvm-compressed.py gvm2x_000.bin hiphop-spirit.sgs --offset 176
```

Узкий дополнительный поиск по 31 локальному образу и файлу проверял
открытый заголовок GVM v1/v2 с IMAGETYPE 4/8 и последующие секции после
распаковки. Кроме `힙합정신` полных совпадений не было. Проверка искала
непрерывные байты и отдельно два ранее собранных файла EFS SD1020.
