# Вложения к играм GVM Club за 2003 год

В разделе обмена исходниками сохранились точные пути к семи ZIP.
Четыре записи описывают игры, а публикация с `BomberMan2.zip`
обозначена как пример сетевого контента GVM. Три снимка списка
подтверждают имя файла этого примера.

| Публикация                   | Что известно о вложении                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Пингвин бросает мяч          | В апрельском списке указано `penguin.zip`, в июньском посте `팽귄.zip`. Заголовки совпадают, содержимое обоих файлов неизвестно. [Список](https://web.archive.org/web/20030514064717id_/http://www.gvmclub.com:80/data/source/list.php3?table=tbl_pds_source&page=1), [пост](https://web.archive.org/web/20030726025754id_/http://www.gvmclub.com:80/data/source/read.php3?table=tbl_pds_source&no=20).                                                               |
| Головоломка с картинкой      | 최기수 указал, что `퍼즐게임.zip` содержит исходники игры. [Пост](https://web.archive.org/web/20031021120135id_/http://gvmclub.com:80/data/source/read.php3?table=tbl_pds_source&no=24).                                                                                                                                                                                                                                                                              |
| Игра с цветами               | 신상우 выложил свою первую работу для GVM вместе с исходниками в `gvmflower.zip`. [Пост](https://web.archive.org/web/20031021121407id_/http://gvmclub.com:80/data/source/read.php3?table=tbl_pds_source&no=33).                                                                                                                                                                                                                                                       |
| Сетевое приключение          | jaster описал мини-игры, переодевание аватара и сервер на Java, PHP и MySQL. Под именем `street.zip` в двух постах есть разные пути. Во втором посте говорится об исходнике Java. [Игра](https://web.archive.org/web/20040123181033id_/http://gvmclub.com:80/data/source/read.php3?table=tbl_pds_source&no=30&page=2), [дополнение](https://web.archive.org/web/20040815051738id_/http://www.gvmclub.com:80/data/source/read.php3?table=tbl_pds_source&no=34&page=2). |
| Пример сетевого контента GVM | `BomberMan2.zip` прикреплён к записи № 38 от 9 октября 2003 года. Какие файлы внутри и была ли это играбельная сборка, неизвестно. [Список](https://web.archive.org/web/20031011041933id_/http://gvmclub.com:80/data/source/list.php3?table=tbl_pds_source).                                                                                                                                                                                                          |

Сохранены 11 HTML-ответов. Для каждого повторно проверены CDX SHA-1
и локальный SHA-256. По всем семи путям проверены оба имени хоста.
В локальном индексе CDX совпадений нет. Из 14 прямых запросов к Wayback
13 вернули HTTP 404, один завершился по тайм-ауту. Каждый из двух
индексов Common Crawl, 2008–2009 и 2014-52, вернул один HTTP 404,
пять HTTP 503 и восемь тайм-аутов. Вложения остаются в поиске.
