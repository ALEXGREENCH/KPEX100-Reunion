# Mobile GoStop на Samsung Anycall

В «Играх» выберите Mobile GoStop. Подтверждайте заставку, New Game и переходы
к столу кнопкой OK, Enter или Z. На первом столе кнопки 1, 5 и 7 разыгрывают
карты. [Открыть библиотеку](https://alexgreench.github.io/KPEX100-Reunion/).

Исполняется оригинальный `버전 다름/모바일 고스톱.mbin` из вложения Anycall Land.
В записи 89 421 байт и CRC32 `7e476ef8`. Оригинал и производные кадры
сохранены отдельно. [Оригинальный архив](../research/archives/Samsung-Anycall-ADS-MBIN.zip) ·
[Публикация с вложениями](https://m.blog.naver.com/sendei333/222605737137) ·
[Кадры и манифест](../research/archives/Samsung-Anycall-Mobile-GoStop-Replay.zip).

На одинаковой раздаче проверены отдельные нажатия 1, 5 и 7. В контрольном
прогоне без ввода стол не изменился. Через 80 тактов после ввода разница
с контролем составила 205, 1 236 и 1 434 пикселя соответственно. Для 5 и 7
на кадрах также меняется счёт. Все 14 кадров 120 × 128 из прогона Python
Unicorn совпадают с индексными кадрами веб-ядра ARM/WASM.
[Манифест](../validation/anycall-mobile-gostop.json).

В заставке один вызов `+0xc4` передаёт 12 нулевых байт по адресу
`0xf500132c` и возвращается через `0xf4005755`. Хост пропускает этот
вызов при совпадении всех трёх условий. Назначение общего API `+0xc4`
ещё предстоит установить. Начальная раздача воспроизводится с фиксированным
зерном генератора. Палитра RGB332 и частота таймера приближённые.

Между раздачами игра обновляет счёт в памяти и обращается к службе
`+0x0c` из `0xf400554b` с блоком по адресу `0xf5001940`. Хост подтверждает
запрос для этого блока. Прогон с повторными раздачами проверяет состояние
после 5 320 показов кадра. Звук и сохранение между запусками пока недоступны.
[Тест ARM/WASM](../tests/ads.test.mjs).

python -m pip install unicorn==2.1.4 Pillow==13.0.0
