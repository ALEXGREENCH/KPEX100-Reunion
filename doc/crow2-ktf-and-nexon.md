# Crow 2 для KTF и каталог Nexon 2006 года

[Скачать комплект](../research/archives/Softmax-Crow-2-KTF-and-Nexon-Catalogue.zip).
Внутри оригинальный ZIP игры, список файлов с CRC32 и SHA-256, сценарий
запуска, кадры, снимки каталога Nexon и результаты поиска в двух сборниках S60.

## 창세기전 크로우2

Из вложения получен оригинальный `창세기전 크로우2.zip` размером 686 040 байт.
SHA-256 `ea35907b22a4b36d841bf355a8c0f8a8b125ad11c2c6dbfd9364bb39a9b052d3`.
В `__adf__` указаны версия `01.00.06`, издатель `(주)소프트맥스`, класс
`Crow2`, AID `010100D2` и экран 240×320. Проверены CRC всех шести файлов
архива и всех 154 записей во вложенном JAR, включая каталоги. В JAR есть
исполняемый Thumb-код `client.bin964` и метаданные WIPI Java с именем
`org/kwis/msp/lcdui/Jlet`. Внешние файлы и содержимое JAR проверены на SGS
в открытом виде и под XOR 165. Валидных SGS в пакете не найдено.
[Исходное вложение KTF](https://dubigame.tistory.com/431).
[Формат пакетов KTF](https://github.com/dlunch/wie/blob/main/docs/ktf.md).

В ARAM с профилем `wipi-1.2.1/ktf/generic` проверены меню, новая игра,
реплики вступления и перемещение вправо и вниз в первой игровой сцене.
Два запуска с `--run-budget 200000` дали побайтно одинаковые 15 PNG.
Для воспроизведения в комплекте есть Lua и точная команда. Проверка
ограничена началом игры. Звук и прохождение до конца не проверялись.
[Исходники ARAM на проверенном коммите](https://github.com/mirusu400/aram-core/tree/fea299cba15696ed1460f965b76626d6edab5e03).

Пакет KTF/WIPI хранится в исследовательском каталоге. В библиотеке
Reunion уже есть отдельная SGS-сборка Crow 2 для SKT. Softmax подтверждала
раздельные релизы KTF и SKT. Первая Crow для GVM остаётся целью поиска.
[Релиз Softmax](https://www.newswire.co.kr/newsRead.php?no=65491).
[Сведения о первой Crow](softmax-mobile-and-symbian.md#первая-crow).

## Nexon Mobile

В июльском HTML главной страницы у `삼국지영웅전5` указан ID `194`.
Форма открывает `/html/Game/GameView.asp?Idx=194&ListGubun=Popular`.
Ссылка на советы по игре ведёт на
`/html/Game100/Game_Knowhow/Read.asp?Idx=3&DisNum=3`.
Сохранён и отдельный список игр с идентификаторами карточек и категорий.
[Главная](https://web.archive.org/web/20060703014630id_/http://mobile.nexon.com:80/main.asp?).
[Список игр](https://web.archive.org/web/20060718101435id_/http://mobile.nexon.com:80/html/game/List.asp?).

Wayback Availability не вернул снимков по двум полным вариантам адреса
карточки. Запросы к CDX частично завершились HTTP 429, 503 и ошибками
соединения. В комплекте отдельно сохранены статусы, исходные HTML
и квитанции с датами снимков. Совпадение с CDX digest для этих HTML
не проверялось.

Из каталога Nexon файл игры пока не получен. В Reunion уже доступна
сборка `0053794639.SGS`. В инструкции владельца Motorola MS800
показана другая копия `0053541897.SGS`, которую продолжаем искать.
[Данные о Motorola MS800](gnex-devices.md#устройства-с-документацией-gnex-и-gvm).

Из того же каталога Nexon известна **2006 Germany Soccer**. Пакет SKT
из зеркала Dubigame сохранился и в ARAM дошёл до матча.
[Пакет и сценарий проверки](dubigame-mirror-ktf-skt.md).

## Два сборника S60

Под двумя названиями распространяется почти одинаковый набор Ultimate SIS
Pack. В распакованных деревьях 14 751 пар файлов совпали по SHA-256.
Основной проход разобрал 862 из 866 вхождений SIS. Десять попаданий SGS
совпали по байтам с уже сохранёнными Aiolos Fighter, Pocket Baseball 2 и
Pocket Golf. После дополнительной проверки осталось семь неразобранных
контейнеров 7z и один RAR, а в двух уникальных SIS произошли ошибки
распаковки. В комплект включены манифесты проверки. Сами сборники
можно скачать с исходных страниц.
[Сборник ZIP](https://www.mediafire.com/file/zqhqrtxnqiouw8c/s60v2_games_pack.zip/file).
[Сборник RAR](https://www.mediafire.com/file/scw64ntpx8obqdf/sis_pack.rar/file).
