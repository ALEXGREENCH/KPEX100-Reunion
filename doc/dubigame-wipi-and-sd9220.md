# Девять игр Dubigame и неполный дамп LG SD9220

Из десяти открытых вложений Dubigame девять впервые добавлены в архив Reunion. Десятая игра, `정무문2`, побайтно совпала с уже сохранённым ZIP. Для каждой новой сборки проверены CRC внешнего ZIP и всех файлов вложенного JAR. У семи версий KTF найден нативный `client.bin*`, у двух версий LGT — ARM ELF `binary.mod` в пакете Raptor. Структурный поиск SGS по обоим слоям совпадений не дал.

Для прогона использован ARAM `fea299c`, виртуальный кадр 16 мс, размер окна по умолчанию 240×320. Для сборок, которые объявляют иной размер, фактическое разрешение указано рядом с хешем кадра. В ZIP сохранены страницы вложений, неизменённые игровые пакеты, Lua-сценарии, журналы и PNG. Кадры парных прогонов совпадают непосредственно перед последним вводом. После него кадр сопоставляется с контрольным прогоном на том же виртуальном времени. Проверка охватывает перечисленные сцены. В браузерной библиотеке Reunion эти сборки WIPI не запускаются. [Исходники использованной версии ARAM](https://github.com/mirusu400/aram-core/tree/fea299cba15696ed1460f965b76626d6edab5e03)

```sh
aram-debug lua -width 240 -height 320 -run-budget 200000 /path/to/original.zip /path/to/replay.lua
```

## LG SD9220

На зеркале Sunderland сохранился `SX601318 [Incomplete Memory dump].7z`. Он прошёл `7z t`, CRC32 извлечённого `SX601318_memory.bin` — `D792D3C1`. В 3 670 010 байтах образа найдены `QCOML` по смещению `0x20`, модель `LG-SD9220` по `0x22ad6a`, строка `.sgs` по `0x322f18` и надпись `GVM1X 콘텐츠` по `0x33e990`. Сканер проверил 266 097 возможных смещений, подтвердил 94 из 94 контрольных SGS и не извлёк контейнеров из этого образа. [Исходная папка зеркала](https://archive.sunderland93.ru/Firmwares/LG/SD9220/) · [Скачать сохранённый образ с отчётом](../research/archives/LG-SD9220-SX601318-Memory.zip)

В исторической таблице `SKT!201` для `SD9220(S600U)` указаны GVM 2.0 и SK-VM 1.1. Метка `GVM1X` в образе не даёт определить точный состав VM или восстановить скачанные приложения. [Таблица и исходные ячейки](../validation/gvm-historical-handset-guides.json)

Отдельно проверены пять одноимённых ZIP из Phonetones: SD460, SD840, SD870, SD910 и SD9210. В них 953 файла, включая четыре OMA DCF с типом `audio/x-mp3` и текстовый список звуков. В этих файлах SGS не найдены. Размеры, хеши и состав сохранены в отчёте. [Каталог Phonetones](https://3.onj.me/phonetones/zipped/LG/)
