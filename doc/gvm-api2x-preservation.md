# GVM API 2X и ранние публикации Sinjisoft

6 ноября 2026 года выполнен отдельный проход по `education/API2x/`
официального GVM Club. Из уже сохранённого публичного CDX выбраны
**109** исходных записей без изменения их полей.
Это раздел документации; он не подменяет полный сбор домена.

[Скачать комплект](../research/archives/GVM-API2X-and-Early-Sinjisoft-Patents.zip) — 788 659 байт.
SHA-256: `f76dea1860bb8ee1f07566e6d2baabae01c13ee0cc1f819a208dd81affc3b37c`.
[Проверка](../validation/gvm-api2x-preservation.json): 115
файлов, 114 проверенных записей манифеста, CRC совпал.

## Покрытие

Состояния выбранных задач: `{'mismatch': 1, 'verified': 108}`.
**89** совпавших ответов имеют имя `.htm`;
остальные совпадения — связанные изображения и другие ресурсы.
Три кадра HTML-меню сохранены отдельно и также совпали с CDX.
Неудачные ответы, их HTTP-заголовки и причины включены с исходным статусом.
Тайм-аут не назван исчезнувшим файлом.

Отдельно восстановлено **приложение A** по буквальной корейской ссылке
`부록 A.htm` из проверенного меню. Его путь в CP949 совпал с исходным
`urlkey`, а тело — с SHA-1 CDX. Общая очередь сохраняет исход неудачной
попытки по искажённому адресу; успешный запрос вынесен в
`evidence/api-menu-repair.json`, не скрывает первоначальную ошибку.

Меню ссылается и на страницы вне этой выборки. Получение 109 записей
не означает восстановление всех статей, всех версий документа или всех
API платформы. Корейские HTML и изображения сохранены исходными байтами;
страничный JavaScript не исполнялся.

## Первичные ранние публикации

Сохранены исходные корейские HTML и PDF
[KR20010095607A](https://patents.google.com/patent/KR20010095607A/ko)
и [KR100357663B1](https://patents.google.com/patent/KR100357663B1/ko).
Это две публикации **одной** заявки Sinjisoft от 11 апреля 2000 года,
опубликованные 7 ноября 2001 года и 25 октября 2002 года.

Оба PDF получены с HTTP200; проверены исходные хеши, заголовки PDF,
отсутствие шифрования и структурное чтение всех 31 страницы. Это сохранение
первоисточников, без оценки правового статуса или вывода о соответствии
их описаний конкретному бинарному ABI SGS.

## Происхождение и границы

`evidence/seed-provenance.json` содержит неизменённые записи CDX;
`captures.json` — результаты и способы запросов; `receipts.json` — URL,
UTC, HTTP-заголовки и хеш каждого полученного ответа. Сами исходные тела
находятся в хеш-адресуемых каталогах. Полные сырые страницы CDX относятся
к [отдельным согласованным снимкам](wayback-collection.md), а не к этому
узкому комплекту. Изображения и ошибки не подсчитаны как новые руководства.

Новых SGS, ранних SDK 1.20/1.40, GVM 1.52 или самостоятельного
телефонного GNEX-плеера в этом комплекте не установлено.

[Уточнение к списку зацепок в ZIP](gvm-technical-library-pass.md#уточнение-имени-sdk-140):
точное имя `GNEX_SDK_v1.40.exe` уже подтверждено исходной страницей;
неизвестным остаётся сам установщик. Неизменяемый старый ZIP не заменён.
