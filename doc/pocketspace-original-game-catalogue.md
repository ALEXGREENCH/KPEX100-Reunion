# Игры PocketSpace и ролик New Pocket Baseball 3

Из архивных снимков восстановлены восемь карточек каталога PocketGame.net за декабрь 2002 года. В комплект вошли 38 исходных ответов, в том числе пять GIF из карточки и руководства «Приключений Синдбада». Для 19 HTML-ответов независимо проверен SHA-1 из CDX. Остальные сверены по HTTP-метаданным снимка и локальному SHA-256. ## New Pocket Baseball 3

Оригинальный `npb.swf` из снимка 26 мая 2005 года восстановлен из трёх ответов HTTP. Перекрытие двух диапазонов совпало побайтно. Полный размер **5 794 155 байт**, SHA-1 совпал с CDX. В SWF v6 сохранились заставка, видеоряд и звуковая дорожка. Заставка прямо объявляет GNEX-версию **New Pocket Baseball 3**. Из видеопотока извлечены кадры турнирной таблицы и матча. Исходный SWF лежит в `originals/`, производные PNG в `previews/`. [Снимок SWF](https://web.archive.org/web/20050526113912id_/http://www.pocketspace.co.kr:80/ad/pbb3/npb.swf)

В Reunion уже доступен [Pocket Pro Baseball3 в формате SGS v2](compatibility.md). Ролик подтверждает отдельное объявление GNEX-версии, но в исследованной подборке её исполняемый файл не найден. В восьми пробах по точным адресам JAR из дескрипторов LGT Wayback не указал снимков.
