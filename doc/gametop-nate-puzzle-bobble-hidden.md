У последнего ответа сохранены исходные параметры перехода. В индексе Wayback для точного URL назначения строк нет. Фильтр расширений SGS/JAR/DAF/WML/DD/BIN на хосте mPlayOn в 2002–2007 годах тоже дал пустой ответ. Отдельный фильтр `application/*` дал восемь записей, в них один путь CSS и редиректы примеров JSP и Servlet. Поиск по подстроке ID завершился тайм-аутом. Две отдельные попытки через Wayback Availability вернули HTTP 429. Версия игры по этой карточке не установлена.

Сканер подтвердил 94 из 94 контрольных SGS и не нашёл контейнеров в WML. Отдельный проход по 686 новым для сканирования телам из текущей очереди GNEX Club, GVM Club, Sinjisoft и связанных сайтов также не дал SGS. Скачанные WML сохраняют точку перехода и состояние сервиса в конкретные даты.
