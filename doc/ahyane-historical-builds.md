# AHYANE: исторические сборки GNEX

[репозитория автора](https://github.com/kosooyoul/gnex-dating-simulation-game)
сохранены **13 различных SGS-сборок одного проекта**, а не 13 отдельных игр.

`bin/integral.sgs`. Все 13 бинарников имеют **GNEX v4**; их байты не менялись.

## Что проверено и что пока не работает

Семь контейнеров `COMPTYPE 0` проходят статический строгий парсер Reunion.
Это не проверка полной играбельности. Для `dcc55fcf` отдельный исследовательский
проход увидел титульное меню в телефонном профиле **240 × 280**; сценарий
завершился `idle` без ошибки после 219 событий. Переход Continue с удержанием
клавиш привёл к чёрному игровому экрану. Полная игра не подтверждена; статус
остальных исторических сборок из этого наблюдения не выводится.

## Запуск исходного сжатого SGS

В руководстве компилятора `COMPTYPE 2` указан для SKT WIPI. У всех
шести сборок AHYANE после первых 18 байт медиаданных идёт один поток
zlib, затем байт `FF`. Смещение медиаданных хранится по `0x54`, размер
распакованного тела по `0x6c`, размер исходного тела по `0x78`.
У последней сборки zlib начинается на 80 050, на выходе 751 472 байта.
Размер полного тела 831 522 байта, таблица описывает 941 ресурс.
[Руководство и заголовки SDK](gnex-sdk-internal-sources.md).

Веб-версия распаковывает данные в памяти и затем проверяет таблицу
ресурсов. Сканер прошивок извлекает исходный сжатый контейнер. У всех
шести файлов распакованные хеши совпали между Python zlib и
декодером веб-ядра. Поддержка подтверждена для этой раскладки v4.

В библиотеку включён побайтно неизменённый `bin/ahyane.sgs` из коммита
`f40efc1f`. В профиле 240×280 удержание Z продвигает реплики пролога,
а Continue открывает карту. При удержании → карта сместилась за 240 мс.
Контрольный кадр за то же время сохранил прежнюю позицию.
[Исходный коммит](https://github.com/kosooyoul/gnex-dating-simulation-game/commit/f40efc1fc90e39dbf12a24235fc589aa142b98b5),
[хеши и сценарии](../validation/ahyane-compressed-gameplay.json).

В `src/main.mc` есть условная ветка `_GVM` с объявлением `SCRIPTVER 2`.
**Скомпилированной GVM2-версии в этой подборке нет.** Имена, Git-даты и
целые поля заголовков не интерпретировались как даты компиляции.

CRC внешнего ZIP и хеши всех 17 файлов манифеста проверены после чистой
распаковки. Упакованный bundle восстановлен в новый bare-репозиторий:
`git bundle verify` и `git fsck --full` пройдены, 31 коммит и HEAD совпали.
Все 13 SGS побайтно равны `git show commit:path` как в первичном клоне,
так и в восстановленной истории; Git blob SHA-1 пересчитаны независимо.
Сборки в архиве взяты из истории Git. Современная Windows и
работоспособность редакторов не проверялись.
Сохранения и сырые трассы в комплект не включены. Лицензия Reunion
не распространяется автоматически на исторические материалы автора.
