# Следующий проход по игровым архивам плееров

5 ноября 2026 года проверены оставшиеся неоднозначные имена в двух
публичных каталогах производителя и уточнена зависимость загрузчика MyRacer VGN.
**Новых принятых SGS нет.** Сами исследовательские загрузки в репозиторий
не добавлены. [Источники, хеши и адреса инструкций](../validation/player-game-hunt-followup.json).

## Grundig: семь неоднозначных архивов

Исходные каталоги:
[Download.UsageManuals](https://download.arcelik.com.tr/Download.UsageManuals/) и
[Download.UsageManualsBeko](https://download.arcelik.com.tr/Download.UsageManualsBeko/).
Ранее в них выделены 577 ссылок с архивными расширениями.

**570 ссылок отсеяны только по именам**: названиям бытовой техники,
руководств и повторяющимся обозначениям таких руководств. Их содержимое
не скачивалось. Это не проверка всех 577 архивов на отсутствие игр.

Оставшиеся семь имён проверены отдельно:

| Архив                      | Получено                     | Результат                                                           |
| -------------------------- | ---------------------------- | ------------------------------------------------------------------- |
| `31471_New-folder-(2).zip` | 1 829 905 байт               | Две PDF-инструкции B 9476                                           |
| `7693_1_12.7z`             | 3 404 048 байт               | Четыре PDF-инструкции TSM1541A++                                    |
| `7693_1_Kılavuzlar20.zip`  | 3 901 570 байт               | Те же четыре PDF                                                    |
| `7693_Kılavuzlar20.zip`    | 3 901 570 байт               | Побайтный дубликат предыдущего ZIP                                  |
| `Cisco314.zip`             | 9 666 052 байта              | Один установочный DMG Cisco AnyConnect                              |
| `Cisco3_14.zip`            | 9 666 052 байта              | Побайтный дубликат предыдущего ZIP                                  |
| `Cisco.zip`                | Только последние 65 536 байт | Центральный каталог: четыре каталога, пять DMG и два MSI AnyConnect |

Полностью получены **шесть архивов, четыре уникальных SHA-256**.
Пять ZIP прошли проверку CRC всех записей; 7z прошёл проверку `7z t`.
Для `Cisco.zip` сервер вернул HTTP 206 с диапазоном
`37592469–37658004/37658005`. Все 11 записей центрального каталога
разобраны, но полезные данные и их CRC не проверялись. Установщики
не запускались и не исследовались как игровые контейнеры.

Нового пакета плеера среди этих семи имён не обнаружено. Диск VP1000
**759540666100** остаётся ненайденным, наличие GNEX на VP1000 не доказано.
Предыдущие границы поиска сохранены в
[отчёте о маршруте Grundig](../validation/grundig-directory-route-evidence.json).

## MyRacer Sketcher VGN: откуда берутся четыре байта ключа

Ранее полученный [файл из публичного поста Halfstudy](https://cafe.naver.com/halfstudy/1949)
`clubzio_sketcher.vgn` имеет 939 698 байт и SHA-256
`ced8ba4961e2c57b9af644a06577adfedf3918852f1a3d446514f85812bd0318`.
Он сохранён без изменений. Анализ выполнен по `ROM_EXEC` из
[обновления MyRacer от мая 2008 года](https://cafe.naver.com/myracer/4921):
3 030 408 байт, SHA-256
`1e83c0ebf7afc01f9b483384b63c0e819ec1a972d476679086e59c63ad6d4a9a`.

Статически прослежена следующая цепочка ARM-кода:

| Адрес                   | Действие                                                                                             |
| ----------------------- | ---------------------------------------------------------------------------------------------------- |
| `0x0805984c`            | Ветка расширения `vgn` вызывает `0x0809a368`                                                         |
| `0x0809a368–0x0809a370` | Возвращается слово из RAM `0x086bb948 + 0x10`                                                        |
| `0x0809b310–0x0809b314` | После успешного чтения конфигурации слово из буфера `+0x58` записывается в эту RAM-ячейку            |
| `0x08099f00`            | Чтение конфигурации через NAND-контроллер `0x0021d000`                                               |
| `0x08099f4c–0x08099f5c` | В прослеженной ветви для страниц 2048 байт передаётся адрес `0, 0` для чтения первой страницы данных |
| `0x0809bf08–0x0809bf34` | Формируется восьмибайтный ключ: литерал `TPSP` и четыре байта вызывающей стороны                     |
| `0x08059928–0x08059968` | Ненулевое слово выбирает эту конфигурируемую ветку; нулевое — фиксированную ветку XGN                |

Таким образом, дополнительное значение поступает из **NAND-конфигурации**,
а не задано константой в исследованной ветви `ROM_EXEC`. Для проверки VGN
нужен настоящий конфигурационный сектор соответствующего устройства или
сборки, включая слово по смещению `0x58` в данных первой страницы.
Произвольный дамп другого аппарата не гарантирует подходящего значения.
Сам пост Halfstudy не доказывает, что этот файл предназначен именно для MF101.

В ROM также есть строка `nf:1:\flashkey.bin`. Её связь с указанным словом
не установлена; она не объявляется найденным источником ключа.
Ранее проверенный фиксированный ключ XGN не принял хвост этого VGN.
Две каталожные версии Sketcher имеют другие размеры: 593 340 и 508 442 байта.
Они не заменяют отсутствующий заголовок файла на 939 682 байта полезной нагрузки.

Ключи не перебирались, заголовок SGS не подменялся, игровая логика и
установщики не запускались. Расшифрованный SGS и работоспособность этого
VGN пока не получены. [Существующий распаковщик XGN](../tools/unpack-myracer-xgn.py)
поддерживает только уже подтверждённую фиксированную ветку.
