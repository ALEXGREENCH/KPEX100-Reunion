# Три игры IntroMobile на Samsung Anycall

Три оригинальных MBIN из Anycall Land дошли до игрового процесса в локальном Thumb-хосте. В каждом случае сравнивались два прогона с одинаковым числом тактов и показов кадра. [Кадры и манифесты](../research/archives/Samsung-Anycall-IntroMobile-Replays.zip) · [Исходные игры](../research/archives/Samsung-Anycall-ADS-MBIN.zip) · [Публикация с вложениями](https://m.blog.naver.com/sendei333/222605737137)

| Игра                                        | Что видно при вводе                             | Кадр | Изменённые пиксели |
| ------------------------------------------- | ----------------------------------------------- | ---: | -----------------: |
| Hungry Hunter                               | Код 2 поднимает прицел на первом уровне         |  137 |              1 245 |
| Love Love Ppyong Hammer (`러브러브 뿅망치`) | Код 10 меняет ход поединка, виден удар молотком |  151 |              5 626 |
| Oh My Head                                  | Код 10 сдвигает фигуры влево после экрана START |  283 |              1 667 |

В меню всех трёх игр работает код 19. Точный порядок событий, SHA‑256 исходных MBIN и кадров, а также смещения 164 записей MQ указаны в манифестах. Ранний экран загрузки и некоторые надписи появляются из исходных спрайтов. Часть текста меню вызывается через отдельную службу `+0x5c` и пока отсутствует. Другие заглушки перечислены в манифесте каждой игры. Палитра RGB332 пробная. Звук, сохранения и прохождение целиком не проверены.

```sh
python -m pip install unicorn==2.1.4 Pillow==13.0.0
python tools/replay-anycall-jumping-baby.py research/archives/Samsung-Anycall-ADS-MBIN.zip hungry-hunter-replay --game hungry-hunter
```

Для остальных игр укажите `--game love-love` или `--game oh-my-head` и отдельную папку вывода. Можно передать соответствующий MBIN вместо ZIP. Перед исполнением инструмент сверяет SHA‑256.
