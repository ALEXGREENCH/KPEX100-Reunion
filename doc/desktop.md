# Настольная версия

Исходники находятся в [`desktop/`](../desktop/README.md). Python исполняет модели
периферии и окружение GNEX, Unicorn — оригинальный ARM-код Kingston 2.12.
Tk отображает снимки framebuffer, а отдельный поток владеет состоянием машины.

## Границы совместимости

Нативные проверки охватывают четыре K-PEX SGS: Hell Fire, KPetris Beta, Ikaria ep2,
Godori. Зафиксированы игровые сцены и реакция на ввод, а не прохождение всех уровней.
Прямой режим принимает SGS v4/v36, но это не означает совместимость с телефонными
играми. Телефонные профили, старый SGS v1/v2 и интеграция Swerve развиваются в
веб-ядре.

В полном режиме Kingston 2.12 проходит холодную загрузку, показывает исходное
меню, читает FAT16 и запускает Hell Fire через гостевой файловый менеджер.
USB, SD, RTC, физический аудиокодек и точное время ARM остаются неполными.
Остальные версии ROM имеют экспериментальный статус.

## Управление

| Клавиша   | Кнопка / действие                                 |
| --------- | ------------------------------------------------- |
| Стрелки   | Направления                                       |
| Z         | SELECT / A                                        |
| X или Esc | ESC / B                                           |
| Enter     | PLAY                                              |
| Tab       | MENU                                              |
| C / V     | MODE / REC                                        |
| F5 / F6   | Продолжить / пауза                                |
| F10       | Одно событие SGS или одна ARM-инструкция прошивки |

Z/X/C/V поддерживают русскую раскладку. Для Hell Fire нажмите PLAY на заставке;
в KPetris выберите Start кнопкой A. В Ikaria и Godori дождитесь окончания вступления.
Короткие нажатия в полном режиме сохраняются до опроса клавиатуры гостевой прошивкой.

В прямом SGS-режиме сохранения находятся в `desktop/saves/<SHA-256>.json`.
В полном режиме изменения виртуального диска входят в сохранённое состояние
машины. Сброс исполнения не удаляет игровые сохранения. Пользовательские
сохранения не входят в Git. Исходная коллекция ROM/SGS и контрольных состояний
включена в `web/`; первый запуск автоматически готовит из неё настольную библиотеку.

## Командная строка

Выполняйте команды из `desktop/`, используя Python установленного окружения:

```sh
python launch.py --rom /path/to/Kingston-2.12.rom --game /path/to/hell_fire.sgs
python -m kpex --help
python launch.py --self-test build/native-smoke.json
```

`--self-test` не открывает окно и не требует ROM. Он исполняет синтетическую ARM-
инструкцию в главном и рабочем потоках. `--self-test-originals` вместе с
`--self-test` проверяет также четыре импортированные игры и доступные контрольные
состояния Kingston 2.12. Неполный JSON после аварийного завершения процесса остаётся
диагностическим свидетельством, а не успешным результатом проверки.

## Windows-сборка и загрузчик

[`desktop/build.ps1`](../desktop/build.ps1) создаёт окружение и устанавливает
зависимости из фиксированных `requirements*.txt`. Стандартный загрузчик
PyInstaller на Windows может включать Control Flow Guard, несовместимый с возвратами
из динамически сгенерированного ARM-транслятора Unicorn. Поэтому
[`prepare_bootloader.py`](../desktop/tools/prepare_bootloader.py) проверяет PE-флаги
и при необходимости пересобирает **только загрузчик** с поддерживаемым параметром
`--no-cfg`. Настройки защиты Windows не меняются.

См. [официальное руководство PyInstaller](https://pyinstaller.org/en/stable/bootloader-building.html)
и [обсуждение совместимости Unicorn](https://github.com/pyinstaller/pyinstaller/issues/9352).
Для первого такого запуска нужен C++ toolchain: MSVC Build Tools либо LLVM-MinGW.
Запуск `python launch.py` не требует компилятора или PyInstaller.

Скрипт `build.ps1` автоматически подготавливает коллекцию из `web/`, переносит её
в `build/package/data` и проверяет игры в собранном EXE, а не только исходный Python.
Сборка проверена с Python 3.11 и 64-битным LLVM-MinGW. Вывод и временные файлы
попадают в `desktop/build/`, исключённый из Git.

## Звук

В точном режиме Kingston 2.12 принимает звуковые подтипы 7/8. MP3-ресурсы Godori
воспроизводятся через Windows; подтипы 0/1/2 исходный адаптер игнорирует.
Необязательная настройка SMAF добавляет приближённый FM-синтез для Ikaria.
Это расширение совместимости, а тембры не являются дампом Yamaha ROM.

```sh
python tools/build_smaf.py
```

Команда требует `clang++` из LLVM-MinGW и собирает `desktop/bin/smaf-render.exe`
из общего Apache-2.0 исходника `vendor/yamaha-smaf-player/`. `build.ps1 -WithSmaf`
выполняет её автоматически и включает декодер в EXE. По умолчанию опция SMAF
выключена. При отсутствии декодера интерфейс сообщает об этом; остальные режимы
продолжают работать. MP3/WAV декодируются штатными средствами Windows.

сразу после клонирования.
