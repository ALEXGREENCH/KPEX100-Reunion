# Jumping Baby на Samsung Anycall

Оригинальный `점핑!_베이비.mbin` загрузил 89 записей графики MQ и отрисовал заставку, меню, подсказку управления и начало уровня. Сравнили два прогона на одной и той же 85-й подаче кадра. В обоих выбрали New Game. В одном затем нажимали 7, в другом оставили игру без ввода. После прыжка отличаются 150 пикселей. [Кадры и манифест](../research/archives/Samsung-Anycall-Jumping-Baby-Replay.zip) · [Исходный архив Anycall Land](../research/archives/Samsung-Anycall-ADS-MBIN.zip) · [Публикация с вложениями](https://m.blog.naver.com/sendei333/222605737137)

Тело MBIN начинается по смещению `0x109`. Инструмент отображает его в память Unicorn по адресу `0xf4000000`, а гостевые глобальные данные — по `0xf5000000`. Игра получает таблицу функций при событии 0, принимает кнопки при событии 4 и обновляет состояние при событии 5. В меню код 13 передвигает выделение вниз, а 19 подтверждает выбор. Подсказка в самой игре показывает 7 для прыжка.

Хост подставляет буфер 120 × 128 и декодирует MQ на вызове `+0xb0`. Блиттер `+0x70` пишет в ту же память, которую оригинальный код использует при копировании фона. Палитра RGB332 пробная. Шесть вызовов хоста остаются заглушками. Игра также запускается из веб-библиотеки. [Управление в браузере](samsung-anycall-ads-mbin.md#запуск-в-браузере).

```sh
python -m pip install unicorn==2.1.4 Pillow==13.0.0
python tools/replay-anycall-jumping-baby.py research/archives/Samsung-Anycall-ADS-MBIN.zip jumping-baby-replay
```

Инструмент также принимает отдельный MBIN и проверяет SHA-256 оригинала перед исполнением. [Код воспроизведения](../tools/replay-anycall-jumping-baby.py) · [Хеши кадров и ресурсов](../validation/anycall-jumping-baby-replay.json)
