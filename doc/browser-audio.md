# Звук браузерной сборки

[Ранний зуммер GVM](gvm-buzzer-audio.md) также обрабатывается отдельным
аудио-Worker: частоты и длительности сверены с SDK, тембр динамика приближён.
Raw MA1 остаётся неподдержанным; он не смешивается со SMAF.

Прямой запуск SGS использует звуковые запросы оригинального интерпретатора. MP3 и PCM WAVE декодирует Web Audio. Для телефонного профиля SMAF/MMF передаётся отдельному Web Worker, который запускает WebAssembly-сборку [Yamaha SMAF Player](https://github.com/akustikrausch/yamaha-smaf-player) Андреаса Вендорфа, commit `627f7ad8583ce34c5fec0269ef9778167af080d6`, Apache-2.0.

Синтезатор воспроизводит события и загруженные инструменты SMAF. Встроенные стандартные FM-тембры приблизительны: это не дамп тембров оригинального Yamaha MA. Режим K-PEX сохраняет прежнюю обработку подтипов, которую проверяют тесты оригинальной прошивки.

Поддерживаются пять независимых каналов GNEX (`PlaySoundEx`), индивидуальная громкость, общая и поканальная остановка, пауза и продолжение. Флаг `0x8000` в телефонном звуковом ресурсе включает повтор. Контекст Web Audio открывается после действия пользователя. Остановка или смена игры отменяет ещё не завершённое декодирование; поздний результат не запускает старую мелодию.

Ограничения загрузчика: входной SMAF до 4 МиБ, выход до трёх минут на запрос, кеш PCM до 32 МиБ на используемый канал. При достижении ограничения длины интерфейс записывает это в журнал. Синтез работает отдельно от интерфейса и ARM-потока; исходные звуковые ресурсы не преобразуются в составе каталога.

## Воспроизводимая сборка

Готовые `web/engine/vendor/smaf.mjs` и `smaf.wasm` включены в сборку. Для пересборки нужны Python 3.11+ и Emscripten 3.1.64. Активируйте окружение emsdk (или задайте его `EM_CONFIG`), затем выполните из корня репозитория:

```sh
python tools/build-smaf.py --emcc /path/to/emsdk/upstream/emscripten/em++.py
# Аудиопроверки используют включённые оригинальные SGS:
node --test tests/smaf.test.mjs tests/browser-audio.test.mjs
```

Используется веб-окружение Emscripten `web,worker`. Тесты Node передают `wasmBinary` явно; браузер загружает соседний `smaf.wasm`. Сборка с `worker,node` в этой версии Emscripten добавляет импорт Node `module`, непригодный для браузерного Worker.

Проверка первой SMAF-дорожки Sketcher .2inch дала 453 176 стереокадров при 44 100 Гц. Независимый нативный C++ рендер дал ту же длину; максимальное расхождение 16-битного PCM — 1, среднеквадратическое — 0,0133. Это проверка переносимости синтезатора, а не сравнение с записью настоящего телефона. Данные проверки: [smaf-web.json](../validation/smaf-web.json).

Исходный музыкальный ресурс 27 Independence Day 3D использует старый контейнер
`MMMG/VOIC/EXVO/SEQU`, который upstream-загрузчик пропускал. Локальный патч
читает эти блоки и события, включая изменения громкости `0x36`, сохраняя
20 мс на шаг последовательности. После исправления неизменённый ресурс
декодируется в 38,206 с PCM; тест Sketcher остаётся прежним.
[Происхождение и ограничения патча](../vendor/yamaha-smaf-player/PATCHES.md),
[результаты проверки](../validation/smaf-independence.json).

Звуковые эффекты Independence 29–33 используют разные сэмплы `Mwa1` при одной
и той же последовательности нот. Исправлены трёхбайтовый заголовок mono ADPCM
и назначение StreamPCM по банку 125: теперь звучат пять разных исходных
сэмплов, которые заканчиваются по своей длине. Ранее все пять превращались
в один длительный FM-тон. Регрессионный тест проверяет различие PCM и
окончание слышимой части; другие непроверенные форматы Mwa не расширялись.
