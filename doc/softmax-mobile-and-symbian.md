# Softmax, m4leaf и проверка архива Symbian 6/7

Сохранены страницы Softmax и m4leaf, пакет Magna Carta M для KTF и результаты
проверки отдельного архива Symbian. [Скачать комплект](../research/archives/Softmax-Mobile-and-Symbian-6-7-Game-Search.zip).
[Размеры, хеши и результаты](../validation/softmax-mobile-s60-audit.json).

## Первая Crow

В [записи семинара 4 июля 2003 года](https://4leafmemorial.tistory.com/1014)
геймдизайнер 정재한 говорит о GVM для версии SKT и отдельно сравнивает её
с версией KTF. Он также называет свои предыдущие проекты для GVM, Eternal
Ranger 1 и 2 и Stormbringer. Это зацепки по названиям, без файлов сборок.
В [публичном сообщении 2018 года](https://cafe.naver.com/gnssantaria/7284)
автор вспоминает разработку серии в GVM, Java и BREW.

У Softmax сохранились два объявления о тестировании Crow. В одном указаны
номера 011/017, в другом 016/018. Второе объявление ведёт на страницу
`/2002/m4leaf_crow.php`. Её ссылка `4leaf_check.php` открывает форму входа
4LEAF, а полученное тело совпадает по SHA-1 с семью записями CDX.
Все 75 записей в ограниченном индексе главной m4leaf содержат SHA-1 пустого
тела. Запросы по каталогу `/2002/` завершились ошибками сети и HTTP 503.
[Тест 011/017](https://web.archive.org/web/20030819221302id_/http://softmax.co.kr/news/view.php?tbl=notice&uid=60&main=1),
[тест 016/018](https://web.archive.org/web/20030819221018id_/http://softmax.co.kr/news/view.php?tbl=notice&uid=61&main=1),
[снимок формы](https://web.archive.org/web/20030803073823id_/http://www.m4leaf.net/2002/m4leaf_crow/4leaf_check.php).

Речь о первой Crow. [Релиз Softmax о Crow 2](https://www.newswire.co.kr/newsRead.php?no=65491)
отдельно называет её продолжением. Первая часть пока остаётся целью поиска
для SKT. Проверенные снимки, включая публичное объявление Daum о запуске
магазина, сохранены вместе с квитанциями.

## Magna Carta M для KTF

Получен [ZIP из Brewgames](https://m.blog.naver.com/brewgames/223944569645)
размером 142 836 байт. Проверены CRC всех десяти файлов, включая `7799.mif`,
`mac.bar`, `mac.sig`, ресурсы и 152 004-байтный `mac.mod`. Начало
`mac.mod` разбирается как ARM, а внутри есть строки Softmax и MagnaCarta.
В проверенных файлах SGS не обнаружен. Этот пакет сохраняется как версия
BREW для KTF. [Объявление о выпуске для SKT](https://www.gamemeca.com/view.php?gid=49128)
помогает искать отдельную операторскую сборку, формат которой ещё предстоит
подтвердить по байтам.

## Аудит Symbian 6/7

Полный [исходный 7z](https://archive.org/details/symbian-6-7-games.-7z)
занимает 239 683 863 байта. SHA-1, MD5 и CRC32 совпали с метаданными
Internet Archive. 7-Zip проверил и распаковал 1 043 файла. В SGS-аудите
прочитаны 1 026 файлов и сверены их CRC. Из проверки SGS исключены 17
Windows EXE. Первая попытка распаковки через py7zr остановилась на BCJ2,
для распаковки использован 7-Zip.

Парсер обработал 426 из 431 вхождения SIS. Проверены 10 586 извлечённых
полезных нагрузок, 351 вложенный ZIP и четыре RAR. Пять отказов SIS и
неразобранные контейнеры перечислены в отчёте. 79 SGS из библиотеки
использованы как контроль для ускоренного сканера.

Пять найденных SGS-вхождений совпали с тремя сохранёнными играми:
Aiolos Fighter, Pocket Baseball 2 и Pocket Golf. Отдельно скачанные три
SIS и два APP также совпали с оригиналами в
[прежнем комплекте S60](../research/archives/Sinjisoft-S60-Runtimes-Recovered.zip).
Полный 7z остаётся доступен у источника. Новый ZIP содержит отчёты,
манифесты и инструкции для повторной проверки.
