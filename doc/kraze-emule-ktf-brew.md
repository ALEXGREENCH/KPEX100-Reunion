# Коллекция ранних игр KTF от Kraze

Internet Archive опубликовал подборку ранних игр KTF, найденных Kraze в сети eMule. Сохранён исходный ZIP размером **49 081 055 байт** с корейским именем файла. SHA-1, MD5 и CRC32 совпали с метаданными публикации. Архив скачан диапазонами HTTP 206. В комплекте сохранены метаданные, заголовки ответов и SHA-256 каждого диапазона. [Исходная публикация](https://archive.org/details/ktf.....game..qpst.) · [Скачать комплект](../research/archives/Kraze-eMule-KTF-BREW-Original-Collection.zip) · [Реестр файлов](../validation/kraze-emule-ktf-brew.json)

## Игровые модули

Проверены CRC всех **249 файлов** исходного ZIP и **1 609 вложенных файлов**, доступных при обычном чтении ZIP, RAR и ALZ. Среди 134 разных MOD у **78** нет совпадения в проверенной выборке. В выборку вошли прямые файлы 118 опубликованных архивов, модули из 651 вложенного пакета и отдельная сверка с 357 читаемыми пакетами Dubigame. Совпали 12 разных SHA-256 внешних пакетов. [Отдельная коллекция Dubigame](dubigame-ktf-brew-358.md)

Среди модулей без совпадений есть Bubble Bobble (`bubblebobble.mod`), 2004 Pro Baseball (`baseball2004.mod`), N Tetris (`ntris.mod`) и Romance of the Three Kingdoms Plus (`jrsamp.mod`). Число модулей учитывает разные сборки одной игры. Полных SGS и пакетов с дескрипторами KTF WIPI в проверенных файлах не обнаружено. Модули BREW проверялись статически.

## Неполные архивы

- **Super Robot Tactics 3** (`슈퍼로봇택틱스3`, приложение 7245). Вложенный ZIP обрывается внутри `srobo3.mod`. Пять предшествующих файлов прочитаны и сверены по CRC. Все 57 681 байт обрезанного файла побайтно совпали с началом полного ZIP из Dubigame. Его восемь файлов прошли проверку CRC. Полный экземпляр вынесен в `references/` с указанием происхождения.
- **QPST**. Из пяти исходных томов ALZ прочитан один файл `QPST.exe` размером 8 260 950 байт. Размер и CRC совпали с заголовком ALZ.
- **PhoneManager 1.2**. Заголовки сохранившихся томов имеют номера 0 и 2. Тома 1 нет, а имеющихся данных недостаточно для восстановления установщика.

Установщики оставлены внутри исходных томов. Проверка выполнялась без их запуска. [Исходный код формата многотомных ALZ в UnAlz](https://sources.debian.org/src/unalz/0.65-7/UnAlz.cpp)
