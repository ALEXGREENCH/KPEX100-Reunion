# Marine Blues для KTF и ещё семь телефонных игр

В ZIP из публикации Dubigame о **Marine Blues** сохранена сборка KTF `PD004766`, `01.00.03`. В `01036830.jar`, внутри `client.bin29220`, по смещению `0x2a72c` лежит целый SGS v4 размером 790 562 байта. Извлечённый файл совпал с соответствующим диапазоном байтов нативного файла. Контейнер распознаётся напрямую, у него 592 ресурса. В каталоге Reunion эта версия получила отдельную карточку **Marine Blues (KTF, 240×320)**. У ранее сохранённой версии `0056806663.sgs` другой хеш и 570 ресурсов. [Вложение Dubigame](https://dubigame.tistory.com/428)

[Исходные пакеты, извлечённый SGS и прогоны](../research/archives/Dubigame-Marine-Blues-KTF-and-Seven-Games.zip) · [Хеши и происхождение](../validation/dubigame-marineblues-ktf.json)

## Запуск SGS

Проверен телефонный профиль 240×320, совпадающий с полем `DisplaySize` исходного пакета. Оригинальный SGS прошёл меню, вступление, карту и первый уровень. На одинаковом виртуальном времени в первом уровне стрелка вправо сместила персонажа. Между кадрами с вводом и без него различаются 550 пикселей. Клавиша `6` дала такой же кадр, клавиша `5` тоже меняет изображение игры.

На воспроизводимом пути к первому уровню запуск остановился по бюджету события `TIMEOUT` при 20, 25 и 40 млн единиц блочной работы. При 60 млн сценарий дошёл до первого уровня и выдержал проверку управления. Этот лимит задан в профиле KTF-сборки. Прогон использует порядок событий планировщика и виртуальные интервалы. Частота кадров в реальном времени по нему не измерялась.

```sh
node tools/replay-sgs.mjs marineblues-ktf validation/marineblues-ktf-actions.json
```

Чтобы повторить извлечение, откройте `01036830.jar` из ZIP, сохраните его член `client.bin29220` и запустите сканер. Полный SHA‑256 извлечённого файла начинается с `3aa0596a83b763e0`. В отчёте записаны смещение, длина и оба хеша.

```sh
python tools/scan-firmware-games.py --check-controls --extract extracted client.bin29220
```

## Исходные операторские сборки

У всех восьми ZIP проверены CRC внешнего архива и каждого члена вложенного JAR. Хеши вложений впервые появились в архиве Reunion. В семи остальных вложениях структурный поиск не подтвердил SGS. Сами WIPI и Raptor пакеты проверялись отдельно в ARAM `fea299c`. Полные прохождения не проверялись.
