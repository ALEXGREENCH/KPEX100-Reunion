# 23 пакета KTF WIPI из Palletshipping

Сохранены 23 исходных вложения Naver с 22 различными JAR. В комплекте есть Bubble Bobble Premium, Bubble Bobble 2, три сборки MapleStory, Raiden III, Tengai, Action Hero 3D: Wild Dog и Penoa Chronicles 2. Для каждого вложения сохранены страница, заголовки ответов, квитанция загрузки и хеши. Проверены CRC внешнего ZIP и вложенного JAR. Сканирование этих пакетов не обнаружило целых SGS. [Скачать комплект](../research/archives/Palletshipping-23-KTF-WIPI-Packages.zip) · [Список пакетов, хеши и прогоны](../validation/palletshipping-23-ktf-wipi.json)

## Запуск в ARAM

В 22 прогонах получены все шесть кадров короткого сценария. **Epic Chronicle PE** показала стартовый экран и остановилась на кадре 609 после первого нажатия OK с ошибкой `invalid application machine state`. В архиве сохранены исходный пакет, снимок и журнал остановки. Из десяти парных сравнений семь дали различие на одинаковом виртуальном кадре. Оба дескриптора называют игру `물가에돌튕기기3`, указывают продукт `PD005691` и версию `01.00.04`. Различается AID, `010100D2` и `01037E36`. В обоих пакетах байты JAR и всех 115 его файлов совпадают.
