# Сверка целей прошивок: LG, SKY, Pantech/Curitel и VK

5 ноября 2026 года сверены **98 положительных строк XLS** 2003 года и **31 карточка GNEX Zone** выбранных производителей с пятью сохранёнными каталогами прошивок. Это **129 наблюдений источников**, а не 129 разных телефонов: таблица сохраняет операторские варианты, обновления и повторы моделей из карточек.

[Полный ledger: строки, ячейки, URL, размеры, хеши и границы](../validation/firmware-target-join-round5.json). Исходные [исторические таблицы](gvm-historical-handsets.md) и [52 карточки GNEX Zone](gnex-zone-complete-profiles.md) остаются раздельными источниками.

В пяти снимках каталогов разобраны **1 100 ссылок на каталоги первого уровня**. По полному поисковому ключу и группе производителя найдены **24 каталога-кандидата** для **34 наблюдений**; у остальных **95 наблюдений** такого совпадения нет. Последнее число не означает 95 разных отсутствующих прошивок и не доказывает отсутствие файлов в других местах.

## Уровни доказательств

- Строка XLS/карточка подтверждает указанное в ней значение VM для своего обозначения устройства.
- Совпадение имени с каталогом — адрес для дальнейшего поиска. Оно не устанавливает содержимое или полноту ROM.
- Ссылка на архив из полученной страницы — наблюдение листинга, без проверки полезных данных по сети.
- Локальный файл с тем же полным именем дополнительно пересчитан по размеру и SHA-256. Это кандидат по имени; побайтное совпадение с файлом по URL в этом проходе не заявляется.

Записаны **14 обращений** к подкаталогам/страницам поддержки: получены 12 страниц, две попытки завершились сетевыми ошибками. Для SD1100 после первой ошибки есть отдельный успешный ответ; IM-5400 остаётся timeout именно этого обращения. **11 различных локальных архивов-кандидатов** пересчитаны по SHA-256. Новые архивы прошивок, SGS и результаты сканирования в этом проходе не добавлены.

## Как исключены ложные новые загрузки

Для LG SD200 полученный листинг предлагает `SX40W339_memory.7z`, который уже имеется среди входов предыдущего исследования. Для SD1200 аналогично найден прежний `SD120I05.7z`. Их локальные размеры и SHA-256 пересчитаны; повторной загрузки ради нового счётчика не было. Старая эвристика по подстроке имени могла пропустить такие файлы: имя архива содержит номер сборки, а не обязательно модель папки.

В `validation/firmware-target-join-round5.json` все исходные обозначения сохранены буквально. Поисковая нормализация убирает пробелы, дефисы, префикс LG/SKY и текст после первой скобки только для поиска каталога. Она не объединяет серийные варианты: IM-5000 Worldcup/WI-TOP не становится доказанным одним базовым дампом; Upgrade не объявляется конкретной редакцией ROM.

Не объединены автоматически VK-100M/VK100, VK-200C/VK200, PG-S5500C/PG-S5500, SK/IM и варианты CX-300A/V/Dv. Отдельное доказательство внутренней маркировки в другом отчёте может объяснять конкретный файл, но общий join не переносит его на все строки и сборки.

## Дополнительные маршруты и оставшиеся цели

Страница `lg-firmwares.com/lg-sd340-firmwares/` вернула HTTP 200; прямой ссылки на архив в полученном HTML не наблюдалось. Это не проверка всех страниц сервиса или результата исполнения JavaScript. В возвращённых метаданных одной коллекции Internet Archive `im-s-550-s` нет точных имён `IM-6400.zip`, `IM-7100.zip`, `IM-7400.zip`; содержимое её ZIP в этом проходе не скачивалось. Метаданные коллекции не устанавливают отсутствие дампа вне неё.

SD340, IM-6400 и PH-S5700 остаются документированными направлениями, которым нужен модельный образ или точный пакет обновления. Для каждого следующего входа требуются происхождение, размер, хеш, распаковка и отдельная проверка полезных данных. Уже найденные телефонные SGS и нативные игры по-прежнему описаны в [обзоре прошивок](phone-firmware-games.md).

Новые программы производителя не запускались; пользовательские разделы и записи EFS не экспортировались. Границы проверки не подменяют утверждением, что во всех этих телефонах нет игр.
