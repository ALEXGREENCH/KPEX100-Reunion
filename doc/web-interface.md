# Экран и корпуса устройств

Игровая страница содержит устройство, название игры и панель воспроизведения.
Библиотека открывается поверх страницы. Настройки корпуса, перезапуск, импорт,
снимок экрана и подсказки управления находятся в меню «•••».
Пошаговое исполнение и технические панели убраны из интерфейса; инструменты
исследования остаются в `tools`.

LCD имеет постоянный прямоугольник 5:4, максимум 440 × 352 CSS-пикселя.
Разрешение кадра меняет только размер внутреннего canvas. Кадр центрируется
с чёрными полями; пиксели не растягиваются по разным осям. При увеличении
используется целочисленный масштаб. На узком экране корпус обрезается,
а кнопки располагаются ниже. Библиотека, название и ошибки не сдвигают LCD.

Громкость регулируется от 0 до 100% с шагом 5%. Уровень сохраняется в браузере.
Кнопка звука переключает ноль и последний ненулевой уровень. Пользовательская
громкость умножается на громкость каналов игры; отключение звука не
останавливает уже воспроизводимую дорожку.

## Фотографии и ограничения

[Реестр](../web/devices/catalog.json) содержит точные размеры, SHA-256,
источник, прямоугольники фотографических частей и преобразования.
Исходные JPEG не редактировались: подгонка выполняется восемью SVG-фрагментами
в браузере. Корпуса адаптированы к одинаковому LCD и не являются масштабными
чертежами аппаратов. Внешность не устанавливает совместимость VM.

Для SD1020 намеренно не используется фотография SD1000 или другой похожей
модели. Для остальных телефонных SGS, у которых модель неизвестна, выбран
универсальный GNEX-телефон. Ручной выбор корпуса меняет только оформление,
сохраняет текущую игру и не отправляет в Worker команду загрузки.

Идентификаторы игр, извлечённых из четырёх LG, сопоставлены с корпусами явно.
Kingston/Cenix определяются по выбранной прошивке. Размер кадра не используется
для определения модели. При смене оформления и потере фокуса кнопки отпускаются.
На игровой странице показывается один набор управления; MODE/REC доступны
на корпусе плеера только в режиме прошивки, а также с клавиатуры C/V.

Фотографии сохраняют права авторов и не входят в MIT-лицензию Reunion.
Source-only сборка содержит метаданные и универсальное оформление, без JPEG.

## Проверка в браузере

После обычной сборки можно выполнить дополнительную проверку интерфейса:

```sh
npm install --no-save playwright
npx playwright install chromium
node tools/browser-presentation-check.mjs
```

Для установленного Chrome задайте `REUNION_CHROME` — путь к его исполняемому
файлу. Проверка использует отдельный временный профиль браузера. При заданном
`REUNION_BROWSER_OUTPUT` сохраняются снимки и JSON-отчёт.

Тест проверяет LCD с допуском 1 CSS-пиксель на 1440, 390 и 320 пикселях,
автоматическую и ручную смену корпусов, клавиатуру, отмену мультитача,
полноэкранный режим и сохранение громкости. Worker подменяется фиксированными
кадрами для воспроизводимости интерфейса. Это не тест совместимости игр;
настоящее исполнение отдельно проверяется существующим integration-набором.
