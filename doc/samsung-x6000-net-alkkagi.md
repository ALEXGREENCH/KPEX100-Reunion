# Net Alkkagi из Samsung SPH-X6000

Из второй части дампа Samsung SPH-X6000 извлечён пакет **Net Alkkagi (넷알까기)** для KTF BREW, идентификатор **1351**. Название `알까기` найдено в MIF. В ARM-модуле `netpebble.mod` сохранилась справка с названием `넷알까기` и указаниями для сетевой игры. В архиве лежат MIF, MOD, BAR, SIG и десять файлов SMAF. [Скачать комплект](../research/archives/Samsung-SPH-X6000-Net-Alkkagi.zip) · [Хеши и результаты](../validation/samsung-x6000-net-alkkagi.json) · [Исходный дамп](https://archive.sunderland93.ru/Firmwares/Samsung/SPH-X6000/SPH-X6000%20%5BMemory%20Dump%2C%202%20parts%5D.7z)

Извлечение проверяет SHA-256 образа, CRC16 каждой использованной страницы и непрерывность номеров фрагментов. При двух копиях фрагмента их общие байты должны совпадать. Проверены границы регионов MIF и BAR, а также размеры десяти контейнеров MMMD. Карта страниц и исходные HTTP-заголовки лежат в комплекте.

```sh
python tools/extract-samsung-x6000-net-alkkagi.py SPH-X6000-pt2.bin net-alkkagi.zip
```

Повторное извлечение дало те же 14 файлов. Подпись сохранена как часть пакета, её криптографическая проверка остаётся открытой.

## Запуск

Штатный `aram-debug` распознал пакет с одним BREW-модулем и остановился до его выполнения. Для отдельного локального прогона собран тот же коммит ARAM с `factory.AllowUntrustedBREW = true` сразу после `application.NewFactory()` в `cmd/aram-debug/main.go`. Байты игры совпадают с результатом извлечения. [Исходники проверенной ревизии](https://github.com/mirusu400/aram-core/tree/fea299cba15696ed1460f965b76626d6edab5e03)

```sh
aram-debug lua -run-budget 200000 -width 176 -height 220 -timeout 20s net-alkkagi.zip replay/playable.lua
```

На титуле указаны Com2uS и 2002 год. OK открывает главное меню, «Вниз» переводит курсор на настройки, следующий OK открывает экран звука. Два прогона дали побайтно одинаковый PNG настроек. При выборе начала игры появился индикатор загрузки. Сетевой матч и вывод звука не подтверждены. Кадры и сценарии лежат в `replay/`.

## Другие образы

Проверены семь образов из шести архивов. Полных SGS в открытом виде и с XOR A5 сканер не обнаружил. У SCH-B100 найдены пути WIPI в образе памяти. У SCH-N255 совпадение `Gnext` относится к строке `next` после байта машинной инструкции. Самостоятельный модуль GNEX этим совпадением не подтверждается.

В SCH-N299, SPH-X5900 и второй части SPH-X6000 нашлась таблица из 50 уровней Push Push I. В SPH-E1100 найдено 66 записей Push Push II. Все четыре таблицы совпали с уже известными по SHA-256. [Извлечение и список уровней](phone-firmware-games.md#samsung-push-push-i-ii-и-iii)
