# Samsung YP-T8: устройство XOV runtime

В официальной прошивке **YP-T8 1.38FR** подтверждён ARM-интерпретатор
XEOVIA, загрузчик внешних `.xov` и формат таблицы приложений.
В этом проходе новые оригинальные игры не извлечены и их запуск не подтверждён.
Нативный код движка и игровой XOV — разные объекты.

Источник — [оригинальный архив Samsung](https://org.downloadcenter.samsung.com/downloadfile/ContentsFile.aspx?CDSite=UNI_FR&OriginYN=N&ModelType=N&ModelName=YP-T8Q%2FELS&CttFileID=1072613&CDCttType=FM&VPath=FM%2F200611%2F20061114161749984_YP_T8_ROM_20060609_138FR.zip).
Его SHA-256:
`1806caaf2fede1f3871978e9ae0bb51ea34fb422b0ec1372d2047efe6d8aec34`.
Все адреса ниже относятся к `YP_T8.rom`, 944 020 байт,
SHA-256 `36dd184a8d3a71f78e1348ac46387c4854092475f0d57ce89e4f09c1823b597d`.

Машиночитаемые поля, исходные байты инструкций и результаты проверки:
[yepp-xov-runtime-followup.json](../validation/yepp-xov-runtime-followup.json).

## Адреса оригинального кода

Bootstrap копирует участок с адреса `0x7000089c` в `0x20010000`, длина
`0xd3850`. Эти значения лежат в ROM по смещениям `0x63c`, `0x640`, `0x644`.
Поэтому в скопированном участке `ARM address = file offset + 0x2000f764`.
К первым `0x89c` байтам bootstrap эта формула не относится.

| Смещение в ROM | ARM-адрес    | Поведение                                                                                          |
| -------------- | ------------ | -------------------------------------------------------------------------------------------------- |
| `0x49468`      | `0x20058bcc` | Исполнитель событий: читает 16-битные инструкции, вызывает обработчики через таблицу `0x208daf7c`. |
| `0x495d8`      | `0x20058d3c` | Разбирает разделы приложения, создаёт указатели переменных и ресурсов.                             |
| `0x4990c`      | `0x20059070` | Инициализация и START.                                                                             |
| `0x49954`      | `0x200590b8` | END с последующей очисткой.                                                                        |
| `0x494dc`      | `0x20058c40` | Событие таймера.                                                                                   |
| `0x49578`      | `0x20058cdc` | Обновление состояния клавиш и событие ввода.                                                       |
| `0x57380`      | `0x20066ae4` | Чтение записи `AppInfo.sys`.                                                                       |
| `0x57438`      | `0x20066b9c` | Перебор 50 записей приложений.                                                                     |
| `0x58470`      | `0x20067bd4` | Загрузка внешнего содержимого из файловой системы порциями до 16 000 байт.                         |
| `0x570d0`      | `0x20066834` | Запись 16-битного пикселя через указатель framebuffer `0x208dbdb4`.                                |

Исполнитель принимает инструкции меньше `0xf5`, а `0xff00` и отдельный
нативный sentinel завершают событие. Это байткодная VM внутри ARM-прошивки;
оснований считать сам XOV нативным ARM-приложением здесь нет.

## Восстановленная структура

В отличие от стандартного SGS4, здесь пять точек входа находятся по
смещениям `0x44`–`0x54`: START, END, таймер, клавиши и дополнительное событие.
Точное публичное имя последнего события не установлено.

Оригинальный инициализатор непосредственно читает четыре относительных
смещения разделов по `0x58`, `0x5c`, `0x60`, `0x64`. Дескриптор переменной
занимает 8 байт: тип, 16-битное число элементов и указатель, который заполняет
runtime. Элемент переменной занимает 4 байта. Дескриптор ресурса занимает
12 байт: тип, длина и заполняемый runtime указатель.

Эта организация похожа на GNEX, но совместимость XOV с существующими SGS
не проверена. Совпадение устройства таблиц не заменяет запуск оригинального XOV.

`AppInfo.sys` содержит до 50 записей по 456 байт. В записи имя начинается
с `0x15` и занимает 33 байта, флаг использования находится по `0x1c6`.
Код строит имена `%s.xov` и `%s.sys`, использует каталоги `GAME` и `SYS`.
Метаданные и файлы сохранений не считаются игровыми контейнерами.

## Что проверено в обновлении

Выполнен поиск по каждому байту трёх исходных файлов с восстановленными
смещениями XOV, без предположения о magic или номере версии. Проверялись:

- порядок разделов и выравнивание дескрипторов 8/12 байт;
- не менее 18 переменных, к которым обращается оригинальная инициализация;
- чётные точки входа внутри байткода и ненулевая точка START;
- точное совпадение суммы размеров переменных с выделенным разделом;
- размещение всех последовательно заданных ресурсов внутри файла.

| Файл          |    Размер | Кандидаты до проверки переменных | Объекты, прошедшие все условия |
| ------------- | --------: | -------------------------------: | -----------------------------: |
| `YP_T8.rom`   |   944 020 |                               17 |                              0 |
| `YP_T8.img`   | 2 738 020 |                                0 |                              0 |
| `YP_T8D1.FNT` | 1 486 488 |                                0 |                              0 |

Результат относится только к объектам, соответствующим этим условиям в
данных трёх файлах. Он не исключает другой упаковки, другого обновления или
игр на пользовательском разделе плеера. Загрузчик непосредственно подтверждает
маршрут через внешние файлы, поэтому наличие движка в ROM не означает наличие
там же всех игровых ресурсов.

Ранее найденный `T8_Game.zip` остаётся кандидатом: [архивный каталог
GenerationMP3](https://web.archive.org/web/20100409153635id_/http://media.generationmp3.com:80/lebellium/T8/)
указывает пакет размером 2,6 МБ. Оригинальные байты этого пакета пока не получены.
Ранее подтверждённые названия и источники перечислены в
[общем обзоре игр прошивок](phone-firmware-games.md#samsung-yp-t8--xeovia-подтверждена-бинарно).

## Дополнительный маршрут MPIO

Сохранены две публичные архивные страницы:
[FG200](https://web.archive.org/web/20111015044659id_/http://www.mympio.com:80/mpio/fg200.htm)
и [HD400](https://web.archive.org/web/20111015044807id_/http://www.mympio.com:80/mpio/hd400.htm).
Первая раскрывает ранее не сохранённый точный путь
`/mpio/firmware/FG200%20Firmware%20ver%201.17.zip`; версия 1.17 пока известна
только из имени файла. Вторая независимо подтверждает ранее известные ссылки
на прошивку HD400 1.04.0 и `games_hd400.zip`.

Бинарные архивы с этих страниц не получены. Страницы не называют игровой
движок MPIO, поэтому новые устройства с GNEX/XEOVIA на их основании не добавлены.
Адреса, хеши HTML и результаты сетевых обращений сохранены в
[mpio-mympio-followup.json](../validation/mpio-mympio-followup.json).
