# Sinjisoft 2002: Mobile C, SDK и каталог контента

Получены четыре ранее не сохранённые страницы производителя:
`mobilcsdk.html`, `mobilc.html`, `embeded.html` и `example.html`.
Это 77 538 байт исходных HTML из снимков 19 и 23 июня 2002 года;
SHA-1 каждого файла совпал с известной записью CDX.
[Источники, SHA-256 и очередь исследования](../validation/sinjisoft-2002-sdk-content.json).

[Архив оригиналов и фактической очереди](../research/archives/Sinjisoft-2002-MobileC-and-Content-Catalog.zip):
**20 988 байт**, SHA-256
`ab5b387a5e8417e6d1be93d19ccc2fee8b561834df00e006a96786e2ec48349d`.
В нём четыре HTML, JSON с записями каталога, README и manifest.
SGS, прошивок, установщиков SDK и полученных изображений в комплекте нет.

## SDK и Mobile C в этом историческом описании

[Страница Mobile C SDK](https://web.archive.org/web/20020623165959id_/http://www.sinjisoft.co.kr:80/mobilcsdk.html)
выделяет три компонента: компилятор, Media Tool Kit и GVM Emulator.
Названы Image Master и Audio Master, варианты эмуляторов для 4GRAY/256Color
и BUZZER/MA1/MA2. Конкретная версия SDK и адрес установщика здесь не найдены.

[Описание Mobile C](https://web.archive.org/web/20020623170159id_/http://www.sinjisoft.co.kr:80/mobilc.html)
говорит о языке на основе ANSI C с двухбайтными целыми, ресурсными типами,
статическими переменными и обработчиками событий. Указаны запрет рекурсии
и встроенные либо исходные библиотеки. Это описание ранней среды;
его ограничения не переносятся автоматически на поздние GNEX SDK.

## Изображения: точные ссылки, но запросы завершились тайм-аутом

В HTML найдено **46 ссылок на изображения**, сопоставленных всем 24 записям.
Они сохранены в JSON как исходные URI. Разметка первых двух записей ставит
картинки перед заголовком, остальных — после; сопоставление выполнено
по разделителям записей HTML, с проверкой последовательности 1–24.

Новый запрос CDX по исходному каталогу `gvmfile/` завершился тайм-аутом
TLS. Затем проверены три точных URI: первые изображения Galaga, записи 21
и покера. Все три также дали тайм-аут TLS-handshake; после трёх неудач
проход остановлен. Изображения не получены, их MIME и размеры не заявлены.
Оставшиеся 43 ссылки в этом проходе не запрашивались. Это транспортные
ошибки, а не HTTP 404 или доказательство отсутствия архивных изображений.

## Изготовители встроенных игр: отдельная очередь

[Страница о встроенных играх](https://web.archive.org/web/20020619040816id_/http://www.sinjisoft.co.kr:80/embeded.html)
перечисляет бренды SKY, CYON, NEOMI, Anycall, Liben@, SANYO, NOKIA и
`Motolora` — последнее написание сохранено как в источнике.
Среди изготовителей названы Wide Telecom, Smart Mobile, `기가텔레콤`,
`휴 텔` и KBT, наряду с уже известными компаниями.
Это свидетельство бизнеса Sinjisoft по встроенным играм; конкретные модели,
версия VM и SGS-формат для каждой марки этим не установлены.
Бренды и похожие названия производителей не объединяются догадкой.

## Границы поиска дистрибутивов

Для отдельного конкурсного домена `www.g-nex.com` использован новый точный
запрос главной страницы за 2005–2007 годы: CDX вернул пустой массив.
Отдельный запрос availability API получил HTTP 429 и не повторялся.
Прежний неудачный запрос всего доменного префикса не запускался заново.

Дополнительно прочитаны семь ранее полученных индексов CDX и статически
проверены выбранные ASCII URL-подобные строки 40 файлов уже сохранённого SDK.
Нового дистрибутива по этим проверкам не получено; это не универсальный
поиск по всем упакованным или Unicode-строкам. Два прежних точных запроса
имён SDK 1.20/GVM 1.52 не повторялись. Учётные записи, формы загрузки
и исполнение производителя в этом проходе не использовались.

## Проверка точных названий и новые адреса для поиска

Для десяти названий выполнены 30 поисковых запросов. Новых игровых файлов,
SDK или прошивок этот отдельный проход не дал. Четыре прямых запроса Naver
и CDX для `gamelist/` завершились TLS-handshake timeout; это не пустые
результаты архивного индекса. [Журнал и границы](../validation/gvm-2002-title-search-followup.json).

[Первичный Form 20-F Partner за 2002 год](https://www.sec.gov/Archives/edgar/data/1096691/000095012303002847/u45961e20vf.htm),
поданный 14 марта 2003 года, на печатной странице 48 прямо относит OBOX
к J2ME и GVM. GAMEZ на странице 49 отдельно описан через WAP, интернет,
SMS и IVR. Поэтому одна метка obox или Gamez не определяет формат игры.
Исполняемых файлов в прочитанном тексте не найдено.

Две публикации прессы, современные запуску, уточняют поисковые адреса:
[iNews24 от 24 августа 2001](https://m.inews24.com/v/43193) связывает
`낚시왕` с GVM и называет `www.webengkr.com`;
[iNews24 от 18 апреля 2001](https://inews24.com/view/32818) описывает
`포켓프로야구` для GVM, `www.pocketspace.co.kr`, `www.n-top.com`
и старый путь меню. Это вторичные источники и очередь дальнейшего обхода,
а не полученные игровые дистрибутивы. Сами три хоста ещё не обходились.
Raw HTML этих новых страниц не сохранён; хеш оригинала не заявляется.
