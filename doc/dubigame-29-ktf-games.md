# 29 игр KTF из Dubigame

Сохранены 29 исходных операторских пакетов, включая **Princess Maker 4**, **FIFA 07**, **Shrek the Third**, **Super Robot Tactics R**, **KBO Pro Baseball 2009**, **World Olympics 2006** и **Zeke**. Один уже известный архив, Pirate King 2007, исключён по совпадению SHA‑256. В комплекте есть страницы вложений, заголовки ответов, квитанции загрузки и списки файлов с хешами. CRC каждого внешнего ZIP, ALZ и вложенного JAR проверены. [Комплект](../research/archives/Dubigame-29-KTF-Games.zip) · [Все игры, сборки и результаты](../validation/dubigame-29-ktf-games.json)

## Запуск в ARAM

Для каждой из 29 сборок ARAM определил профиль `wipi-1.2.1/ktf/generic` и отдал четыре кадра. Разрешение взято из операторского `DisplaySize`. В **Zoo Tycoon 2** после нажатий остался белый экран с индикатором. В **GetAmped** и **Kang Ho-dong New Matgo 2** заметны проблемы отрисовки. Для остальных вывод о полном прохождении по этим снимкам сделать нельзя. [Использованная версия ARAM](https://github.com/mirusu400/aram-core/tree/fea299cba15696ed1460f965b76626d6edab5e03)

| Игра                | Проверенная сцена                                                                                                                        |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Zeke                | Первый город. Удержание вправо перемещает персонажа и сдвигает камеру. [Пакет](https://dubigame.tistory.com/424)                         |
| World Olympics 2006 | После OK со страницы рекорда открывается беговая дорожка. [Пакет](https://dubigame.tistory.com/404)                                      |
| Princess Maker 4    | OK продвигает вступление к следующей иллюстрации. [Пакет](https://dubigame.tistory.com/183)                                              |
| 2006 Soul Fishing   | OK переводит начальную подсказку на следующую страницу. [Пакет](https://dubigame.tistory.com/403)                                        |
| FIFA 07             | Открывается тренировочное поле. В проверенной точке эффект нажатий вправо и OK не подтверждён. [Пакет](https://dubigame.tistory.com/186) |

Для этих сцен кадры с нажатием и без него сравнивались на одном виртуальном кадре. В `replays/` лежат Lua-сценарии, журналы и PNG. Для **2006 Soul Fishing** оригинальный ALZ хранится в `originals/403/`. ARAM использует отдельный ZIP из `derived/403/`, собранный из тех же семи распакованных файлов. Их размеры, CRC и SHA‑256 записаны в `evidence/soul-fishing-alz-verification.json`.

```sh
aram-debug lua -width 240 -height 320 -run-budget 200000 -timeout 50s game.zip replay.lua
```

## Поиск SGS и GVM

Структурный сканер проверил исходные контейнеры и все распакованные файлы, включая 11 585 членов JAR из 30 проверенных пакетов. Валидных SGS не найдено. Сборки доступны в исследовательском разделе Pages как KTF WIPI для ARAM. Ещё 208 недавно полученных объектов Wayback из очереди GNEX/GVM и связанных сайтов тоже проверены, совпадений с SGS нет. В `evidence/wayback-sgs-check.json` сохранены URL и хеши проверенных объектов.
