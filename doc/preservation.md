# Сохранение материалов GVM / GNEX

Сохраняем полученные файлы, а не только ссылки на них. В репозитории
находятся **24 исследовательских ZIP, 203 405 094 байт**; они доступны
на [странице архивов](https://alexgreench.github.io/KPEX100-Reunion/research/).
Это дополнение к 81 оригинальному файлу коллекции для запуска.
Клонирование репозитория получает сами архивы; Git LFS для них не нужен.

## SDK, эмуляторы и руководства

- [Полные GNEX SDK 2.10 и 2.12](../research/archives/Sinjisoft-GVM-GNEX-Emulators-Recovered.zip):
  два неизменённых установщика, IDE, компиляторы, эмуляторы, скины,
  заголовки и документы. Оба установщика сохраняют полный исходный payload,
  включая части, отсутствующие в удобном извлечённом поднаборе.
  Повторно проверены 238 + 255 CAB-файлов. Отдельный исторический GVM2X
  модифицирован и так обозначен; оригинальность официального релиза ему
  не приписывается. [Состав и ограничения](gnex-emulators.md).
- [Исходный Mobile C Reference 311 из Daum](../research/archives/Sinjisoft-MobileC-API-311-Reference.zip):
  точный PDF на 1 340 616 байт, SHA-256
  `f3fe78dba53055774e83b94668e4f3cae2862662a66653877577edda0da54e0e`.
  Это отдельный документ из запроса, отличающийся от API313 внутри SDK.
  PDF не редактировался; исходное расхождение 310/311 сохранено.
- [GNEX Technical White Paper](../research/archives/Sinjisoft-GNEX-Technical-Whitepaper-2003.zip)
  и [GNEX Service](../research/archives/Sinjisoft-GNEX-Service-2003.zip):
  исходные ZIP производителя, один и два PDF соответственно. SHA-1 обоих
  архивов совпали с CDX. Они сохраняются без добавления файлов внутрь;
  внешний реестр содержит хеши членов.

Другие комплекты сохраняют GVM Club 2002–2003, WI-TOP, технические бюллетени,
справочники телефонов, Mobile C, ImagePlus/GetID, вложения Naver, исходники
примеров SDK, исследования SV400, S60, GNEX Zone и страницы Sinjisoft.
Сохранены также полученные игровые файлы и ресурсы. Нативные PXO,
незавершённые прототипы и документы учитываются отдельно от рабочего
каталога SGS; скачивание комплекта не означает поддержку всего его содержимого.

[Источники Innocom и Super GNEX](innocom-super-gnex.md) сохраняют ещё четыре
исходных HTML, два из них — релизы ICOLS. Производные представления
документов SEC помечены отдельно: их исходные HTML пока не получены.

## Проверка и независимая копия

Для каждого ZIP в [публичном каталоге](../web/research/catalog.json) указаны
размер, SHA-256 и источники. [Проверка перед публикацией](../validation/preservation-archive-review.json)
фиксирует манифесты, происхождение и границы анализа. В
[полном реестре файлов](../validation/preservation-inventory.json) находятся
CRC32, SHA-256 и размеры всех непосредственных файлов внутри 24 ZIP.

После клонирования можно независимо пересчитать архивы и каждый их член:

```sh
python tools/preservation-inventory.py --output ../preservation-inventory-local.json
```

Команда использует только стандартную библиотеку Python, проверяет исходный
SHA-256 ZIP, читает все его файлы до конца с проверкой CRC и ничего не запускает.
Выходной файл должен быть новым. Вложенный установщик здесь учитывается
как точный файл; разбор его внутренних CAB описан отдельным отчётом SDK.
Обычная `npm run build` также проверяет размеры и SHA-256 всех архивов.

## Что сохранять при следующей находке

Сначала сохраняются точные полученные байты, URL источника и родительской
страницы, время получения, длина и SHA-256. Для Wayback отдельно записываются
дата снимка и совпадение с CDX, когда оно доступно. Исходный архив остаётся
неизменным; распакованные файлы, декодированные SGS, текст и изображения
страниц являются отдельными производными. Временные подписанные CDN-адреса
не заменяют постоянную ссылку на исходный пост.

Проверяются CRC и манифесты. Повреждённые или неполные ответы сохраняются
в исследовательском рабочем архиве с явной отметкой; они не выдаются за
исправный дистрибутив. Тайм-аут не считается доказательством исчезновения.
Оригинальные уведомления и соответствующие исходники GPL сохраняются вместе
с программами. Собственная лицензия Reunion не меняет права на исторические
материалы.

Это реестр уже полученного, а не заявление о сохранении всего интернета.
Например, ранние SDK 1.20/1.40 и GVM SDK 1.52 пока известны по объявлениям;
их установщики не восстановлены. Файлы, которых ещё нет, не подменяются
одноимёнными сборками. [Точные старые имена и очередь поиска](gnex-club-early-sdk-sources.md).
