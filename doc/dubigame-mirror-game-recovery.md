# Игры SKT, KTF и LGT из зеркал Dubigame

Из майской копии Dubigame восстановлены **15 пакетов SKT, 35 сборок KTF и 7 сборок LGT**. Из январской копии и сохранившегося вложения добавлена **Magic Shop Tycoon 2** для KTF. Оригинальные архивы лежат внутри двух комплектов вместе с манифестами CRC32 и SHA‑256, квитанциями загрузок и сценариями ARAM. [Скачать SKT](../research/archives/Dubigame-SKT-15-Game-Packages.zip) · [Скачать KTF и LGT](../research/archives/Dubigame-KTF-LGT-43-Game-Packages.zip) · [Данные проверки](../validation/dubigame-mirror-game-recovery.json)

В майском ZIP использованы HTTP-диапазоны. Все 102 выбранных записи сверены по длине и CRC32 с центральным каталогом. У 42 сборок KTF и LGT хеши JAR впервые появились в сверенных отчётах. Остальные 45 майских пакетов KTF и LGT повторяли уже учтённые игровые бинарники. Бинарники 15 сборок SKT совпали с прежними проверками живого сайта. Комплект сохраняет точные ZIP из зеркала и результаты запуска. [Майское зеркало](https://archive.org/details/dubi_20210525) · [Прежняя проверка Dubigame](wayback-game-search-pass22.md#dubigame-и-nexon)

Для январского 7z скачаны заголовок и конец файла с оглавлением. Оригинальное вложение Magic Shop Tycoon 2 скачалось с CDN. Его длина и CRC32 совпали с записью 7z. Дескриптор указывает `PD003214`, `AID 01031685`, версию `01.00.00` и 176×220. JAR побайтно совпадает с ранее сохранённой сборкой Palletshipping с `AID 010100D5`. ZIP и вложенный JAR прошли проверку CRC. [Январский снимок](https://archive.org/details/dubigame.tistory.com) · [Сборка Palletshipping](palletshipping-31-ktf-wipi.md)

## Ввод в ARAM

Для каждой пары кадры сравнивались на одном виртуальном времени. В комплекте сохранены начальные и конечные PNG и журналы. [Версия ARAM](https://github.com/mirusu400/aram-core/tree/fea299cba15696ed1460f965b76626d6edab5e03)

| Игра                                 | Что подтверждено                                                             |
| ------------------------------------ | ---------------------------------------------------------------------------- |
| Great Pirate Age / 대해적시대        | OK открывает порт, следующее нажатие открывает диалог в башне.               |
| X-Men Legends II: Rise of Apocalypse | OK открывает выбор сложности, следующее нажатие открывает выбор персонажа.   |
| Dragon Knight EX                     | OK открывает список сохранений, следующее нажатие открывает меню новой игры. |
| Knight Maker                         | OK запускает сюжетное вступление.                                            |
| Magic Shop Tycoon 2                  | OK открывает выбор между новой игрой и загрузкой.                            |

Начальный сценарий запущен для всех опубликованных пакетов. Девять сборок KTF остановились до конца общего сценария. Для нескольких SKT сохранились только заставки, сообщение о проверке приложения или чёрный кадр. Прогоны подтверждают перечисленные экраны и действия. Комплекты доступны в исследовательском каталоге для ARAM.

## Проверка SGS

В пакетах обнаружены три полных SGS. Их SHA‑256 совпадают с уже опубликованными **Fullmetal Alchemist**, **Inuyasha** и **Dungeon Fighter: Gunner**. Для Real Soccer 2009 восстановлен вложенный ZIP из 18 частей `lo.z00`–`lo.z17`. CRC всех 94 записей прошли проверку, SGS среди них не обнаружено. В `정통맞고2007.zip` сохранён JAR-контейнер с заголовком `odcf`. Проверка CRC относится к его сохранённым байтам, расшифровка не выполнялась. [Fullmetal Alchemist и Inuyasha](palletshipping-fullmetal-inuyasha.md) · [Dungeon Fighter: Gunner](wipix-ktf-three-gnex.md)

Параллельный проход по 14 BIN из архивов LG нашёл один полный SGS, ранее сохранённый **Ladder** из SD1250. Этот скан охватывает поддержанные структуры SGS и не проверяет нативные ARM-игры. [Разбор SD1250](phone-firmware-games.md#lg-sd1020-и-sd1250-bubble-bobble-и-ladder)
