# Dungeon Fighter и Sketcher из пакетов KTF

В трёх публичных ZIP WIPI-X обнаружились полные SGS v4 внутри нативных файлов `client.bin*`. Извлечённые файлы побайтно совпадают с указанными диапазонами исходников. Все три SHA‑256 новые для библиотеки Reunion. Разрешения взяты из `DisplaySize` операторских дескрипторов. ## Запуск в Reunion

- **Slayer.** После пропуска диалога в Элвенгарде удержание вправо сдвигает героя к краю кадра. Цифра `6` дала тот же кадр. В прогоне без ввода герой остался на прежнем месте. Сравнение сделано на 29 200 мс виртуального времени.
- **Gunner.** Удержание OK тратит очко и увеличивает STR. После распределения очков, подтверждения цифрой `1` и пропуска вступления открывается локация Мирквуд.
- **Sketcher.** OK на экране Stage 1 запускает трассу. На том же виртуальном времени в прогоне без ввода остался экран перед стартом. Дальнейшее управление на трассе и полные прохождения в этих тестах не проверены.

В проверенных сценах достаточно штатного бюджета исполнения. Для повторения теста распакуйте `replays/` из комплекта и передайте соответствующий сценарий инструменту:

```sh
node tools/replay-sgs.mjs dungeon-fighter-slayer-ktf replays/dungeon-fighter-slayer-ktf/final-right/actions.json
```

## Проверка источников

Сканер проверил 35 дополнительных вложений WIPI-X и 22 667 файловых объектов, включая распакованные JAR. Все три совпадения описаны в таблице. В KTF-пакете Dungeon Fighter: Fighter из соседнего вложения структурно валидного SGS не найдено. У Rhythm Star перед ZIP есть JPEG-префикс длиной 99 557 байт, поэтому его проверяли как архив по центральному каталогу. В нём SGS тоже не найдено. Полная опись этого прохода лежит в `evidence/survey.json`. [Вложение Fighter](https://wipix.tistory.com/5) · [Вложение Rhythm Star](https://wipix.tistory.com/30)
