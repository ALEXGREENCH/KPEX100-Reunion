# Источники Reunion

Источники проверены 5 ноября 2026 года. Здесь отделены первичные документы, результаты анализа конкретных файлов и ещё не подтверждённые направления поиска.

## Mobile C / GNEX

Дополнительно восстановлены **GVM 단말기별 개발가이드** (Sinjisoft,
2002-11-30, 101 страница), **GVM Technical Bulletins** (Sinjisoft,
2002-12-20, 55 страниц) и историческое XLS-вложение SKT/STI с датой
2003-10-14 в имени файла. SHA-1 всех трёх файлов совпал с CDX.
[Страницы, ячейки, исходные адреса и SHA-256](gvm-historical-handsets.md).
Из вложений самого форума получены [WI-TOP и пример Mobile C](gvm-community-recovery.md).

Новые первичные инструкции: [Nokia 8887](sanyo-nokia-korean-gvm.md)
(63 PDF-страницы; Snake II на PDF 45–46 / печатных 39–40) и
[Curitel C-500](curitel-c500.md) (Magic Ball на PDF 33 / печатных 62–63).
Их сохранённые копии сверены по SHA-256 и просмотрены по изображениям страниц.
Названия встроенных игр не устанавливают их SGS-формат.

[Сервисные документы GVM 2001–2002 годов](gvm-early-service-guides.md)
восстановлены из ещё шести вложений: три ZIP/PDF-источника, исходный PPT
и два файла Mobile C/данных. Таблица телефонов прочитана непосредственно
из встроенного EMF: 26 строк, 9 явно планируемых. Даты, конфликты,
DD-101 и технические особенности телефонов сохранены отдельно от
современных эмуляционных профилей.

**Mobile C Library Function Reference**, Sinjisoft Corporation, октябрь 2007, **MCC-API-301-311**. На странице copyright осталось обозначение `MCC-API-301-310`; титул и запись изменений от 2007-10-25 указывают `311`. Это следует сохранять в библиографии, а не исправлять догадкой.

Проверенные адреса: [исходная HTTP-копия PDF](http://cfile209.uf.daum.net/attach/165521104A3E87994E43CC), [HTTPS-адрес из запроса](https://cfile209.uf.daum.net/attach/165521104A3E87994E43CC). HTTP вернул `200`, `application/pdf`, 1 340 616 байт. HTTPS через инструмент просмотра завершился тайм-аутом. Полученный PDF совпал с хешем, указанным в исходном исследовательском архиве:

```text
SHA-256 PDF:
f3fe78dba53055774e83b94668e4f3cae2862662a66653877577edda0da54e0e
Путь в исходном исследовательском архиве: reverse/reference/MobileC_reference.txt
Этот архив и текстовая копия руководства не входят в репозиторий.
```

Полезные места в документе:

| Страницы   | Содержание и применение                                                           |
| ---------- | --------------------------------------------------------------------------------- |
| 1–2, 8     | Заголовок, copyright, история редакции.                                           |
| 9–10       | Семейства GVM 1X / GVM 2X / GNEX и матрица версий компилятора.                    |
| 44         | `GetSysInfo`: запрос возможностей платформы.                                      |
| 96 и далее | Графические функции, буферы LCD и `Flush`.                                        |
| 221–224    | Файловые операции; реальные параметры нужно сверять с ROM конкретного устройства. |
| 282–283    | `SetTimer`: события и повторный таймер.                                           |
| 314        | `GetVirtualKeyCode`: поздний API виртуальных клавиш.                              |

Руководство описывает совместимость GNEX с предыдущими поколениями GVM, но таблица компиляторов содержит и частичную поддержку. Поэтому принадлежность двух файлов к семейству SGS сама по себе не доказывает совпадение ABI, графического формата, кодов клавиш и доступных системных функций. Документ 2007 года также не доказывает наличие всех его API в более раннем Kingston 2.12.

В самом руководстве перечислены ещё три первичных документа: **GNEX SDK Overview** (`SDK-OVW-301-xxx`), **GNEX SDK User’s Guide** (`SDK-MAN-301-xxx`), **Mobile C Programming Guide** (`MCC-PRG-301-xxx`). Их названия подтверждены; наличие полных проверенных экземпляров этих редакций в данном проекте не заявляется.

## Лицензии исполняемых компонентов

- [Unicorn.js](https://github.com/AlexAltea/unicorn.js) — авторский порт Unicorn для JavaScript; upstream указывает **GPL-2.0**. В комплекте сохраняется его LICENSE. Конкретную сборку и адаптер следует идентифицировать отдельно от версии Python-пакета Unicorn.
- [fflate](https://github.com/101arrowz/fflate/blob/master/LICENSE) — **MIT**; используется для чтения ZIP-состояний. Условия и copyright должны сохраняться вместе с библиотекой.
- **Sinjisoft Mobile C Reference**: copyright 2000–2007 Sinjisoft; страница 2 содержит ограничения копирования и перевода. Из доступности PDF не следует свободная лицензия.
- **ROM, SGS, графика, звуковые ресурсы и checkpoint RAM** сохраняют права своих авторов. Состояние машины включает содержимое памяти и не превращает прошивку в свободный материал. Их лицензии нельзя подменять лицензией эмулятора.

## Граница доказательств совместимости

Для каждого SGS требуются хеш, профиль заголовка и VM, проверка старта, содержательный ввод и достигнутое игровое состояние. Проверенные игровые сценарии и утилита Mosquito перечислены в [матрице совместимости](compatibility.md). Для 9 ROM также различаются «контрольная сумма и структура разобраны», «начато ARM-исполнение» и «достигнуто рабочее меню».
