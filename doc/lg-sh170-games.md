# Игры из LG CYON SH170 и KH1600

Из сервисного образа `SW170710` извлечены пять игр, их меню и общие ресурсы. Проверка относится к этому образу. [Исходный SW170710.7z](https://archive.sunderland93.ru/Firmwares/LG/SH170/SW170710.7z) · [Анонс LG Electronics](https://www.newswire.co.kr/newsRead.php?no=289752)

| Игра            | Модуль                    | В прошивке, байт | После распаковки, байт |
| --------------- | ------------------------- | ---------------: | ---------------------: |
| Baduk           | `Game_Baduk.pxo`          |          539 777 |              1 453 185 |
| Rhythm Cooking  | `Game_Cooking.pxo`        |          797 096 |              2 123 121 |
| Grand Golf      | `Game_GrandGolf.pxo`      |          290 770 |                559 017 |
| Rainbow Striker | `Game_RainbowStriker.pxo` |          640 986 |              1 243 405 |
| Sudoku Puzzle   | `Game_Sudoku.pxo`         |          103 534 |                399 121 |

Модули лежат в `MODULE/C/`. В архиве есть обе версии каждого PXO, а также `Game.pxo` и `WIPISKT.pxo`. Названия прочитаны в `Game.pxo`. У распакованных файлов проверены заголовок `PXO4`, внутренний размер и границы метаданных. Машинный отчёт содержит смещения, байты и дизассемблирование начала Thumb-кода. Эти игры требуют телефонного окружения LG. Их запуск в Reunion не проверялся, в игровой список SGS они не входят.

В `MODULE/BUILTIN/GAME/data.lkz` лежит ZIP с 431 файлом. Сохранены сам LKZ и манифест со всеми CRC-32, размерами и SHA-256.

## MAIN и поддержка GNEX

Цепочка `7z → KDZ → CAB → WDB` дала 1668 файлов. Слой `BIN/SH170.bin` состоит из 1731 слота LZO1F по 16 КиБ, последний слот короче. После распаковки получено 47 811 680 байт. Первое слово — ARM-переход `0xEA002E12`. Опубликованы размеры, смещения и SHA-256 всех блоков. Второй проход тем же примитивом LZO воспроизвёл байты результата.

В MAIN дважды встречается последовательность `application/x-gnex-sgs`, `WAM`, `A000200001`, `application/x-wipi-jar`, `A000100001` со строками, разделёнными нулевыми байтами. Фрагменты сохранены со смещениями `0xA81038` и `0x122AB54`. Запись `CONTENT / A000200001` в формате, известном по SH110, в проверенном MAIN отсутствует. Сохранились отдельные записи `PhotoOn2` от Sinjisoft и `MA5500GAME` от LG. Самостоятельный проигрыватель GNEX из этого образа не извлечён. [Запись GNEX в SH110](korean-phone-preservation-pass16.md#запись-телефонного-gnex-в-sh110)

Проверены обычные и XOR-A5 контейнеры SGS известных версий в распакованном MAIN, во всех 1668 файлах WDB, в семи распакованных PXO и 431 файле LKZ. Подтверждённых SGS в этих слоях нет. Положительный контроль прошли 94 файла коллекции. Такой поиск оставляет открытым вопрос об иной упаковке, а сервисный образ не охватывает хранилище с играми, скачанными владельцем телефона.

## Извлечение игр KH1600 из начала WDB

Внешний архив `KW160716.7z` прошёл CRC, KDZ расшифровался в CAB. При чтении `KW160716.wdb` из CAB 7-Zip остановился после 45 907 968 из объявленных 68 556 313 байт. Первая ошибка контрольной суммы MSZIP зафиксирована на блоке 1401 по смещению 45 801 512 в CAB. MD5 KDZ совпал с опубликованным на втором зеркале, адрес старого сервера LG не разрешается в DNS. [Исходный KW160716.7z](https://archive.sunderland93.ru/Firmwares/LG/KH1600/KW160716.7z) · [MD5 на втором зеркале](https://lg-firmwares.com/downloads-file/2250/KW160716_00)

Из непрерывного участка до ошибки извлечены 590 полных записей. Смещения выведены из заголовков, каждый поток zlib проверен до конца. В числе этих записей оказались те же пять игр, меню и ресурсы. `data.lkz` побайтно совпадает с SH170. Все пять игровых PXO и меню различаются по SHA-256 и после распаковки. Полностью уцелевший `BIN/KH160.bin` распаковался в MAIN размером 28 469 984 байта. Структурная проверка 590 файлов, шести распакованных PXO и MAIN не выявила SGS. Строки маршрутизации SGS, найденные в MAIN SH170, в проверенном MAIN KH1600 не встречаются.

## Сервисные образы S-Fone

`SD350F03` и `SD353F04` повторно скачаны и совпали по SHA-256 с предыдущими загрузками. Строки S-Fone и BREW относятся к этим сервисным сборкам. Их два основных BIN уже проверены на SGS без совпадений. Извлечение KDZ, WDB и PXO описано в [комплекте инструментов LG](korean-phone-preservation-pass16.md#скачать-и-повторить). Для плоского MAIN после извлечения WDB запустите следующий скрипт с доверенной библиотекой LZO2, экспортирующей `lzo1f_decompress_safe`. DLL из прошивки используется только как источник размера при разборе WDB.

```sh
python tools/unpack-lg-flat-main.py SH170-software/BIN/SH170.bin SH170-main --lzo-library /path/to/liblzo2.so
```

Для KH1600 используйте `--prefix` на непрерывном выходе 7-Zip до первой ошибки CAB. Обычный режим WDB требует целый индекс и этот вход отклоняет.

```sh
python tools/unpack-lg-wdb.py KW160716.wdb KH160_0.2.0.0.dll KH1600-prefix --prefix
```
