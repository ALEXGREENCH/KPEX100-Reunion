# Haunted School и Lost Planet II на Samsung SCH-S250

Обе встроенные игры из прошивки **YD01** запускаются в воспроизводимом сценарии Unicorn. Оригинальный ARM/Thumb-код отрисовывает заставку, меню, вступление и первый 3D-уровень. В обеих играх подтверждена реакция на движение вперёд. В меню телефона первая игра называется Haunted School, на самой заставке написано **The School**. [Исходная прошивка и руководство](samsung-s250-s380.md) · [Скачать ресурсы и кадры](../research/archives/Samsung-SCH-S250-Haunted-School-and-Lost-Planet-II.zip) · [Хеши и результаты](../validation/samsung-s250-native-games.json)

## Извлечённые ресурсы

В комплекте четыре исходных контейнера Amos и **226 распакованных файлов**. В каждой записи проверены границы, размер, маркеры начала и конца LZW. У изображений MRA проверены размеры и длина буфера RGB565. У файлов `MAP*.MZB` проверены размеры сетки и восемь байт на клетку.

| Игра           | Содержимое  | Смещение в BIN | Файлов | Карт |
| -------------- | ----------- | -------------: | -----: | ---: |
| Lost Planet II | Мир MZB     |     `0x717df4` |     66 |   11 |
| Lost Planet II | Графика MRA |     `0x759e10` |     61 |    — |
| Haunted School | Графика MRA |     `0x7ad218` |     49 |    — |
| Haunted School | Мир MZB     |     `0x80dd00` |     50 |    8 |

Размер контейнера включает выравнивание последней записи. Списки членов, смещения, CRC32 и SHA-256 лежат в `resources.json` внутри `resources.zip`. Распаковка портативным скриптом побайтно совпала с выводом оригинального Thumb-декодера на `0x2ec73c` для всех 226 файлов. При этой проверке подменялось только выделение памяти, а восемь сторожевых байт после каждого выходного буфера сохранились.

## Запуск оригинальных обработчиков

В BIN первые 32 КиБ отделяют загрузочный сегмент. Для проверяемой области адрес в гостевой памяти равен файловому смещению минус `0x8000`. Обработчики меню `0x1bd508` и `0x1bd4ec` записывают разные значения в гостевой байт `0x112c389`. Общий загрузчик на `0x24b984` выбирает по нему таблицу обратных вызовов. Входы инициализации находятся на `0x2516b8` и `0x24c1a0` соответственно.

После заставки сценарий передаёт оригинальному обработчику на `0x24ba0a` код подтверждения `0x53`, а для движения — `0x32` (цифра 2). Кадры читаются из гостевого буфера **240 × 320 RGB565**. Для каждой игры повторный запуск дал те же кадры. Прогон без команды движения за то же число тиков дал другой итоговый кадр, при этом до подачи команды кадры совпадали. В архиве есть оба итоговых кадра и все сценарные квитанции.

Сценарий подменяет сервисы выделения памяти, времени, NV, диагностики, внешней флеш-памяти, звука, передачи LCD и отрисовки системного шрифта. Поэтому часть текста во вступлении отсутствует. Прогон проверяет первый уровень и движение. Полное прохождение, звук, сохранения и интерактивный запуск в веб-эмуляторе пока не проверены.

## Повторить

Распакуйте `S250MSM_CODE_YD01.7z` из [исходного комплекта](../research/archives/Samsung-SCH-S250-Code-and-Manuals.zip). Оба инструмента сверяют SHA-256 оригинального BIN.

```sh
python tools/extract-samsung-s250-amos.py S250MSM_CODE_YD01.bin resources.zip
python -m pip install unicorn==2.1.4 Pillow
python tools/replay-samsung-s250-native.py S250MSM_CODE_YD01.bin haunted-school haunted-school-run
python tools/replay-samsung-s250-native.py S250MSM_CODE_YD01.bin lost-planet-ii lost-planet-ii-run
```

Добавьте `--control` и другое имя каталога, чтобы повторить сценарий без последнего движения. Скрипт `tools/verify-native-amos.py` из архива принимает два аргумента, исходный BIN и полученный `resources.zip`. Он сверяет распаковку с оригинальным декодером.
