# Sinjisoft: корейские объявления и семинар GVM 2000 года

6 ноября 2026 года из оригинального объявления Sinjisoft восстановлены
**два PDF семинара 17 августа 2000 года**. Оба сырых ответа Wayback имеют
HTTP 200 и совпадают с SHA-1 соответствующих записей CDX. Неизменённые
PDF, ответы API, заголовки, UTC получения, URL и SHA-256 включены в комплект.

В `gvm3.pdf` показаны подготовка изображений и MA1, структура программы,

Это первичный материал для проверки раннего GVM и
[сохранённого примера Hellfire](gvm-community-recovery.md).

На слайде 15 указаны `HellfireGray`, `SCRIPTVER 0`, CPID 100 и ID 71.

различаются как минимум идентификаторы и версия. Это также не SDK
и не телефонный плеер.

Для обоих PDF прочитаны все 32 узла страниц, размеры и текст. MuPDF
отрендерил и визуально проверены шесть страниц: `gvm1` — 1;
`gvm3` — 1, 3, 15, 19, 21. Корейский текст и код читаются.
Это не визуальная проверка всех страниц. Производные текст и PNG
лежат отдельно от оригиналов.

## Объявления на собственном сайте

В подборку выделены **25 объявлений `board2` и три корпоративные
страницы** из [снимка Pass 4](wayback-partial-pass4.md). Это курирование
уже скачанных HTML, а не 28 вновь найденных пресс-релизов. Для каждой
страницы сохранены буквальная запись CDX, ответ с заголовками, оригинальные
байты и отдельный текст UTF-8. Все 28 оригиналов совпали с CDX;
текст декодирован без замены символов.

- SWAP и семинары 2000–2001 годов: объявления 9, 10, 11, 12, 16, 24, 48.
- SDK 1.51/1.52, руководства и остановка распространения IDE:
  объявления 61, 77, 164, 235, 264, 369.
- Авторские инструменты **mQuiz** и **mCrossWord**: объявления 103 и 106.
  Страницы описывают платные инструменты Sinjisoft; бинарники не получены.
- GVM Club, RS-232C, книга _GVM Programming_, особенности Samsung X-400,
  Audio Type/LCD Class, Photoshop, перечень аппаратов и technical bulletin:
  объявления 117, 122, 234, 246, 293, 355, 427, 461.
- Wireless Japan, корпоративное объявление 262, история компании,
  зарубежные проекты и собственное описание стратегии.

В истории компании названы встроенные игры и решения для LGIC, Hyundai,
Telson, WIDE Telecom, SK Teletech, Sanyo, Nokia и Samsung. Это направления
поиска прошивок; список не подтверждает GVM/GNEX в любом аппарате этих
производителей. Страница зарубежных проектов отдельно описывает obox
и GNEX для Symbian через Handango.

Дата размещения объявления, дата первоисточника внутри текста и дата
снимка хранятся раздельно. Например, объявления о событиях 2000 года
перенесены в `board2` в феврале 2001 года. Заявления компании сохранены
как исторический оригинал и не превращены в независимые измерения
скорости или доли рынка.

Ранее сохранённые [30 релизов Newswire](sinjisoft-press-preservation.md)
остаются отдельным комплектом. Общий архив корпоративной доски содержит
также перепечатки и спам; они не объявлены релизами Sinjisoft.

## Поиск по корейским оригиналам

В ZIP есть `derived/wayback-pass4-text-index.json`: 1 965 различных
подтверждённых HTML с HTTP 200 из всего снимка, а не только Sinjisoft.
Семь текстов имеют явно отмеченную потерю символов при декодировании.
Индекс включает формы, спам, перепечатки и страницы ошибок с HTTP 200;
совпадение слова не является находкой программы.

После распаковки:

```sh
python tools/wayback-text-index.py search derived/wayback-pass4-text-index.json "기술세미나"
python tools/wayback-text-index.py search derived/wayback-pass4-text-index.json "개발 가이드"
python tools/wayback-text-index.py search derived/wayback-pass4-text-index.json "mQuiz"
```

Индекс не исполняет страницы и не запрашивает ссылки. Корейские оригиналы
сохраняются вместе с английскими терминами и точными именами файлов.

## Невосстановленные вложения

Текущий availability API вернул пустой `archived_snapshots` для
`gvm2.pdf`, `gvm4.pdf`, `PDF&SOURCE.zip`, `GVM_Seminar.zip` и
`010612_GVM_Service.zip`. Это не доказательство, что они никогда
не архивировались. Два запроса индекса `/HP/data/` завершились
тайм-аутом и HTTP 503; они не записаны как пустые индексы.
Точные запросы CDX для `gvm1.pdf` и `gvm3.pdf` затем прошли успешно.

Следующие буквальные зацепки из HTML сохранены как ещё не полученные материалы:

- `n-top.com/wig1/plsql/inso_developer2.main` — второй адрес поддержки GVM.
- Motorola V.67: обновление с увеличением места для GVM;
  ссылка `mymotorola.co.kr/newsview.asp?n_index=177&category=7`.
- GVM Club `boardcomm/board.cgi?bd=cpds&j=content&u=&i=18&c=1` — Photoshop.

GNEX SDK **1.20/1.40**, `GVM_SDK_v152_031222.zip` и самостоятельный
телефонный GNEX-плеер в этом проходе не восстановлены. Статусы и
подтверждённое имя `GNEX_SDK_v1.40.exe` остаются в
[отдельном отчёте](gnex-early-sdk-player-followup.md).
