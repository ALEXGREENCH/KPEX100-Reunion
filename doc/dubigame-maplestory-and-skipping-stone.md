# MapleStory, My Princess 2 и Skipping Stone 3 для KTF

В корейском блоге Dubigame сохранились пять сборок KTF WIPI, которых ещё не было в архиве Reunion. Для каждой проверены CRC исходного ZIP и вложенного JAR. Сверка хешей отдельно подтвердила, что ZIP, JAR и нативный `client.bin*` ранее не сохранялись. Структурный поиск SGS по обоим слоям совпадений не дал. [Архив пяти игр](../research/archives/Dubigame-MapleStory-My-Princess-Skipping-Stone.zip) · [Идентификаторы, хеши и прогоны](../validation/dubigame-maplestory-and-skipping-stone.json)

| Игра                                | ID и версия KTF        | Проверенная сцена                                                                                                                                  |
| ----------------------------------- | ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| My Princess 2                       | `PD005261`, `01.00.00` | OK подтверждает новую игру и открывает экран персонажа. [Вложение](https://dubigame.tistory.com/52)                                                |
| MapleStory, маг                     | `PD001295`, `01.00.06` | OK продвигает диалог в пещере. [Вложение](https://dubigame.tistory.com/58)                                                                         |
| MapleStory, воин                    | `PD002198`, `01.00.05` | OK продвигает диалог на крепостной стене. [Вложение](https://dubigame.tistory.com/59)                                                              |
| MapleStory 2007                     | `PD005263`, `01.00.01` | Нажатие вправо разворачивает персонажа на первой игровой сцене. [Вложение](https://dubigame.tistory.com/60)                                        |
| Skipping Stone 3 / 물가에 돌튕기기3 | `PD005691`, `01.00.04` | Клавиша `*` пропускает вступительную сцену и открывает карту. Бросок камня в этом прогоне не проверен. [Вложение](https://dubigame.tistory.com/62) |

В архиве для каждой игры есть парные сценарии ARAM. Они дают одинаковый кадр перед последним действием, а результат нажатия сравнивается с ожиданием на том же виртуальном кадре. Разрешение берётся из `__adf__`: 176 × 220 либо 240 × 320. Сборки можно открыть в ARAM. [Ревизия ARAM](https://github.com/mirusu400/aram-core/tree/fea299cba15696ed1460f965b76626d6edab5e03)

Skipping Stone 2 из соседней записи совпала с ранее сохранённым ZIP. Версии Mini Game Heaven 1, 2 и 4 на Dubigame также совпали с копиями из архива WIPI-X. Для третьей части совпадение найдено в ранее сохранённой подборке Dubigame.
