# Игры и Java-модули LG KH1000, KH1200 и KH1800M

Сохранены три сервисные сборки LG. У всех проверены внешние 7z и вложенные CAB. После распаковки KDZ и WDB получены все записи, объявленные в индексе каждого WDB. [Хеши, размеры, смещения и источники](../validation/lg-kh1000-kh1200-kh1800m.json)

| Телефон | Сборка     | Записей WDB | Извлечённое содержимое                                                                           |
| ------- | ---------- | ----------: | ------------------------------------------------------------------------------------------------ |
| KH1000  | `KW100616` |         937 | Racing Time, Sudoku Puzzle, меню `Game.pxo` и четыре модуля `KWipi*`.                            |
| KH1200  | `KW120615` |         697 | `Java.pxo`, `JavaBg.pxo`, `JavaSv.pxo`. Подтверждённых игр в образе нет.                         |
| KH1800M | `KW18M809` |        1945 | Grand Golf, Mobile Jjangi, Sudoku Puzzle, ZooZoo Club, игровое меню, ресурсы и Flash-жеребьёвка. |

Названия взяты из игровых модулей или их меню. Все шесть игровых PXO отличаются от вариантов в ранее опубликованных архивах Reunion. У KH1000 исходные файлы уже содержат `PXO4`, у KH1800M этот заголовок появился после распаковки. В обоих случаях проверены внутренние размеры и Thumb-код. Для запуска нужен телефонный API LG. [Предыдущие сборки Racing Time и ZooZoo Club](korean-phone-preservation-pass16.md#полученные-игры-lg)

`data.lkz` KH1800M совпадает с архивом ресурсов SH240 по SHA-256. Это ZIP с 435 файлами. Каждый файл проверен по CRC и SHA-256. Отдельный `Ladder.swf` из `Flash/ui/dutchpay` содержит обработчики построения лестницы и получения результата. Проверены длина развёрнутого SWF, границы тегов и присутствие ActionScript. Сам SWF сохранён в исходном виде.

## Java и границы поиска

В KH1200 по смещению `0x90D64` основного BIN рядом находятся `MIDlet-Name`, `MIDlet-Vendor`, `JAM` и `com.aroma.ams.jam.Main`. Три извлечённых Java-модуля — нативные `PXO4`. Современная выпуску публикация описывала запуск Java-игр с карты памяти этого телефона. В проверенных файлах сервисной сборки нет JAR с валидным ZIP и манифестом MIDlet, отдельных JAD или структурно корректных SGS. [Поддержка LG KH1200](https://www.lge.co.kr/support/product-LGKH1200) · [ETNews, май 2007 года](https://www.etnews.com/200705170052)

Сканер проверил все извлечённые файлы, распакованные игровые PXO, MAIN KH1800M, файлы LKZ, развёрнутые потоки SWF и локализации. Положительный контроль прошли все 94 SGS библиотеки. Четыре `KWipi*` в KH1000 сохранены как компоненты платформы. Телефонный проигрыватель GNEX из них не выделен. Поиск ограничен известными форматами и этими сервисными сборками.

## Распаковка MAIN KH1800M

`M6280_KH180M.bin` содержит ARM ELF со смещения `0x220`. Первые 8192 байта ELF сохраняются дословно, затем идут 166 LZO1F-слотов по 128 КиБ. Последний слот короче. Распаковка дала 37 051 164 байта, все сегменты уложились в границы результата. Скрипт проверяет объявленную длину обёртки, таблицу программных заголовков ELF, окончание каждого потока LZO и точный размер его выхода.

```sh
python tools/unpack-lg-flat-main.py M6280_KH180M.bin KH1800M-main --wrapped-elf --lzo-library /path/to/liblzo2.so
```

Режим без `--wrapped-elf` предназначен для исходного плоского формата. Повторная проверка дала прежний SHA-256 распакованного MAIN SH170. [Формат плоского MAIN и инструменты извлечения WDB](lg-sh170-games.md#файлы-и-повторная-проверка)
