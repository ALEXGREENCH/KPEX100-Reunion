# 119 Rescue на Samsung Anycall

Оригинальный `119_구조대.mbin` из Anycall Land дошёл до первого уровня. После кода кнопки 6 команда с носилками сдвинулась вправо. В контрольном прогоне с тем же числом тактов она осталась на месте. На 210-м показе кадра различаются 494 пикселя. [Кадры и манифест](../research/archives/Samsung-Anycall-119-Rescue-Replay.zip) · [Исходный архив игр](../research/archives/Samsung-Anycall-ADS-MBIN.zip)

Игра загружает 113 изображений MQ. Для этого сценария событие 5 получает аргумент 1. Гостевой обработчик по адресу `0xf40032a6` проверяет аргумент перед обновлением сцены. Службы `+0x7c`, `+0x98` и `+0x8c` в пробном хосте задают цвет, рисуют прямоугольник и линию. Служба `+0x48` возвращает синтетическое время в единицах показанных кадров. Штатную частоту таймера, звук, сохранения и прохождение остальных уровней пока не проверяли.

```sh
python -m pip install unicorn==2.1.4 Pillow==13.0.0
python tools/replay-anycall-jumping-baby.py research/archives/Samsung-Anycall-ADS-MBIN.zip rescue-replay --game 119-rescue
```

Инструмент также принимает исходный MBIN и сверяет SHA‑256 перед исполнением. [Скрипт](../tools/replay-anycall-jumping-baby.py) · [Проверка архива](../validation/anycall-119-rescue.json)
