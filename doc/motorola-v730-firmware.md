# Motorola V730 AOne R-UIM

Сохранены пять оригинальных 7z из каталога V730, по одной сборке
`19.03.12`, `19.03.13`, `19.03.17` и две сборки `19.03.19`.
Архивы прошли проверку CRC, хеши распакованных BIN сверены отдельно.
В каждом BIN есть внутренние строки `AONE R-UIM`, версия и `V730`.
[Каталог прошивок](<https://firmware.center/firmware/Motorola/V730%20(AOne_RUIM)/Flash%20Files/>),
[ZIP с оригиналами](../research/archives/Motorola-V730-AOne-RUIM-Firmware.zip).

| Сборка          | Байты BIN |
| --------------- | --------: |
| 19.03.12        | 6 268 092 |
| 19.03.13        | 6 268 092 |
| 19.03.17        | 6 202 556 |
| 19.03.19        | 6 202 556 |
| 19.03.19, 8 МиБ | 8 388 608 |

Корейская таблица SKT указывает GVM2X для V730(Aone). Xobject также
назвал V730 телефоном, на котором проверял «묵!찌!빠!». Для найденных
R-UIM-файлов точное соответствие операторской сборке автора пока неизвестно.
[Историческая таблица телефонов](gvm-historical-handsets.md),
[публикация игры](gvmclub-2003-games-wayback.md).

Сканер проверил 33 329 904 байта и 1 817 684 смещения. Он искал полный
SGS v1/v2/v4/v36 в обычном виде и с XOR `0xa5`, включая известную
раскладку сжатого v4. Контейнеров SGS не найдено. Совпадения строки
`GVM` лежат внутри последовательностей байтов без подтверждённой
связи с движком.

У версии 19.03.19 первые 6 202 556 байт 8-МиБ файла отличаются от
короткого BIN в четырёх соседних позициях. В дополнительных 2 186 052
байтах найдены 26 сигнатур локальных записей ZIP. Шесть записей прошли
распаковку, сверку размеров и CRC. У них три уникальных содержимых:
два манифеста `LianQu90` и `XiangYue98` с MIDP 1.0 / CLDC 1.0
и класс `Kara.class`. Полные JAR из этих байтов пока не собраны.
Архив сохраняет извлечённые записи отдельно от оригиналов.
[Смещения, CRC и SHA-256](../validation/motorola-v730-firmware.json).
