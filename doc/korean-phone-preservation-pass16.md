# Новые прошивки Samsung и LG: оригиналы и игровые модули

7 ноября 2026 года сохранены **11 исходных 7z** из публичного архива
[Sunderland93](https://archive.sunderland93.ru/Firmwares/). У всех проверены
структура, CRC, размеры и SHA-256. Исходные загрузки не изменялись.
[Машинный отчёт](../validation/korean-phone-preservation-pass16.json) связывает
каждый файл с URL, временем получения и результатами разбора.

| Каталог модели   | Полученные варианты          | Что проверено                                                               |
| ---------------- | ---------------------------- | --------------------------------------------------------------------------- |
| Samsung SCH-E170 | E170Stock                    | BIN, внутренние обозначения модели, SGS и строки GVM                        |
| Samsung SCH-E250 | SamsungSCH-E250_orig         | BIN, внутренние обозначения модели, SGS и диагностические строки GVM        |
| Samsung SCH-V450 | sch-v450                     | BIN, внутренние обозначения модели, SGS и строки GVMINFO                    |
| Samsung SCH-V600 | v600_memdump / v600-test.bin | Только полученный образ; внутреннее обозначение V600 не подтверждено        |
| Samsung SCH-V740 | ZB21, ZG27                   | Оба полных полученных BIN, маршрутизация GNEX/GVM и другие записи Sinjisoft |
| LG SH100         | SW100617                     | KDZ → CAB → WDB, 905 файлов                                                 |
| LG SH110         | SW110612_memory, SW110617    | Отдельный образ памяти и KDZ → CAB → WDB, 1084 файла                        |
| LG SH210         | SW210721                     | KDZ → CAB → WDB, 2181 файл; первый компонент MAIN распакован                |
| LG SH240         | SW240814                     | KDZ → CAB → WDB, 1919 файлов; первый компонент MAIN распакован              |

Имена каталогов и суффиксы `orig`, `Stock`, `factoryreset` сохранены как
атрибуты источника. Они не удостоверяют полноту заводского дампа.
Внутри образов встречаются также имена других телефонов: это не повод
переименовывать модель. Геометрия NAND не угадывалась по размеру файла,
служебные байты из Samsung V740 не удалялись.

## Полученные игры LG

Из WDB извлечены **14 файлов `Game*.pxo`**, включая четыре меню.
У шести уже есть незапакованный заголовок `PXO4`; восемь распакованы
без выполнения кода телефона, через открытый safe-декодер LZO 2.10.
Внутренние размеры и границы метаданных проверены во всех 14 результатах.

| Модель | Реально присутствующие игровые модули    |
| ------ | ---------------------------------------- |
| SH100  | Racing Time, Sudoku Puzzle               |
| SH110  | Racing Time, Sudoku Puzzle               |
| SH210  | Eye Shot, Mini Mini                      |
| SH240  | Grand Golf, JjangiV, Sudoku, ZooZoo Club |

Названия Racing Time, Sudoku Puzzle, Eye Shot и Mini Mini прочитаны в
исходных меню или распакованных модулях. В Racing Time присутствуют титры
**LG SoftLab Spb**. Модули Racing Time у SH100 и SH110 имеют одинаковый
размер, но разные SHA-256. Меню SH210 ссылается ещё на Grand Golf, однако
такого файла в этом WDB нет. Для JjangiV сохранено имя файла без догадки
о точном коммерческом названии.

Сохранены также оригинальные внешние игровые ресурсы. `data.lkz` SH240 —
ZIP с **435 файлами**, у каждого проверен CRC и записан SHA-256.
PXO требуют отдельного телефонного API; в библиотеку запускаемых SGS
они не добавлены. Их принадлежность Sinjisoft не установлена.

## Запись телефонного GNEX в SH110

В образе SW110612_memory и основном BIN SW110617 найден один и тот же
189-байтный фрагмент с проверенными 32-битными длинами полей:

```text
CONTENT / A000200001 / application/x-wipi-app
GNEX / Sinjisoft Co.,Ltd / 036.016.000
EXECUTABLE / PLAYER / MULTI-INSTANCE
application/x-gnex-sgs
```

SHA-256 фрагмента:
`134a0439501a296da48f1008c488f407343766d7919dbed0dc647fcd98a630b3`.
В комплекте сохранены байты, абсолютные смещения и разобранные поля.
Неизвестные числовые значения и шесть дополнительных байтов оставлены
неинтерпретированными. Это свидетельство регистрации GNEX в двух образах,
**не восстановленный самостоятельный установщик или границы его кода**.
Записи PhotoOn2/NATEAIR с именем Sinjisoft в других моделях не объявляются GNEX.

## MAIN и покрытие поиска SGS

Первый компонент MAIN SH210 и SH240 использует LZO1F-слоты по 128 КиБ.
После неизменённого ELF-префикса проверены все блоки, точные размеры выхода
и границы всех сегментов. Результаты: 44 119 868 и 36 653 852 байта.
Вторые компоненты начинаются с `txPI`; они сохранены отдельно, их формат
не объявляется полностью разобранным. SH100/SH110 имеют другой MAIN
с плоским ARM-телом, к ним этот декодер не применялся.

Поиск известных SGS v1/v2/v4/v36, обычных и XOR-A5, выполнен по семи
сырым BIN, 6039 извлечённым файлам/слоям LG, 14 результатам PXO и 435
внутренним ресурсам LKZ. Подтверждённых SGS нет. Это не исключает иной
упаковки, формата или встроенного интерпретатора. Большие файлы проверены
целиком окнами 64 МиБ с перекрытием 32 МиБ; учитываются полные SGS до
32 МиБ. Пограничные проверки прошли в 48 случаях, положительный контроль —
все 69 SGS текущей коллекции.

Переносимый `recover-cyon.py` повторно воспроизвёл точные байты 22 выходов:
четырёх CAB, четырёх компонентов двух MAIN и 14 PXO. Для обоих проходов
использован один и тот же открытый примитив LZO; это проверка реализации
обёртки, а не независимый алгоритм распаковки. Исторические DLL не загружались.

В последнем комплекте — переносимый скрипт, исходники LZO с GPL, проверенная
самостоятельно собранная библиотека и рецепт сборки для Windows/Linux.
`README.md` задаёт команды KDZ, WDB, MAIN и PXO. Сессионные вспомогательные
скрипты тоже сохранены, но явно отделены: у них есть привязки к рабочим путям.
Собственный загрузчик [`preserve-firmware-files.py`](../tools/preserve-firmware-files.py)
принимает явный JSON со ссылками и происхождением, сохраняет ответы и
квитанции, проверяет кеш по хешу; повреждённые и ошибочные ответы не кеширует
как успешные загрузки. Примеры списка URL находятся внутри комплектов.

Ранние SDK **1.20/1.40** и отдельный телефонный GNEX-плеер пока не восстановлены.
Новая запись SH110 — конкретная зацепка для следующего разбора встроенного кода.
