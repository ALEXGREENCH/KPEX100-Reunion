# Samsung SCH-X850: получены два оригинальных сегмента

Впервые получен [SCH-X850.zip из коллекции Internet Archive](https://archive.org/download/gt-b-7722_20250528/SCH-X850.zip):
2 202 301 байт, SHA-256
`a15ee054c8fc668e9837078b818194feda1f5cfb8003440f650e5d25a1826361`.
Размер и SHA-1 совпали с метаданными коллекции; ZIP и вложенный `X850.7z`
прошли CRC. Прошивка читалась как данные, оригинальный код не запускался.
[Полный отчёт, источники и результаты сканера](../validation/samsung-x850-round4-evidence.json).

| Оригинальный файл |     Байты | SHA-256                                                            |
| ----------------- | --------: | ------------------------------------------------------------------ |
| `X850-Fb-Pt1.bin` | 8 385 808 | `0a4b74244d938516f09c4063648cdfd72e32f0aa7eee744d79bd93f1f5e9e222` |
| `X850-retry1.bin` | 3 670 000 | `11f1bb69965b80439d454feee37f9446fa09d449ae21dbef17213eba26859c77` |

В первом файле строка `SCH-X850  YB04` находится по `0x6ec4b0`.
Второй содержит `SCH-X850` по `0x2d848`, `GVM %s` по `0x2ba5e8`
и три пути `/skp/c/GVM/` по `0x2bc760`, `0x2d72c4`, `0x2dadb0`.
Это подтверждает модельные метки и следы хранения GVM в конкретных байтах.
Целый интерпретатор, версия VM и доступ к ускорителю этим не установлены.

В [сообщении о Formula Championship от 15 октября 2004 года](https://game.donga.com/21244/)
SCH-X850 уже был назван среди телефонов GNEX/GIGA. Это свидетельство
поддержки загружаемой игры. В [руководстве Samsung SCH-X850LY](https://manualzz.com/doc/4262613/samsung-sch-x850ly-user-manual),
стр. 134–135, загрузки Anycall отделены от встроенной Push-Push III.
Точное совпадение прошивки этих сегментов с вариантом LY не доказано.
В `X850-retry1.bin` есть строка `Push-Push`, но она не устанавливает
номер редакции или формат исполняемого файла.

## Что проверено и что остаётся

Ограниченный сканер проверил оба файла на SGS v1/v2/v4/v36 в открытом
виде и с XOR-A5: **307 999 возможных смещений, ноль принятых контейнеров**.
Все **65 из 65** SGS-контролей коллекции прошли проверку. Узнаватель
точных таблиц уровней Push Push I/II/III также не принял ни одной таблицы.
Другие редакции, упаковка, фрагментация и нативные игры этим не исключены.

Исходные адреса flash, отношение двух файлов, пересечения и полнота пока
не установлены. Образы не склеивались, отсутствующие байты не достраивались.
Полное отсутствие игр в памяти телефона не заявляется. Новых файлов
для игровой библиотеки Reunion в этом проходе нет.

Прямой каталог Sunderland для SCH-X850 дал ссылку на `X850.7z`, но две
попытки соединения с файлом завершились тайм-аутом; байты удалось получить
через Internet Archive. Проверка каталога SCH-E350 дала HTTP 404.
Эти ответы относятся к конкретным маршрутам, а не ко всем возможным архивам.

Для повторения сканирования распакуйте оба вложенных архива как данные
и выполните из корня репозитория:

```sh
python tools/scan-firmware-games.py /path/to/X850-Fb-Pt1.bin /path/to/X850-retry1.bin --check-controls --output x850-scan.json
```

Контрольные SGS уже включены в репозиторий. Выходной JSON должен быть новым
файлом: инструмент не перезаписывает существующие результаты.
