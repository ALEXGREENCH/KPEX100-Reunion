# Merry Christmas, Mr. 라면왕 и 우동타임 на Samsung Anycall

Все три сборки из папки `버전 다름` оригинального Anycall Land дошли до первого уровня. В архиве сохранены сами три MBIN, кадры меню и уровня, контроль без ввода и отдельный кадр для каждой проверенной кнопки. Начальные кадры перед вводом совпадают побайтно. После ввода оба прогона получают одинаковое число событий таймера. [Игры, кадры и манифесты](../research/archives/Samsung-Anycall-Merry-Ramen-Udon-Replays.zip) · [Полный архив Anycall Land](../research/archives/Samsung-Anycall-ADS-MBIN.zip)

Игры открываются из вкладки «Игры» в Reunion. Веб-версия исполняет оригинальный MBIN в ARM/WASM Worker. Для запуска достаточно самого MBIN. В source-only сборке импортируйте проверенный файл из папки `original/` через «Добавить файлы». Встроенные кнопки телефона, клавиатура и переназначение работают через обычное управление Reunion. Enter и Z подтверждают выбор. [Веб-библиотека](https://alexgreench.github.io/KPEX100-Reunion/)

Крестовина передаёт родные коды ADS 10–13. Это позволяет перемещаться по меню в Mr. 라면왕 и 우동타임, сохраняя отдельные цифровые клавиши для игрового поля.

| Игра                                | Проверенный ввод                                                                                                            |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Merry Christmas (`메리 크리스마스`) | 2 поднимает сани, 4 сдвигает их влево, 6 вправо. Стрелки дают те же движения.                                               |
| Mr. 라면왕                          | 1–9 выбирают конфорки, 0 открывает склад, `#` показывает заказы. Чтобы подать готовую порцию, откройте заказы и нажмите OK. |
| 우동타임 (Udon Time)                | Цифры выбирают кастрюли. В проверенном сценарии очки набирались через 2, 5, 6 и 8.                                          |

В Merry Christmas после поражения игра вернулась в меню. Следующее нажатие OK открыло тот же стартовый кадр, а стрелка вправо снова сдвинула сани. В Mr. 라면왕 восемь поданных заказов завершили первый уровень. После подтверждения игра показала рецепт и активные конфорки второго уровня. В 우동타임 контроль без ввода завершился с нулём очков, а серия из 51 нажатия принесла 49 очков. После Game Over два нажатия OK вернули игру на кухню с нулевым счётом. Расширенные прогоны сверены по кадрам между ARM/WASM и Python Unicorn. [Последовательности кнопок и хеши](../validation/anycall-extended-play.json) · [Кадры и сценарии в ZIP](../research/archives/Samsung-Anycall-Extended-Gameplay-Replays.zip)

В Mr. 라면왕 оригинальный код задаёт 120 × 144 и в прямоугольнике вывода (`0xf40000e6`), и в описателе LCD (`0xf400014e`). Полный кадр показывает нижний ряд из трёх конфорок и подписи в инструкции по управлению. Старые кадры в ZIP сохраняют верхние 128 строк. Для новой проверки записаны хеши всех 144 строк.

При переходе между уровнями Mr. 라면왕 вызывает `+0x0c` из `0xf4005d19` с указателем `0xf5005f48`. Эмулятор подтверждает этот вызов. Прогресс хранится в памяти игровой сессии.

Рисование использует пробную палитру RGB332 и синтетическое время. Для 우동타임 служба `+0x40` получает границы диапазона и возвращает 16-битное число в буфер вызывающей стороны. Фиксированный seed обеспечивает повторяемость прогона. [Проверки оригинальных звуковых фрагментов](samsung-anycall-ads-mbin.md#звук-ads)

В браузерном хосте бюджет проверяется по блокам ARM/Thumb. В пяти парных замерах Node переход от счётчика инструкций к блочному бюджету уменьшил медиану времени этих сценариев на 33,5–37,7%. Замеры включают обработку ввода, таймеров и конвертацию изменившихся кадров. Конечные кадры и число показов совпали. [Измерения](../validation/ads-watchdog-performance.json)

```sh
python -m pip install unicorn==2.1.4 Pillow==13.0.0
python tools/replay-anycall-jumping-baby.py research/archives/Samsung-Anycall-ADS-MBIN.zip merry-replay --game merry-christmas
python tools/replay-anycall-jumping-baby.py research/archives/Samsung-Anycall-ADS-MBIN.zip ramen-replay --game mr-ramen
python tools/replay-anycall-jumping-baby.py research/archives/Samsung-Anycall-ADS-MBIN.zip udon-replay --game udon-time
```

Вместо общего ZIP можно передать скрипту соответствующий MBIN из папки `original/` нового архива. Сценарии воспроизводятся локально и сверяют SHA‑256 перед исполнением. Тест веб-ядра повторяет все 15 сценариев с кнопками и три контрольных прогона, сверяя индексные кадры с архивом.
