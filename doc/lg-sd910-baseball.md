# LG SD910. 2007 Pro Baseball v1.0.4

В библиотеку добавлен оригинальный SGS из дампа SX910610. Все 799 652 байта
сохранены с 32-байтной обёрткой. Это другая сборка 2007 Pro Baseball:
байткод отличается от ранее включённого SGS, а 4299 ресурсных блоков совпадают.
[Игра](../web/data/games/2007-pro-baseball-lg-sd910.sgs) ·
[Образ SX910610](https://archive.sunderland93.ru/Firmwares/LG/SD910/SX910610_jtag.7z) ·
[Извлечение EFS2 и хеши](../validation/lg-sd910-baseball-evidence.json).

Для начала матча выберите `게임시작` (начать игру), затем `일반모드`
(обычный режим). Выбор подтверждается Z или экранной OK. В первом
иннинге клавиша 5 вызывает замах. Парные прогоны с общим стартовым
вводом и одинаковым виртуальным временем дали 17 различающихся кадров
после дальнейших нажатий 5. В этих прогонах проверялась игра за бьющего
в первом иннинге. Параметры 176×220 и виртуальный идентификатор заданы
в каталоге для этой сборки.
[Сценарий и парные контрольные кадры](../validation/lg-sd910-baseball-playback.json).

## Справка и поиск цвета

Старый сценарий с движением вниз в главном меню выбирает `도움말`
(справку). На этом экране один кадр превышал обычный лимит в 20 млн
единиц работы ARM. Горячий участок — перебор ближайшего цвета для
`SetColorRGB` в Kingston 2.12.

Ускоритель обрабатывает средние итерации поиска за одно чтение палитры.
Последняя итерация по-прежнему проходит в ARM, сохраняя результат,
регистры, флаги и байты стека. Виртуальные часы учитывают пропущенные
ARM-инструкции. Сторожевой лимит отдельно учитывает работу ограниченного
поиска. Ускоритель сверяет ROM и участки машинного кода перед установкой.

Локальный прогон в Windows / Node.js сравнил два исполнения по 136 событий.
Старому пути для полного прогона дали временный лимит 100 млн. Новый путь
прошёл с обычными 20 млн. Медиана времени кадра справки на интервале
4350–5350 виртуальных мс снизилась с 221 до 130 мс. Хеши двух контрольных
кадров, счётчики вызовов VM и виртуальных инструкций совпали.
[Данные прогона](../validation/lg-sd910-baseball-playback.json).

```sh
node tools/replay-sgs.mjs 2007-pro-baseball-lg-sd910 validation/lg-sd910-baseball-playback.json replay-sd910
```
