# Dadumbi и пять игр в каталоге NATE

Сохранились 19 снимков сайта Dadumbi с 2002 года, включая девять оригинальных GIF и JPEG. SHA‑1 каждого тела совпал с индексом Wayback. В комплекте есть исходные HTML в корейской кодировке, HTTP-заголовки, записи CDX, журнал запросов и манифест с SHA‑256 и CRC32. [Скачать комплект](../research/archives/Dadumbi-NATE-GVM-Catalogues-and-Media.zip) · [Проверка снимков](../validation/dadumbi-nate-gvm-catalogues.json)

Страница CU@지하철 связывает игру с NATE и показывает цену в 1500 вон. С неё восстановлены четыре анимации 120×106. В превью 19 кадров, в остальных трёх файлах 4, 7 и 8 кадров. Для A Scary Game сохранились карточка за 1000 вон и отдельная инструкция. [CU@지하철](https://web.archive.org/web/20021021182623id_/http://www.dadumbi.com/nate_subway/) · [A Scary Game](https://web.archive.org/web/20021008223628id_/http://www.dadumbi.com/nate_horror/)

Страница Super Board показывает три эпизода по 1500 вон и три соответствующих JPEG. Издатель Game Chosun объявил запуск через SK Telecom 1 июня 2002 года. [Выбор эпизода](https://web.archive.org/web/20020806182656id_/http://www.dadumbi.com/nate_super/super_kind_down.html) · [Объявление издателя](https://www.chosun.com/site/data/html_dir/2002/06/07/2002060770175.html)

| Название в NATE | Жанр по объявлению издателя |
| --------------- | --------------------------- |
| 삼형제 대격투   | Пошаговый бой               |
| 사오정VS저팔계  | Шутер от первого лица       |
| 삼장구출작전    | Экшен с боковой прокруткой  |

Кнопки ведут через `GVMManageServlet` с командой `Device_Info`. В страницах сохранились три обратных адреса в `/vm/gvm/`: `subway/sw_bill.php?v_online=yes&sp_page=4`, `horror/m.php?v_online=yes` и `super/m.php?v_online=yes`. Архивные GET-запросы к этим адресам вернули HTTP 404. Два восстановленных PHP-ответа Super Board содержат форму и короткое сообщение о ключе. Исполняемых файлов игр в полученных ответах нет.
