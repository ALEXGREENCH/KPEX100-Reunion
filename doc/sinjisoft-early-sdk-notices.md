# Ранние объявления Sinjisoft и поиск по сохранённым страницам

6 ноября 2026 года опубликован следующий неизменяемый снимок очереди
GNEX Club, GVM Club, Sinjisoft и выбранных сообществ. Он содержит
**43 877 записей CDX, 1 715 совпавших ответов и 1 854 объекта HTTP**.
Часть объектов — ответы ошибок и исходные страницы индекса; это не
1 854 руководства или скачанных программы. Полный сбор сайтов ещё не завершён.

Состояния задач в снимке: 1 715 `verified`, 143 `mismatch`, 22 `retry`,
41 997 `pending`. Среди ответов с правильным digest есть исторические
перенаправления и ошибки: совпадение не превращает их в найденный файл.

- [Снимок очереди Pass 3](../research/archives/GNEX-GVM-Wayback-Partial-Pass3-20261106.zip):
  29 014 805 байт, SHA-256 `bebe1e1a6f9f02c3ee0dc5c0ccaa726b582228d4ad6c9d5a27c4090d1a988548`.
- [Объявления и поисковый индекс](../research/archives/Sinjisoft-Early-SDK-Notices-and-Search-Index.zip):
  1 067 313 байт, SHA-256 `3537e428ba24d87edd975cf048cd0751dbbd8736871a3bc0ec9fea8bc5172cf7`.

[Проверка снимка](../validation/wayback-partial-pass3.json) охватывает CRC
1 864 файлов и SHA-256 1 863 записей манифеста.
[Проверка подборки](../validation/sinjisoft-early-notices.json) — CRC 35 файлов,
SHA-256 34 записей, происхождение семи выбранных HTML и сравнение с предыдущим комплектом.

## Что добавилось

Все **43 696 буквальных записей CDX** из опубликованного Pass 2
перепроверены как неизменённое подмножество. В том снимке было 423 задачи
`verified`; теперь их 1 715. Дополнительные 181 записи индекса связаны
с ранее документированным [алиасом Chamcham](gvm-technical-library-pass.md).

По сравнению с прямыми файловыми членами предыдущих 38 архивов в новом
снимке **1 271 ранее не публиковавшийся SHA-256 объекта ответа**.
Для корпоративных доменов Sinjisoft — 966 совпавших ответов,
904 различных тела; 701 из этих хешей не встречался в предыдущих архивах.
Это количество байтовых версий ответов, а не новых статей: сохранены
также формы, страницы ошибок с HTTP200, перепечатки и форумный спам.
Все эти типы остаются в исходном снимке и не объявляются пресс-релизами компании.

## Офлайн-поиск по корейским оригиналам

[wayback-text-index.py](../tools/wayback-text-index.py) читает замороженный
ZIP без распаковки файлов на диск. Индексируются только HTML с HTTP200
и статусом `verified`; перед чтением текста повторно проверяются SHA-256
объекта и SHA-1 CDX. Скрипты и стили не исполняются, ссылки не открываются.

Готовый `derived/wayback-text-index.json` в подборке объединяет
**1 488 снимков в 1 449 разных HTML-тел**, сохраняя ссылки на все снимки.
Шесть тел имеют явно отмеченную потерю символов при декодировании.
Исходные байты остаются в полном снимке. Метка EUC-KR обрабатывается
как корейская веб-кодировка CP949 с расширениями; выбранная кодировка
и исходная декларация записываются отдельно.

```sh
python tools/wayback-text-index.py build research/archives/GNEX-GVM-Wayback-Partial-Pass3-20261106.zip --output wayback-index.json
python tools/wayback-text-index.py search wayback-index.json "SDK"
python tools/wayback-text-index.py search wayback-index.json "개발"
python tools/wayback-text-index.py search wayback-index.json "SWAP151"
```

Выходной индекс при сборке должен быть новым. Поиск буквальный,
без учёта регистра, с нормализацией корейского текста NFC.
Совпадение слова не подтверждает ни подлинность содержимого сообщения,
ни наличие игры, SDK или телефонного проигрывателя. Индекс — производное
средство поиска; исходный ZIP и его квитанции остаются первоисточником.

SDK GNEX 1.20/1.40, `GVM_SDK_v152_031222.zip` и самостоятельный
телефонный GNEX-плеер в этом проходе не восстановлены. Объявления,
недоступные ссылки и точные статусы продолжают храниться отдельно
от проверенных загрузок.
