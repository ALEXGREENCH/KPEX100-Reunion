# MA1: музыка и эффекты Hellfire

Raw MA1 теперь воспроизводится в отдельном аудио-Worker. Поддержаны четыре
монофонические партии, исходные двухоператорные тембры, ноты, паузы,
смена тембра, gate и tie/slur. Это применяется к прямому запуску SGS;
звуковой кодек полной машины с прошивкой здесь не добавлялся.

Пять MA1-ресурсов **Kingston Hell Fire** и **Hellfire WI-TOP** побайтово
совпадают. Оба оригинальных SGS сохранены без правок. Они вызывают
альтернативы зуммера и MA1; в их настройках запуска задан `nativeSoundType: 1`,
чтобы отфильтровать зуммер. Без выбора устройства быстрый кешированный
зуммер мог успеть прозвучать перед заменой на MA1.

Этот параметр задаёт виртуальный звуковой вариант. Он не устанавливает
точную модель телефона и не зависит от корпуса, выбранного пользователем.
Разрешение, ввод и исполнение VM остаются прежними. Для импортированных
файлов без такого параметра сохраняется порядок звуковых вызовов программы.
Значения `0` и `1` выбирают зуммер или MA1; остальные звуковые форматы
этим параметром не фильтруются.

## Модель звука

[ma1-render.js](../web/engine/ma1-render.js) использует регистровые тембры
самого ресурса. Поддержаны MULT, TL, AR/DR/RR/SL, EGT, SUS, полуволна,
вибрато и обратная связь несущего оператора. Таблицы номинального времени
огибающей и частоты сопоставлены с ранее сохранённым руководством Yamaha
YMU757B B2. Ноты размещаются на номинальной временной шкале;
задержки WinMM из [эталона SDK](gvm-ma1-native-reference.md) не копируются.

Вычисления FM, индекс фазовой модуляции, поведение при повторной атаке
и односэмпловая задержка обратной связи приближены. Огибающие линейны
в децибелах; точная внутренняя кривая микросхемы не восстановлена.
Фильтр AC-связи на выходе также является приближением. Это рабочий
рендерер по параметрам ресурса, без заявления о побитном совпадении
с физическим телефоном или его динамиком.

Неоднозначные нулевые интервалы пауз следуют подтверждённой в SDK
конвенции `0/B → 0`; противоречие таблиц руководства остаётся отмеченным
в предыдущем отчёте. Зарезервированная высота ноты вызывает ошибку
декодирования. Пустой поток останавливает предыдущее воспроизведение.

Синтез и упаковка WAVE периодически отдают управление и проверяют отмену.
Вход, длительность и выход ограничены; максимум — три минуты на запрос.
Кеш использует формат и SHA-256, поэтому SMAF, зуммер и MA1 не смешиваются.
VM передаёт собственную копию байтов; изменение исходного массива после
отправки не меняет запрос. Исходные ресурсы в каталоге не преобразованы.

## Проверки

- Измерены частоты 220/440/880 Гц при изменении MULT и ослабление TL16 на 12 дБ.
- Проверены номинальные AR13 9,30 мс, RR14 8,94 мс, EGT и SUS.
- Проверены одновременные партии, прекращение старого gate паузой,
  смена тембра, длины, отмена во время рендера и упаковки WAVE.
- Все пять оригиналов дали разные ненулевые PCM без усечения.
- Проверены маршрутизация обоих исходных SGS, фильтрация альтернативы,
  копирование байтов, кеш и отказ CLI перезаписывать выходной файл.

Два локальных прогона Chrome использовали настоящий Worker VM, ROM, SGS
и аудио-Worker. За примерно 25,5 секунды каждый получил 164 кадра и
78 переходов клавиш; в Web Audio декодировались музыка и эффекты MA1.
Уровни 100/50/0/40% проверены по фактическому gain, измерительный узел
зафиксировал ненулевой сигнал. LCD оставался на месте. Это программные
прогоны, без прослушивания реального динамика телефона.

Десять PNG при 215 одинаково запланированных событиях побайтово совпали
с checkout до изменения аудио. Это проверка изображения и ввода данного
сценария, без полного прохождения или решения всех случайных зависаний.
[Результаты и границы проверки](../validation/gvm-ma1-playback.json).

В исходном `web/data/availability.json` также восстановлена запись
WI-TOP Hellfire: все 82 оригинальных файла проверены по хешам.
Теперь он доступен и при локальном `npm run dev`; полная Pages-сборка
и ранее генерировала актуальный список автоматически.

## Преобразование для исследования

Node.js 22+, полный checkout:

```sh
node tools/render-ma1.mjs web/data/games/hellfire-witop-v1.sgs 45 theme.wav
node tools/render-ma1.mjs resource-45.bin another-theme.wav
node --test tests/unit/ma1-render.test.mjs tests/gvm-ma1.test.mjs tests/gvm-buzzer.test.mjs
```

Выходной файл должен быть новым. CLI выводит хеши входа и WAVE, длину,
частоту дискретизации, пик и измеренное время обработки. Пять WAVE из
комплекта — производные рендера, а не вновь найденные оригинальные записи.
