# Игры из LG CYON KH1800

В сервисной сборке `KW180713` сохранились пять нативных игр. В `MODULE/C/` лежат Baduk, Rhythm Cooking, Grand Golf, Sudoku Puzzle и `Game_JjangiV.pxo`. В самом распакованном `Game_JjangiV.pxo` встречаются строки `Mobile Jjangi` и `Jjangi2 Game`. Это другой бинарник, чем извлечённый ранее из SH240. [Исходный KW180713.7z](https://archive.sunderland93.ru/Firmwares/LG/KH1800/KW180713.7z) · [Материалы по SH240](korean-phone-preservation-pass16.md#полученные-игры-lg)

В `Game.pxo` осталась строка `Rainbow striker`. Путь к последнему модулю указывает на `Game_JjangiV.pxo`, а файла `Game_RainbowStriker.pxo` среди извлечённых записей нет. Состав игр определён по файлам и их заголовкам.

| Модуль               | В прошивке, байт | После распаковки, байт |
| -------------------- | ---------------: | ---------------------: |
| `Game_Baduk.pxo`     |          539 778 |              1 453 245 |
| `Game_Cooking.pxo`   |          777 623 |              2 085 813 |
| `Game_GrandGolf.pxo` |          290 770 |                561 257 |
| `Game_JjangiV.pxo`   |          699 230 |              1 511 281 |
| `Game_Sudoku.pxo`    |          103 334 |                398 757 |

Все пять PXO отличаются от сохранённых вариантов SH170, KH1600 и SH240 по SHA-256 распакованных файлов. `data.lkz` с 431 файлом ресурсов совпадает побайтно с SH170 и KH1600. [Игры SH170 и KH1600](lg-sh170-games.md)

Внешний 7z и внутренний CAB прошли проверку. Из WDB извлечены все 1669 записей по его индексу. В архиве сохранены исходный 7z, пять игр и меню в обоих видах, ресурсы, манифесты и смещения Thumb-кода. После декодирования LZO1F основной образ занимает 28 681 076 байт. Структурная проверка всех записей WDB, шести распакованных PXO и MAIN не выявила SGS. Для запуска PXO требуется телефонное окружение LG.
