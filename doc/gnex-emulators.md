# Сохранённые эмуляторы GVM / GNEX для Windows

5 ноября 2026 года собран отдельный комплект
[Sinjisoft-GVM-GNEX-Emulators-Recovered.zip](../research/archives/Sinjisoft-GVM-GNEX-Emulators-Recovered.zip): **91 170 938 байт**,
SHA-256 `68b37ec3514bcaac7443dc05262e1f72b081b477d7f1145a70c34c5a2918c7e7`.
Он сохраняет уже найденные программы, исходные установщики и материалы SDK.
Новые сетевые загрузки для этого прохода не выполнялись.
[Машиночитаемый реестр и результаты проверки](../validation/gnex-emulator-preservation.json).

Все три файла — Windows PE для x86 (`Machine=0x014c`). Одинаковый номер
версии двух GNEX EXE не означает одинаковые байты. Версия SDK также
отличается от версии PE-файла эмулятора.

Зеркальный GVM2X сохранён под исходным именем вложения
`2x_Cr256_Magic_expired_remove.exe`. Название указывает на модификацию;
он не объявляется нетронутым официальным релизом. Ссылка в реестре ведёт
на постоянный пост, временный подписанный URL CDN не распространяется.

Это исполнители виртуальной машины Mobile C/GVM/GNEX с профилями устройств.
Наличие профиля или скина не доказывает полной эмуляции процессора,
модема или прошивки соответствующего телефона. **Запуск этих программ на
современной Windows или Wine не проверялся.** Установщики и сами программы
Sinjisoft в ходе сохранения не исполнялись.

## Состав самостоятельного комплекта

В архиве 166 файлов: два неизменённых установщика, 153 выделенных файла SDK,
отдельный GVM2X, инструкции на русском и английском, карта происхождения,
SHA-256-манифест и инструменты статического восстановления.

- `original-installers/` содержит полные GNEX SDK 2.10 и 2.12. Их размеры
  и SHA-256 совпали с ранее сохранёнными дистрибутивами. Установщики
  сохраняют собственные встроенные примеры SDK; отдельные розничные SGS
  и дампы памяти в новый комплект не добавлялись.
- `SDK-2.10/` и `SDK-2.12/` содержат `Emulator.exe`, `EmulController.exe`,
  `GNEXIDE.exe`, Mobile C / MASM, сопутствующие DLL, INI, все скины,
  заголовки Include и четыре руководства каждой версии. Восстановлены
  объявленные MSI имена и относительные пути. Например, CAB File ID
  `cygintl_2.dll` становится исходным `cygintl-2.dll`.
- В `SDK-*/source-fragments/` сохранены 43 текстовых фрагмента без
  расширения с оригинальными CAB File ID. Это заголовки и фрагменты
  GNEX/MGL, палитр и шрифтов. Вместе с `SScript.h` они полезны для
  исследования ABI, но не объявляются полным собираемым исходником
  эмулятора. Файлы или исходники с именами M16VM/M32VM в проверенных
  дистрибутивах не обнаружены.
- `MASM.exe` — ассемблер, `mcc.exe` — компилятор. Они сохранены как
  инструменты разработки, их наличие не увеличивает число эмуляторов.
  `vsflex8l.ocx` сохранён в `SDK-*/system-companions/`; системная
  регистрация не выполнялась.

Имена и версии 16 основных инструментов, статические импорты DLL и
границы подтверждённого записаны в `provenance.json` внутри архива.
Системные DLL Windows не добавлены. Статический список импортов не
устанавливает все динамические зависимости и не гарантирует запуск
выделенного поднабора без установки. Исходные INI, включая демонстрационные
идентификаторы из дистрибутива, оставлены без изменений; новые личные
профили и сохранения не включались.

## Проверка и повторное извлечение

После распаковки из корня комплекта:

```sh
python tools/verify-bundle.py .
python tools/restore-sdk.py 2.12 restored-2.12 --seven-zip "C:/Program Files/7-Zip/7z.exe"
python tools/restore-sdk.py 2.10 restored-2.10 --seven-zip "C:/Program Files/7-Zip/7z.exe"
```

Нужны Python 3.11+ и установленный 7-Zip. Выходные каталоги должны быть
новыми или пустыми. Скрипт проверяет исходный установщик по SHA-256,
читает контейнер InstallShield, затем MSI и CAB как данные и восстанавливает
выбранные файлы по `sdk-member-map.json`. Установщик и MSI CustomAction
не запускаются. Формат контейнера независимо реализован в
[sdk-static.py](../tools/sdk-static.py) по описанию
[ISx](https://github.com/lifenjoiner/ISx).

Проверены CRC всех 166 ZIP-записей, чистая распаковка и SHA-256 всех
165 файлов манифеста. Из установщиков внутри распакованного архива заново
извлечены **71 файл SDK 2.10 и 82 файла SDK 2.12**; каждый побайтно совпал
с включённым экземпляром. Для 16 INI скинов проверены ссылки на BMP —
отсутствующих файлов нет. Повторная проверка подтвердила, что комплект
не изменился после этих операций. Это проверка сохранности и извлечения,
а не тест исполнения старых приложений.

Оригинальные программы, скины, заголовки и руководства сохраняют права
их владельцев и не перелицензируются под MIT Reunion. Новые инструменты
сохранения сопровождаются копией MIT-лицензии проекта.
