# Настраиваемое управление

Откройте меню → **Управление**. Две раскладки — «Плеер» и «Телефон» —
определяют доступные действия. Кнопка `+` добавляет альтернативное назначение;
нажатие на существующее меняет его; `×` удаляет; «Заменить» оставляет одно
новое назначение вместо всех прежних. Конфликт с другим действием требует
явного выбора «Переназначить».

«Только для этой игры» сохраняет изменения по стабильному идентификатору
игры. Остальные действия наследуются из общей раскладки. Если позднее общая
раскладка назначит ту же физическую кнопку другому действию, назначение игры
имеет приоритет. Сброс при включённой галочке удаляет только изменения игры;
без галочки сбрасывает выбранную общую раскладку. Индивидуальные изменения
других игр сохраняются.

Клавиатура использует физические коды клавиш, поэтому буквы не зависят от
русской/английской раскладки. `*` и `#` дополнительно распознаются как символы.
Esc отменяет захват нового назначения; системные сочетания Ctrl/Alt/Meta
остаются браузеру. Кнопки мыши и колесо действуют над LCD. При назначении
мышью нажмите на выделенную область захвата, чтобы клики по настройкам
не превратились в привязки. Экранные кнопки и мультитач остаются доступны.

Геймпад должен быть виден браузеру через **Gamepad API**. После подключения
нажмите на нём кнопку; меню покажет имя устройства. У стандартного контроллера
по умолчанию назначены крестовина, левый стик и основные кнопки. Нестандартные
кнопки и обе стороны каждой оси назначаются вручную. Оси преобразуются в
цифровые направления с порогом нажатия 0,65 и отпускания 0,35; аналоговые
триггеры — 0,6 и 0,35. Привязки геймпада общие для контроллеров с одинаковыми
индексами кнопок/осей. Отдельные профили по серийному номеру, WebHID и сырые
USB/Bluetooth-протоколы не реализованы; устройство должно предоставляться
браузером как клавиатура, мышь или Gamepad.

Удержание учитывается отдельно для каждой физической кнопки. Отпускание одной
альтернативы не отпускает другую. Потеря фокуса, открытие меню, смена корпуса
или игры освобождают удержания; отключение геймпада освобождает его кнопки.
После назначения кнопки контроллера нужно отпустить её перед следующим
игровым нажатием. Настройки хранятся в `localStorage` под `reunion-bindings`;
сохранения игр в IndexedDB от них независимы. Смена корпуса не меняет профиль VM.

## Проверка

`tests/unit/input-bindings.test.mjs` проверяет наследование, альтернативы,
конфликты, загрузку настроек и пороги. `tools/browser-input-check.mjs` проверяет
реальный интерфейс в Chrome с отдельным тестовым Worker и подставленным
Gamepad API: перекрывающиеся удержания, захват мыши/колеса/геймпада,
отключение, потерю фокуса, перезагрузку и сброс. Физический контроллер
этим тестом не проверяется. Существующий `browser-presentation-check.mjs`
дополнительно проверяет мультитач и неподвижность LCD.

После `npm run build`, с отдельно установленным Playwright:

```sh
node tools/browser-input-check.mjs
```

`REUNION_PLAYWRIGHT` позволяет задать URL модуля Playwright, `REUNION_CHROME` —
путь к установленному Chrome; `REUNION_INPUT_OUTPUT` — JSON-файл результата.
