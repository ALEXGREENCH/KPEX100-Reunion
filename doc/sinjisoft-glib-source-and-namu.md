## Что находится в коде

`GLib.h`, `GLibMain.c` и `GExt.c` описывают нативную библиотеку C:
`GameMain(reason, data)`, таблицу функций, события клавиш и таймеров,
графический адаптер MIL. Это полезный материал для исследования ранних
встроенных игр Sinjisoft. Работающий интерпретатор SGS в этих файлах не
установлен; SDK GNEX 1.20/1.40 этот репозиторий не заменяет.

В заголовках сохранены уведомления SINJISOFT ©1999 и даты версий от 0.9
до 2.x. Это данные заголовков внутри позднейшего проекта, а не доказательство
даты публикации или неизменности исходников производителя. Git-история
относится к марту–июню 2025 года. Проект содержит Win32/Visual Studio,
Yamaha и Sonivox; сборка и игровой запуск в этом проходе не проверялись.

При определённом в текущем `GExt.h` профиле SKTT5 таблица `s_GameDef`
регистрирует восемь игр:

| Запись исходной таблицы | Размер в этой записи |

| G80 Apache5             | 128 × 160            |

| G82 MarsScouter3        | 128 × 160            |

| G84 Puzzle3             | 128 × 160            |

README автора ещё относит две игры к upcoming; последняя версия кода уже
содержит восемь записей. Комментарий SKTT5 про 120 × 160 расходится с
активными глобальными размерами `SWAP_LCD` 128 × 128. Эти различия сохранены,
единственная «правильная» конфигурация по ним не выдумывалась.
README связывает Hamster Box с SGH-C100, Gaza 2 — с Giga Gxx-430;
это атрибуция автора, в данном проходе не подтверждённая исходным дампом.

## Проверка сохранения

Git bundle содержит полную полученную историю и две ссылки HEAD/main.
`git bundle verify`, `git fsck --full` и новая mirror-копия из bundle
прошли успешно. Каждый файл экспортирован как сырые байты Git blob:
проверены Git SHA-1 с заголовком `blob`, SHA-256 и размер.
Автоматическое преобразование CRLF при checkout не применялось.
Первоначальный `git archive`, затронутый глобальной настройкой CRLF,
в комплект оригиналов не включён.

Статически извлечены 576 буквальных `BYTE`-массивов. Для сопоставления
выбраны 206 уникальных массивов map/ma2/ma3 длиной от 256 байт.
У 189 нашёлся 32-байтный якорь хотя бы с восемью разными значениями;
остальные 17 с однообразным началом исключены. После якоря сравнивались
все байты массива. В семи новых сырых образах
и 110 выбранных исходных слоях/игровых файлах совпадений не найдено.
Метод проверяет идентичность ресурсов, не эквивалентность кода, не
сжатые варианты и не работоспособность игры. Слово MMMD само по себе
не считается проверкой полного SMAF.

Корневой LICENSE в полученном дереве отсутствует. Существующие уведомления
в исходниках, включая Sonivox, сохранены. Они не заменяются лицензией MIT
Reunion. Исторический код и бинарники отделены от основного эмулятора.
Forgejo API вернул 429; повторные запросы к нему прекращены. Отсутствие
доступа к API не трактуется как отсутствие релизов или вложений.

## Ссылка NamuWiki

Переданная [английская страница NamuWiki](https://en.namu.wiki/w/%ED%94%BC%EC%B2%98%ED%8F%B0%20%EA%B2%8C%EC%9E%84)
и корейский оригинал вернули 403. Получена и сохранена отдельная
[корейская копия namu.moe](https://namu.moe/w/%ED%94%BC%EC%B2%98%ED%8F%B0%20%EA%B2%8C%EC%9E%84).
Она используется как вторичный указатель. Среди зацепок Sinjisoft —
가자가자/GAZAII, X-Ship, 뽀숑/PoShong, 투사/Real Fighters, Bowling и Aiolos.
Авторство, конкретную модель и формат каждого бинарника нужно проверять отдельно.

Сохранены также пять ответов по ссылкам из этого указателя: настольные и
мобильные страницы brewgames/palletshipping и главная dubigame.tistory.com.
Все вернули HTTP 200; это страницы и оболочки блогов, не полученные пакеты игр.
Внутри архива они отделены от Git-исходников вместе с квитанциями и исходным
HTML. Полный обход этих блогов данным выпуском не заявляется.
