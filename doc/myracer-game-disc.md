# Игры MyRacer MF101 и Sketcher

Игровой диск MF101 содержит пять XGN. Все пять удалось распаковать
побайтно так же, как их распаковывает ARM-загрузчик MyRacer. Отдельное
вложение Sketcher из корейского форума использует VGN. Его SGS сверили
с другой веткой того же загрузчика.
[Образ диска](https://archive.org/details/MyRacerMF101),
[прошивка](https://cafe.naver.com/myracer/4921),
[вложение Sketcher](https://cafe.naver.com/halfstudy/1949).

| Игра                     | Проверено в Reunion при 320 × 240                                 |
| ------------------------ | ----------------------------------------------------------------- |
| Mini Game Paradise       | Первая мини-игра, нажатия Z и 5, счёт 47                          |
| Ppunyu Ppunyu Pong Remix | Начало головоломки, перемещение курсора стрелками                 |
| Super Action Hero        | Удар ↑ + Z на тренировке, противник получает 8 урона              |
| Penoa Chronicles 2       | Пропуск вступления через X / CLR, перемещение по карте стрелками  |
| Sketcher                 | Первая трасса, меню на трассе по кнопке вызова или A              |
| Com2uS Soccer            | Товарищеский матч, движение игрока и камеры при удержании стрелки |

Все шесть сборок доступны в библиотеке. Для них сравнили кадры с вводом
и без ввода в одинаковое виртуальное время. Первый отчёт сохраняет исходные
результаты, включая прежнюю остановку Soccer на загрузке. Ход матча и
разбор нагрузки сохранены отдельно. [Первый отчёт](../validation/myracer-library-replays.json),
[проверка Soccer](myracer-soccer.md).

## Sketcher VGN

Для XGN загрузчик по адресу `0x0809c0c4` использует фиксированное
дополнение к DES-ключу. Ветка VGN `0x0809c034` получает четыре байта
конфигурации от вызывающего кода. Проверка 16-байтного хвоста требует
строку `TPSP`, четыре байта конфигурации и метку типа `sgs`.

Для этого вложения по контрольному хвосту восстановлены байты
`27 70 00 00`. С ними оригинальная ARM-процедура вернула `2`, а её
выход совпал с независимой распаковкой. С фиксированным дополнением XGN
та же процедура вернула `-1`. Проверка относится к этому VGN. Модель
плеера, для которого распространялось вложение, остаётся открытым вопросом.

```sh
python -m pip install pycryptodome
python tools/unpack-myracer-xgn.py game.xgn game.sgs
python tools/unpack-myracer-xgn.py clubzio_sketcher.vgn sketcher.sgs --vgn-config 27700000
```

Полученный `스케쳐` — полный SGS v4 на 939 682 байта с 1370 ресурсами.
SHA-256: `d24629799963cca70ef53ce8678c9ad49856edb992bc8a1ebd4cfefa386bc39e`.

В исследовательском ZIP лежат исходный ISO, обновление 2008 года,
пять отдельных XGN, исходный VGN и шесть производных SGS. В манифесте
указаны размеры, CRC-32 и SHA-256. Ответы форумных API, метаданные
Internet Archive и контрольные кадры лежат отдельно от игровых файлов.
[Каталог архивов](https://alexgreench.github.io/KPEX100-Reunion/research/),
[скачать комплект MyRacer](https://raw.githubusercontent.com/ALEXGREENCH/KPEX100-Reunion/main/research/archives/MyRacer-MF101-Game-Disc-and-Sketcher.zip).
