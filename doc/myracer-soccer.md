# Com2uS Soccer для MyRacer

Из `컴투스사커.xgn` на диске MyRacer MF101 получен SGS v4 на
1 905 224 байта с 1470 ресурсами. Результат совпал с выходом оригинального
ARM-загрузчика. В библиотеке игра называется **Com2uS Soccer (MyRacer)**.
[Оригинальный диск](https://archive.org/details/MyRacerMF101),
[архив и происхождение](myracer-game-disc.md).

В профиле 320×240 проверен товарищеский матч Германии против Нидерландов.
Удержание ↑ в течение 1,1 секунды изменило положение игрока и камеры
по сравнению с прогоном до того же игрового времени без ввода. В Chrome
матч запускается через меню на поле клавишей Z.
[Сценарии и хеши кадров](../validation/myracer-soccer-gameplay.json).

## Предел таймера и стоимость ARM-блоков

На загрузку поля ушло около 18,1 млн виртуальных ARM-инструкций в одном
событии таймера. Сборке MyRacer выделено 40 млн единиц работы на такое
событие. Общий предел для остальных сборок составляет 20 млн.

Подсчёт работы и виртуального времени перенесён в отдельный хук
WebAssembly. Он обращается к JavaScript, когда адрес совпадает с
зарегистрированным ускорением или когда подключён наблюдатель. Тот же
прогон с прежним подсчётом в JavaScript дал одинаковые кадры, таймеры
и виртуальное время. На тестовом компьютере весь прогон занял 11,03 с
с подсчётом в JavaScript и 9,74 с с хуком WebAssembly. Медиана обработки
поздних событий матча составила 66,1 и 58,6 мс соответственно.
Игровой таймер в этой сцене запрашивает 50 мс, поэтому скорость может
зависеть от устройства. [Замеры](../validation/myracer-soccer-gameplay.json).

Ядро Unicorn ARM берётся из того же дистрибутива. Для пересборки
отдельного хука нужен Binaryen `wasm-as`. Опубликованный бинарник собран
версией 118 из [исходника WAT](../vendor/unicorn-sources/block-monitor.wat).

```sh
wasm-as vendor/unicorn-sources/block-monitor.wat -o web/engine/block-monitor.wasm
```
