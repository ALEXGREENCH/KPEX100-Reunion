# Ранние игры MDream для GVM

С сайта MDream восстановлены 104 ранее не сохранённых оригинала. Это 35 страниц, 45 GIF, 23 SWF и один CSS. В комплекте есть индексы CDX, HTTP-заголовки, ссылки на выдачу игр, манифест SHA‑256 и CRC32. Совпадение SHA‑1 с CDX подтверждено для каждого оригинала. Ещё три уникальных тела уже были в архиве WebENG/NATE. [Скачать комплект](../research/archives/MDream-GVM-Game-Catalogue-and-Demos.zip) · [Манифест оригиналов](../validation/mdream-gvm-catalogue-and-demos.json) · [Архив WebENG/NATE](webeng-nate-gvm-game-catalogues.md)

В Chrome с Ruffle 0.7.1 кнопки `3` и `6` в руководстве Moon Patrol вызвали анимации прыжка и выстрела. В SWF найдено 11 записей действий кнопок мыши. Команды переходят между заранее заданными кадрами и целями. Кадры проверки и разбор AVM1 сохранены отдельно от оригинала.

## Где искать телефонные файлы

Карточка Moon Patrol передавала обработчику NATE адрес `www.game-top.co.kr/vm/011/gvm/patrol/patrol_1.php`. Запрос CDX к этому префиксу за 2000–2008 годы вернул пустой список. Для Galaga страницы сохраняют адрес `/vm/011/gvm/galaga/galaga_1.php`. Для Hidden восстановлены отдельные адреса вариантов. На запросы Wayback Availability к четырём проверенным адресам пришёл HTTP 429. Эти ответы оставляют вопрос о наличии снимков открытым. [Сохранившиеся WML GameTop](gametop-nate-puzzle-bobble-hidden.md)

Из 472 выбранных записей о воспроизведении 116 ответов совпали с CDX, включая повторные URL. Остальные отмечены в журнале. Поиск SGS в проверенных телах совпадений не дал. В отдельной выборке CDX по расширениям `.sgs`, `.mbin`, `.jar`, `.jad` и другим были фоновые изображения с расширением `.sis` и записи патчей ПК-игры Tomak. Телефонные файлы этих выпусков пока не восстановлены.
