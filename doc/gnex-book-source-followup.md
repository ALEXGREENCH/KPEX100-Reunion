# Учебные исходники GNEX и книжные проекты

5 ноября 2026 года сохранены два публичных материала разработчика `tack0829`.
**Новых игровых SGS этот проход не дал.** Полученные исходники собраны в
[отдельный архив](../research/archives/Korean-GNEX-Developer-Sources-Round2.zip);
[хеши, происхождение и границы проверки](../validation/gnex-book-source-followup.json).

Архив имеет **68 180 байт**, SHA-256
`6cc9c7fe4debf28e2c21526cc50ce20b31c1c4ccb4fc68d7777dac6aaf7de794`.
В нём оригинальный ZIP, отдельный исходник, точные распакованные копии двух
файлов ZIP, README на русском и английском, манифест и библиография.

| Материал                |        Размер | Источник                                                                       |
| ----------------------- | ------------: | ------------------------------------------------------------------------------ |
| `3dTest-tack0829.zip`   |   31 426 байт | [3D-самолёт, 18 июля 2006](https://blog.naver.com/tack0829/100026419558)       |
| `3dTest.mc` внутри ZIP  |    2 960 байт | Тот же архив                                                                   |
| `airplane.H` внутри ZIP | 118 024 байта | Тот же архив                                                                   |
| `test-1335-tack0829.mc` |      913 байт | [Пример GetSysMin, 26 июня 2006](https://blog.naver.com/tack0829/100025603784) |

3D-пример объявляет `PLAYERVER 4`, использует GNEX3D, таймер и клавиши для
управления моделью. Автор пишет, что `airplane.H` взят из SDK-примера;
независимого совпадения по хешу пока нет. Архив не содержит `SScript.h`,
`GNEX3D.h` и `GNEX3D.SSL`: пост предполагает их наличие в SDK.
Второй материал — исходный код вызова `GetSysMin` и вывода результата,
без сохранённого номера телефона. Он объявляет `SCRIPTVER 1`, который
комментарий называет GVM 1X. Это объявления исходников, а не проверка
формата скомпилированного SGS.

Оригинальные байты и кодировка сохранены. Код не запускался и не
компилировался; сборка, современная Windows и выполнение в Reunion не
проверялись. Проверены CRC внешнего и исходного вложенного ZIP, все
семь файлов манифеста после чистой распаковки и побайтное совпадение
обеих копий исходников с вложенным ZIP. Временные адреса загрузки,
HTML блогов, данные участников и исследовательские дампы в комплект не входят.

## Книжные маршруты

- [WIPI GNEX를 이용한 모바일 프로그래밍](https://www.yes24.com/product/goods/1950963),
  강진영 / 정찬성, 생능출판사, ISBN **9788970504445 / 8970504443**.
  Каталог называет Star Wars и Aiolos и размещение примеров в загрузках
  GNEX Club. Сохранённый доступный снимок раздела загрузок показывает
  форму входа; проектные файлы не получены.
- [모바일 게임 제작 프로그래밍](https://www.yes24.com/product/goods/2497291),
  김진호, 글로벌, 2007, ISBN **9788955023763 / 8955023766**.
  Главы содержат `치약맨`, `Catch & Road`, `뛰맨뛰맨`, `점프점프` и
  `몸짱 만들기`. На четырёх страницах [публичных загрузок издателя](http://www.gbbook.com/file/01.php)
  прочитаны названия 36 записей; подходящих названий нет. Содержимое
  этих 36 вложений не проверялось. Три ZIP-адреса архивного индекса
  дали HTTP 429 при загрузке; живые оригиналы дали 404.
  **Содержимое трёх архивов остаётся непроверенным.**
- [모바일 게임 프로그래밍](https://www.yes24.com/product/goods/5209938),
  김진호 / 최명복, 북스홀릭, ISBN **9788994393032 / 899439303X**.
  Есть GNEX и пример Tetris. Приложения содержат планы `다림질의 달인`,
  `이대리의 10억 만들기`, `화투 캡처 고도리`; наличие плана не доказывает
  сохранность исполняемой игры. YES24 указывает 25 июня 2011 года,
  [Национальная библиотека парламента](https://dl.nanet.go.kr/detail/MONO1201121771)
  описывает издание 2010 года. Сайт издателя вернул HTTP 400, HTTPS
  не прошёл проверку имени сертификата, архивный индекс не ответил
  вовремя. Проверка TLS не отключалась; проектных файлов нет.

Книги остаются направлениями поиска. Отсутствие названия в списке,
пустая поисковая выдача и неудачная загрузка не доказывают утрату диска
или отсутствие игр в его содержимом.
