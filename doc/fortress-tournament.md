# Fortress Tournament из LG SD1000

**포트토너먼트**, заставка Softnyx Mobile, строка версии `GFTC1.7`.
Игра извлечена из записи `gvm2x/gvm2x_001` в образе LG SD1000
`SD430I13`. В каталоге Reunion она отмечена как восстановленная копия.
[Исходный архив дампа](https://archive.sunderland93.ru/Firmwares/LG/SD1000/SD430I13.7z),
[запуск в браузере](https://alexgreench.github.io/KPEX100-Reunion/).

## Сохранившиеся байты

Запись состоит из заголовка файла и 430 страниц данных по 256 байт.
Физический образ обрывается на странице с порядковым номером 409.
Следующие логические страницы сохранились раньше в том же образе.
Недостаёт 12 байт с позиции 98 179 в SGS. Они лежат в ADPCM-данных
`Awa` одного эффекта Yamaha SMAF, ресурса 397. Оригинальный CRC-16
этого эффекта сохранён. После подстановки нулей он не совпадает.

Упакованные исходные фрагменты и запускаемая копия сохранены отдельно.
В копии вставлены только 12 нулей, без изменений кода, таблиц и всех
доступных байтов. Извлекатель проверяет SHA-256 исходного сегмента
и результата извлечения.
[Фрагменты, копия и манифест](../research/archives/LG-SD1000-Fortress-Tournament.zip).

```sh
python tools/restore-fortress-tournament.py LG-SD1000-pt2.bin recovered-fortress
```

## Первый матч

После заставки нажмите `1`, чтобы открыть меню, затем ещё раз `1`
для выбора турнира. `Z` / OK начинает региональный турнир.
В матче `4` и `6` перемещают танк, `Z` / OK стреляет.
На экране 120 × 119 проверены выбор турнира, движение и полёт снаряда.
Сценарий охватывает начало первого боя.

При загрузке поля код делает 7 300 итераций разбора карты.
Один вызов TIMEOUT использовал около 57,9 млн единиц работы ARM.
В профиле игры установлен предел 60 млн для таймеров. При стандартных
20 млн тот же сценарий прерывается во время разбора карты.
Кадры совпали с повтором на обычном подсчёте ARM-инструкций.

```sh
node tools/replay-sgs.mjs fortress-tournament-lg-sd1000 validation/replay-fortress-tournament.json fortress-frames
```
