# Спрайты Mini Game Heaven Anycall

Из Mini Game Heaven в Samsung SCH-W420 CD16 извлечено 635 сжатых изображений MQ. Первые два содержат подписи `Anycall Ver.` и `Anycall`. Есть персонажи, фрагменты заставки и надписи кнопок. В архиве лежат исходные MQ, индексные карты и шесть листов предпросмотра с пробной палитрой RGB332. [Архив](../research/archives/Samsung-SCH-W420-Mini-Game-Heaven-MQ.zip) · [Проверка](../validation/samsung-w420-minigame-heaven-mq.json) · [Исходная игра и звуки](samsung-w420-minigame-heaven.md)

## Откуда взялись размеры

Оригинальный Thumb-код по адресу `0xf400ff4c` обращается к таблице по адресу `0xf5005408`. В двух снимках гостевой памяти, перед вызовами вывода с номерами 2 и 55 (счёт с нуля), все 13 400 байт таблицы совпали. Размер строки — 20 байт. Поля на смещениях `+4`, `+6`, `+8` и `+12` содержат ширину, высоту, указатель на запись и поле прозрачности соответственно.

Из 670 строк 35 имеют нулевой указатель и флаг. В остальных 635 указатели ведут к различным MQ в EADS. Для каждого произведение ширины на высоту совпало с количеством пикселей в заголовке MQ. Исходные записи занимают 153 496 байт, индексные карты — 610 502 байта. Манифест указывает смещения и контрольные суммы каждого файла. В архиве также сохранены 190 оригинальных троек RGB, передаваемых в службу преобразования цвета. Соответствие этих цветов индексам штатной палитры пока не восстановлено.

Для повторного извлечения возьмите `mini-game-heaven-anycall.eads` из [архива игр](../research/archives/Samsung-SCH-W420-Anycall-Games-and-SMAF.zip), а `evidence/descriptors.bin` — из архива спрайтов.

```sh
python tools/extract-samsung-w420-mq.py mini-game-heaven-anycall.eads descriptors.bin w420-mq
```

## Что показал пробный запуск

Служба `0xa0` настраивает поверхность 240 × 297. Размер выделяемого гостем буфера и обращения к пикселям соответствуют одному байту на пиксель. В локальном профиле Samsung для ARAM индексный вывод через `0xa0:0x70` и операции копирования через `0x113:0x24` и `0x113:0x28` показали анимированный фрагмент оригинальной заставки. У `0xa0:0x88` оригинальный вызывающий код выделяет один байт для индекса цвета. Для пробного вывода этот индекс вычислялся по RGB332. [Ревизия ARAM](https://github.com/mirusu400/aram-core/tree/fea299cba15696ed1460f965b76626d6edab5e03)

На кадре 510 оба прогона дали один и тот же кадр с 3 402 нечёрными пикселями. После двух кадров с удержанием SELECT на кадре 519 экран чёрный, тогда как контрольный прогон на том же кадре содержит 3 695 нечёрных пикселей. В архиве сохранены снимки, сценарии и журналы. На этом этапе подтверждена реакция заставки на ввод, а игровой экран ещё предстоит восстановить.

## Другие выпуски

Публикация января 2006 года относит тогдашнюю Mini Game Heaven к GNEX. Это отдельная зацепка для поиска оригинального дистрибутива. Проверенная запись SCH-W420 в этом архиве — ARM Thumb EADS. В корейском списке предустановленных демоверсий есть также KTF-модели SPH-C2200, SPH-C2205 и SPH-W2400. Для SPH-C2200/C2205 указаны сразу Mini Game Heaven и Nom 2. Бинарники с этих моделей в этом проходе не получены. [Публикация 2006 года](https://www.dailygame.co.kr/view.php?ud=200601091805210000511_26) · [Список аппаратов](https://www.namu.moe/w/%EB%AF%B8%EB%8B%88%EA%B2%8C%EC%9E%84%EC%B2%9C%EA%B5%AD%282005%29) · [Варианты Anycall Mini Skirt](https://www.namu.moe/w/%EC%95%A0%EB%8B%88%EC%BD%9C%20%EB%AF%B8%EB%8B%88%EC%8A%A4%EC%BB%A4%ED%8A%B8)

Для поиска образа SPH-W2400 есть точная маркировка `BB27` в таблице испытаний Alpine. Octopus Box указывает поддержку записи прошивки этой модели с версии 1.1.0. Для поиска дампа важен полный префикс `SPH-W2400`, поскольку `SCH-W240` — другая модель.
