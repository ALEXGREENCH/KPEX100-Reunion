# Dragon Knight EX, Lapis Lazuli и Brain Game Q для KTF

Три вложения Dubigame отличаются от ZIP из Naver. При сравнении вложенных JAR все три совпали побайтно с ранее сохранёнными копиями. Архив сохраняет варианты упаковки и новые проверки запуска. У Dragon Knight EX и Lapis Lazuli отличаются идентификаторы AID, а у Brain Game Q совпали все файлы внутри внешнего ZIP. [Архив и прогоны](../research/archives/Dubigame-Dragon-Knight-Lapis-Brain-Game-KTF.zip) · [Сверка файлов](../validation/ktf-dragon-knight-lapis-brain-game.json)

| Игра             | PID и версия KTF       | Проверенная сцена                                                                                                                               |
| ---------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Brain Game Q     | `PD005196`, `01.00.01` | OK продвигает диалог до вопроса о прозвище. [Вложение](https://dubigame.tistory.com/34)                                                         |
| Dragon Knight EX | `PD003066`, `01.00.10` | Клавиша `#` пропускает прокрутку пролога и открывает сцену разговора в доме. [Вложение](https://dubigame.tistory.com/35)                        |
| Lapis Lazuli     | `PD005451`, `01.00.01` | Удержание стрелки вверх выводит персонажа из города на карту. Контрольный прогон остаётся в городе. [Вложение](https://dubigame.tistory.com/40) |

Проверены CRC внешних ZIP и вложенных JAR. Для каждой сцены в архиве есть пара прогонов ARAM. Перед последним действием кадры совпадают, после него сравниваются снимки на одном виртуальном кадре. [Ревизия ARAM](https://github.com/mirusu400/aram-core/tree/fea299cba15696ed1460f965b76626d6edab5e03)

В Lapis Lazuli 194 файла из JAR продублированы в каталоге с именем AID. Ещё 99 файлов лежат в `P/` и совпадают с каталогом `P/` копии из Naver. Всего среди этих ресурсов 29 разных MMF. У всех совпали длина контейнера и внутренняя CRC16 SMAF, а декодер Reunion вернул PCM с ненулевыми отсчётами. Две дорожки достигли лимита прогона в 20 секунд. В архиве лежит пример WAV из `logo.mmf`.
